# 05 · 实机截图与验收

**判断标准是实机截图**，不是 Blender 预览，也不是概念图（风格文档第 12 节原则五）。

## 截图命令

用 `tools/test_fimbulwinter_courtyard.gd` 截图。它会自动跑完整个房间流程，在关键节点保存 PNG。**不能加 `--headless`**，headless 模式下不截图。

```zsh
mkdir -p /Users/zhangjunqiu/Desktop/无限恐怖/docs/Codex_冻石庭院第四版/截图/轮次01
cd /Users/zhangjunqiu/Desktop/无限恐怖
/opt/homebrew/bin/godot --path . --log-file /dev/null --script res://tools/test_fimbulwinter_courtyard.gd -- --save-file=user://test_save.json --settings-file=user://test_settings.cfg --capture-dir=/Users/zhangjunqiu/Desktop/无限恐怖/docs/Codex_冻石庭院第四版/截图/轮次01
pgrep -x Godot || echo "无残留"
```

- 参数必须**原样写出**，不要放进变量。`--log-file /dev/null` 放在 `--script` 前面。
- 加上 `--record-walkthrough` 会跑完整录屏流程（会跳过部分快速路径），只在最终交付时用。
- 跑完确认 `~/Library/Application Support/Godot/app_userdata/无限轮回/` 下 `save.json`、`settings.cfg` 的修改时间没变，`logs/` 大小正常。
- 只跑逻辑测试（不截图）时可以加 `--headless`，其他参数照抄。

会输出这些截图（名称在测试脚本里）：

`courtyard` `dormant-gate` `approach-fight` `approach` `entry-open` `entry-sealed` `encounter` `strike` `reward` `restored-gate` `broad-court` `open-gate` `complete`

## 每轮自查

每次截图后，在 `截图/轮次NN/自查.md` 里写：

1. 选 3 张截图（`broad-court`、`strike`、`restored-gate`）和选定的目标图并排对比，用一两句话写出差距。
2. 对照 `01_审核结论.md` 逐条判断：已解决 / 部分解决 / 未解决。
3. 把截图缩小到 320×180，看能不能分清地面、边界、出口和玩家。
4. 下一轮先改什么。

**连续两轮差距没有缩小时，停下来在 `进度.md` 写明卡在哪里**，不要继续盲调。

## 录屏

最终交付时录一段完整流程，保存为 `docs/冻石庭院验收/media/v4-traversal.mp4`。可以用 Godot 的 `--write-movie <路径>.avi` 录完再用 `ffmpeg` 转 mp4（`/opt/homebrew/bin/ffmpeg`），也可以用 macOS 录屏。控制在 20MB 以内。

## 更新验收网站

网站在 `docs/冻石庭院验收/`，双击 `启动验收.command` 打开（端口 8773）。

1. 截图转成 webp，放进 `docs/冻石庭院验收/media/`，前缀 `v4-`：
   ```zsh
   cwebp -q 85 in.png -o v4-broad-court.webp   # 没装 cwebp 就用 ffmpeg -i in.png -quality 85 out.webp
   ```
2. `review.js`：`items` 里的媒体换成 v4 图。每个条目加一张「v3 → v4」对比图；`architecture` 条目必须同时放出口门的破败态和点亮态。新增一个 `concept` 条目，放制作人选定的目标图和对应的实机图。
3. `serve.py`：`VERSION` 改成 4，默认反馈文件改成 `验收反馈-v4.json`，`ITEMS` 加上 `concept`。**不要删** `验收反馈.json` 和 `验收反馈-v3.json`。
4. `index.html`：标题区改成「第四版」，首图换成 `v4-broad-court.webp`，色板换成冬夜色板，页首历史链接加上第三版反馈的下载。
5. 打开 `http://127.0.0.1:8773/` 实际看一遍：图片能加载、视频能播放、反馈能保存。

## 提交

- 只暂存你改过的文件的明确路径，提交前看一遍 `git status --short`。
- 大文件（mp4、大贴图）提交前先问制作人，或者确认已有 LFS 或忽略规则。
- 提交信息写清楚轮次，例如 `feat(courtyard): v4 winter lighting and snow materials`。

## 硬性规则

### Git

- **禁止** `git add -A`、`git add .`、`git commit -a`。只暂存你自己创建或修改的文件的明确路径。
- 提交前运行 `git status --short`。不是你改的文件（制作人会随时往 `assets/source/` 放素材）一律不提交，并在汇报里列出来。
- 不要 force push，不要改写历史。

### Godot 测试

- Godot 路径：`/opt/homebrew/bin/godot`，项目根目录：`/Users/zhangjunqiu/Desktop/无限恐怖`。
- 每次运行都必须**原样写出** `-- --save-file=user://test_save.json --settings-file=user://test_settings.cfg`，不要放进 shell 变量（zsh 不拆分变量，会覆盖制作人的真实存档和设置）。`--` 分隔符不能省。
- 每次运行都必须在 `--script` 之前加 `--log-file /dev/null`（日志曾经把磁盘写满到 138GB）。终端提示 "Failed to open log file for writing: /dev/null" 是正常的。
- 不要在后台留下 Godot 进程。结束后运行 `pgrep -x Godot` 确认没有残留，有就 kill。
- 测试结束后确认 `~/Library/Application Support/Godot/app_userdata/无限轮回/` 下 `save.json`、`settings.cfg` 的修改时间没变，`logs/` 没有暴涨。

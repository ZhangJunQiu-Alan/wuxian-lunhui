# 01 · 第三版审核结论

截图都在 `docs/冻石庭院验收/media/v3-*.webp`，录屏是 `v3-traversal.mp4`。制作人上一轮的意见在 `docs/冻石庭院验收/验收反馈.json`：「建模应该更精细」「出口门要有破败和点亮两种状态，点亮后要有传送门那样的闪光特效」。

总评：第三版像**夏日海岛上用倒角方块搭的白盒**。问题有三个来源：主题跑偏、建模和光照像积木、镜头和房间边界不像哈迪斯。

---

## P0-1 主题跑偏：没有冬天

**现象**：所有截图都是盛夏：绿草、晴天、白色积云，全场没有一片雪。HUD 上却写着「雪崖前路」「冻石庭院」。

**根因**：`assets/source/midgard_courtyard/v3/制作记录.md` 里的生成提示词直接要求了夏天：

- 松树：`no snow blanket`、`broad directional warm daylight`
- 冻草：`Rich olive green, moss lime`
- 远景：`Crisp hard daylight`、`rich clear cobalt blue sky`
- 水面：`under direct daylight`

第三版照搬了参考图的色板（草坡 `#4D5D2D`、天光 `#5777C1`），没有用风格文档第 3.2 节给「芬布尔之冬」定的元素：深蓝永夜、暴风雪、黯淡太阳、月影、极光、积雪针叶林、冰封峡湾、浮冰、冰霜苔藓。

**树种**：`pine.png` 是黄山松、迎客松那种盆景造型，东方味很重，不是北欧的云杉或冷杉。

## P0-2 建模与光照像积木

**石块上白下黑**（所有截图都有）：石块顶面骨白、侧面接近纯黑，像奶油夹心饼干。这违反第 1.3 节「不采用低多边形、玩具感」和第 6.3 节「不应让区域接近纯黑」。

根因在 `scripts/roguelite/fimbulwinter_courtyard_stage.gd:63-76`：

```gdscript
world.environment.ambient_light_color = Color("#b1bacf")
world.environment.ambient_light_energy = 0.24   # 补光太弱
sun.rotation_degrees = Vector3(-51, -49, 0)       # 唯一光源，高角度顶光
```

只有一盏高角度太阳光，环境光只有 0.24，所以背光面全黑。`courtyard_masonry.gdshader` 可能还把侧面压得更暗了，要一起检查。

**同一个模型复制十几次**：石柱全是同一个「倒角方块叠三层 + 黑色竖槽 + 三道金线」（`v3-broad-court`、`v3-approach-fight`）。三石门像巨石阵，出口拱门像罗马拱，都不是北欧建筑语言。第 10.3 节要求的是：厚重木梁与石质地基、兽首、交织纹样、符文雕刻、强烈的竖向轮廓。

**黑色岩块**：多面体，纯黑，没有纹理层次。在画面上像几个黑洞（`v3-approach-fight` 左上、右上）。

**出口门**（`v3-dormant-gate` / `v3-restored-gate`）：
- 破败状态是黑白相间的斑马纹，看起来像渲染出错，读不出「破败」。
- 点亮状态的蓝色漩涡方向是对的，但地面没有被照亮，也没有泛光和上升粒子，存在感不够。

## P1-1 镜头与构图不像哈迪斯

**天际线占了画面上方三分之一**：天空和远山贴在画面上方，看起来像身后立了一块背景板（`v3-courtyard` 最明显）。

根因：镜头已经是正交投影（`camera.projection = PROJECTION_ORTHOGONAL`，`CAMERA_OFFSET = (-2.25, 7.45, 10.0)`），但远景 `_matte` 是一块**正对镜头的竖直平面**，贴的是平视角度的峡湾画（`fimbulwinter_courtyard_stage.gd:85-89, 273`）。俯视的场景配上平视的远景，透视对不上。

哈迪斯的战斗画面基本看不到天际线，远景放在**画面下方和四周**：深渊、海面、云雾，从高处往下看。

**房间没有边界**：分不清哪里能走。草地和石路都能走，碎石墙随机散落；`v3-broad-court` 右侧那组 T 字形石块像调试摆件；岛的边缘是直线切开的黑色悬崖块（`v3-dormant-gate` 右下角）。

**石路和草地的交界**：边缘是噪点糊出来的软边，外面还有一圈灰绿色的脏晕，像低分辨率的地形混合遮罩。路面只有一张大裂纹贴图，没有石板分块，读起来像水泥地。

## P1-2 战斗可读性

**角色被挡住**：`v3-strike` 里玩家被拱门完全挡住，只露出一条边。这违反第 3.2 节第 6 条「不得长期遮挡玩家」。

**2D 和 3D 不协调**：角色和敌人是低分辨率像素精灵，场景是平滑的 3D 插画风，角色看起来像贴在场景上。接地只有一圈细环，没有落地阴影。

## P2 次要问题

- HUD 是占位：扁平红条加小字，关卡标题压在树上。等场景定稿后再处理，本轮不做。
- 火盆的橙色光点偏小、偏可爱，可以保留，但要和冬夜光照一起重新调亮度。

## 做得对、要保留的部分

- 正交斜俯视镜头和平滑跟随，方向是对的。
- 前路 → 中庭 → 出口的流程、落闸、清场开门已经跑通。
- 出口门「破败 / 点亮」两态的逻辑已经有了，只需要重做表现。
- 石材的骨白色和冷蓝色远景，符合苍蓝神话的主色关系。

- [x] **T1 重做材质贴图**。重新生成 `limestone`、`meadow`、`basalt`、`water`、`fjord_panorama`，提示词写进 `assets/source/midgard_courtyard/v4/制作记录.md`。
  - 地面主体：积雪覆盖的石板。雪厚处纯白偏冷蓝，薄处露出石板接缝。
  - `meadow` 改成 `snowfield`：积雪、冻土、冰霜苔藓，石缝里只露一点枯黄草茎。**不要大面积绿色。**
  - 水面：冰海，带浮冰和薄雾，深蓝偏墨。
  - 删掉旧提示词里所有 `no snow`、`warm daylight`、`clear sky` 类描述。
- [x] **T2 换树**。`pine.png` 换成积雪的北欧云杉或冷杉（窄锥形、枝条下垂、枝上压雪），做 2–3 个变体，避免全场一个树形。
- [x] **T3 冬日光照**。修改 `fimbulwinter_courtyard_stage.gd` 的 `_ready()`：
  - 太阳：低角度（俯角约 20–30°），淡冷白或淡金色，能量降低，拉出长影。
  - 环境光：改成冷蓝（参考 `#6f86b8`），能量提高到背光面能看清石材纹理（从 0.24 起步往上调，目测侧面亮度不低于顶面的 35%）。
  - 加一盏反方向的弱补光，或者给石材加 rim light，让剪影和背景分开。
  - 打开 `Environment` 的 glow，只让传送门、符文和火盆发光；可以加很轻的高度雾，压住远景。
  - 背景色 `#244a93` 改成更深的冬夜蓝。
- [x] **T4 天气粒子**。加一层很轻的飘雪 `GPUParticles3D`，只在镜头附近生成，密度低，不能挡住角色和敌人攻击提示（风格文档第 7.3 节）。

**验收**：截图缩小后，第一眼看到的是「雪」和「冬夜」，而不是绿地和晴天。

## P0 · 建模与出口门

- [x] **T5 去掉「上白下黑」**。T3 做完后检查 `courtyard_masonry.gdshader`，确认它没有把侧面压黑。石材侧面要看得见裂纹和颗粒。
- [x] **T6 重做北欧建筑资产**（流程见 04）。至少做这些，每种 2 个以上变体：
  - 符文石碑：竖高的石板，有交织纹和符文浮雕，顶部可以带积雪和裂口。代替现在的方块石柱。
  - 长厅残骸：厚木梁、石质地基、倾斜断裂的立柱、兽首木雕。代替现在的三石门。
  - 低矮边界墙：干砌石墙加积雪，围出房间边界。代替随机散落的方块。
  - 岩体：有层理和裂面、带积雪顶面的玄武岩，深灰而不是纯黑。
- [x] **T7 出口门两种状态**（制作人上一轮的意见）：
  - 共用一个北欧门框：两根刻纹石柱加木梁和兽首。
  - **破败态**：横梁断裂下垂、柱身微斜、符文槽是暗的、积雪堆在门口。不要再用黑白相间的斑马纹。
  - **点亮态**：模型复原（可以做一个 0.6–1 秒的复原动画：碎块归位，符文从下往上依次点亮），符文发冰蓝光，门内是竖直光幕（沿用 `courtyard_portal.gdshader` 并加强），地面上有一圈被照亮的区域，雪尘和光点上升，glow 生效。
  - 两种状态都要在实机里截图对比。
- [x] **T8 入口木闸**：同样换成北欧木石结构，落下时加尘雪特效和轻微震屏（震屏已有，沿用）。

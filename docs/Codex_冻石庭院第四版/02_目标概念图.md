# 02 · 目标概念图（第一步，必须先做）

第一版到第三版都是边写 `build_*.py` 边调，**一直没有一张目标效果图**，所以每一版都在随机游走。第四版先定目标画面，再动游戏。

## 交付

在本文件夹下建 `目标图/`，放入：

| 文件 | 内容 |
| --- | --- |
| `A_中庭战斗.png` | 中庭主战区，玩家加 3–4 个敌人，出口门在画面一侧（点亮状态） |
| `B_前路.png` | 入口前路，林缘夹道，入口门在画面下方 |
| `C_出口特写.png` | 出口门的破败态和点亮态，左右并排 |
| `提示词.md` | 每张图的完整提示词和生成工具 |

每张图出 **2–3 个方案**（例如 `A_中庭战斗_1.png`、`A_中庭战斗_2.png`），供制作人挑选。

**出完图就停下**，在 `进度.md` 写「目标图待制作人选定」，等确认后再进入 03。

## 构图硬性要求

- **镜头**：和游戏一致的正交斜俯视，约 50° 向下看，镜头从左前方看过去，和当前 `CAMERA_OFFSET = (-2.25, 7.45, 10.0)` 同向。尺寸 1280×720。
- **看不到天际线**。远景在画面下方和边缘：冰海、浮冰、雾、悬崖下的深渊，都是从高处往下看的。
- 战斗区是一块**边界清楚的舞台**：外圈由悬崖、石墙、木栅、雪堆或树林围合，中间地面干净。
- 角色约占画面高度的 9–10%（和现在一致）。

## 内容要求（来自风格文档第 3.2、10 节）

- **季节**：芬布尔之冬。地面以积雪、冻土、冰霜苔藓为主，石缝里只露一点枯草。
- **光照**：低角度的黯淡冬日（蓝调时刻），或深蓝永夜加月光；冷蓝色环境光加一个暖色火光点（火盆）。天上可以有极光，在海面上投下倒影。
- **植被**：积雪的云杉或冷杉，深色剪影。**不要**松树盆景造型。
- **建筑**：北欧语言，包括竖向的符文石碑（有交织纹浮雕）、长厅残骸的木梁与石基、兽首木雕。**不要**希腊柱、罗马拱、巨石阵。
- **出口门**：北欧木石结构，例如两根刻有交织纹的石柱、顶部横梁和兽首。破败态：横梁断裂、柱身倾斜、积雪覆盖、符文熄灭。点亮态：符文发冰蓝光，门内是竖直的光幕，地面被照亮，有上升的雪尘和光点。
- **色彩**：按第 2.3 节分配，大约 35% 蓝（冰海、阴影、雪面反光），30% 骨白（雪、石），25% 深黑（岩、树），10% 金和红（符文、火盆、血条）。
- 地标：远处冰海中可以露出一截**巨型战船残骸**或**冰封神像**的头部（第 3.2 节「巨构与地标」），只作剪影，不抢战斗区。

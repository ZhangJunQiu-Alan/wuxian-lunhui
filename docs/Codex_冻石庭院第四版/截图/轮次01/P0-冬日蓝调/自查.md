## 按第三版审核结论自查

| 现象 | 状态 | 实机依据 |
| --- | --- | --- |
| 盛夏绿草、晴空和迎客松 | 已解决 | 雪地主导，三种垂枝针叶树有积雪。原远景板贴上冰海纹理。 |
| 石材上白下黑、玄武岩像黑洞 | 已解决 | 岩体侧面能辨裂纹和层理。前路大岩块顶、侧各取一块无道具覆盖区域，按 sRGB 解码后的中位相对亮度比约 38%。深缝仍保留阴影。 |
| 石柱复制、建筑北欧语言不足 | 未解决 · T6 | 石柱、三石门和矮墙沿用原几何。 |
| 出口两态缺少破败感、点亮存在感不足 | 部分解决 · T7 | 点亮有局部泛光，门前雪能见光。破败态还有明暗石块相间，造型和传送光幕留待 T7。 |
| 远景缺乏俯视纵深 | 部分解决 · T9 | 深色冰海和轻雾减弱原来的晴天天际线，现有远景板仍会让上缘呈平面感。 |
| 院落边界散、崖缘有直切面 | 未解决 · T10、T12 | 原围合、崖线和碰撞布局沿用。 |
| 路面像一整块水泥、交界有灰绿晕 | 部分解决 · T11 | 石板已分块，积雪替掉灰绿边。边缘仍是雪遮罩的过渡，缺实体路沿。 |
| 入口拱门遮住角色、2D 精灵接地弱 | 未解决 · T13、T14 | 出刀帧仍被遮挡。像素精灵沿用。 |
| HUD 占位、火盆偏小 | 部分解决 · P2 | 火盆局部暖光更易辨，HUD 和火盆外形沿用。 |
| 飘雪影响战斗辨识 | 已解决 | 雪粒在大图中视作小亮点，缩图时前路敌人和黄色拦截提示仍清楚。 |

## 按 06 逐项检查

| 质量红线 | 核查结果 |
| --- | --- |
| 光向 | 圆环刻槽、断碑积雪和冰井上沿承接左上暖光。三个脚点有冷灰接触影。东门点亮后只在门槛附近出现明显冰蓝光。 |
| 结构和穿插 | 西闸沿原门框落下；东门整体平移，破败木板、复原横梁和光幕仍对齐同一门洞。长厅遮挡层收边 2 个纹理像素，边缘填入邻近木色，檐下空隙补回原画暗部；以两张指定截图的原生 100% 裁片复查。高、矮石碑的断面不同，井沿和井中冰面可辨。北侧倒架贴墙放置，南侧头盔和盾牌落在雪线。 |
| 符文 | 圆环空白铭文带逐字刻入 24 个古弗萨克字形。北侧高碑为 ᛉ，矮石为菱形刻纹。出口两态使用此前验收的字形和门框。 |
| 细节密度 | 东侧、南侧和西南侧各有一片带反光的薄冰。踩实的暗色雪路从西闸绕圆环南缘转向东门，沿路可见翘起的石板、暗缝及缺角。墙根与三处掩体下风侧有积雪。盾、头盔和旗集中在墙边。圆环内没有碰撞或直立装饰。战斗截图中可同时辨认玩家、刀光、敌人和断碑。 |
| 接缝和色调 | 从前路接西闸、越过中央圆环、到东门外逐段查图。门槛与积雪连续，巡检取景中未见矩形贴片边缘。 |
| 复制痕迹 | 两根立石分别为高窄斜断面和矮宽裂石，刻纹和雪脚不同。冰井和倒架各出现一次。林缘沿用前路绘图。 |
| 碰撞和遮挡 | 废弃石堆的图层和六个锚点一起移除。三处掩体分别检查步行阻挡、绕行、冲刺和背后站位。单独隐藏掩体或角色轮廓层，比较同一机位和姿态下的蓝色剪影像素。 |

## 测试计数

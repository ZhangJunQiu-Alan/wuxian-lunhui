## 背景

- 5 个部位：武器、头盔、胸甲、护腿、鞋子。武器分职业，枪手永远捡不到剑。防具只有图标，不显示在角色身上。
- **稀有度不进素材**。同一件装备会以任意稀有度掉落，颜色由代码加在名字、图标底框和光柱上，素材里不画稀有度颜色的边框或光晕。
- 装备掉在地上显示它的图标，光柱由代码画。小怪掉的金币和部位素材也直接显示图标。
- 武器用「分层 + 挂点」：身体只画一套空手动作，武器单独一张图，每帧记下手的位置和朝向，代码把武器摆到手上。格式以 S-SW 为准。

## 通用规则

- **不覆盖已有素材**。全部用新文件名交付，旧动作条保留，由 Claude 在代码里切换。
- 交付记录放 `assets/source/taskS_gear_<日期>/`，格式同 K、M：README、manifest、originals / candidates / approved、previews、records（提示词和哈希）。
- **像素密度**：1 像素 = 角色帧里的 1 像素。角色帧 64×64，人物从头顶到脚底约 48 像素高。武器图、图标都按这个密度画，不交需要缩放的图。
- 透明 RGBA，二值 alpha（没有半透明边），近邻缩放预览，限定色板（`docs/美术素材规范.md`）。
- 默认朝右，朝左由代码镜像。
- 第三关的 Boss 预警、火焰地面是红橙半透明。地上的图标、武器特效不要用大面积红橙，以免玩家分不清危险区。火属性的武器用暗色打底、少量亮橙点缀。
- 新来源先核实可商用，记入 `assets/LICENSES.md`。

## S-ART-01 枪手、刺客、法师（等武器设计审完）

![现有动作条](images/codex_s_gear/S01_current_strips.png)

参考图是现有 4 个角色全部 92 帧，3 倍放大，每帧标了 `动作[序号]`。

| 角色 | 动作帧数 | 武器现在的样子 |
| --- | --- | --- |
| 枪手 `gunslinger` | idle 4、move 6、attack 4、hurt 2、death 6，共 22 | 平时左轮在腰间枪套里。attack[0]～[2] 拔枪、瞄准、后坐，attack[3] 收枪 |
| 刺客 `assassin` | 4、6、6、2、6，共 24 | 所有帧双手各握一把短刃 |
| 法师 `mage` | 4、6、4、2、6，共 22 | 所有帧手里都握着长杖；死亡时长杖落地 |

量出来的尺寸：左轮约 8 像素，短刃约 10 像素，长杖约 45 像素。

- 空手动作条 `<角色>_bare_<动作>.png`、挂点表 `<角色>_sockets.json`、`manifest.json` 的格式都照 S-SW 的 SW-01～SW-03。刺客的 `off` 是副手短刃；法师死亡帧填长杖落地的位置和角度。
- 初始武器从原动作帧里拆成干净的单张图：`gunslinger/revolver.png` + `revolver_stow.png`、`assassin/blades.png`、`mage/nova.png`。被手挡住的握把补全。
- 手持图朝向：枪口、刃尖朝右（`base_deg` 0）；法杖杖头朝上（`base_deg` -90）。法师的书、镜子、棱镜这类不跟手转的，manifest 写 `"hold": "upright"`。
- 验收同 S-SW：合成回原样逐帧对比、换最长最短的武器不穿帮、原速和慢放 GIF、朝左镜像。

## S-SFX-01 音效（现在做）

放在 `assets/audio/sfx/`，单声道、44.1 kHz、16 位 WAV，和现有音效一致。响度对齐现有的 `pickup_xp`、`heal_pickup`。

| 文件 | 什么时候播 | 要求 |
| --- | --- | --- |
| `gear_drop_common.wav` | 普通装备落地 | 轻「叮」，很短 |
| `gear_drop_rare.wav` | 稀有装备落地 | 清脆 |
| `gear_drop_epic.wav` | 史诗装备落地 | 低沉的钟声 |
| `gear_drop_legendary.wav` | 传说装备落地 | 号角 |
| `gear_drop_artifact.wav` | 神器落地 | 专属，最隆重，约 1.5 秒以内 |
| `gold_pickup.wav` | 捡金币 | 短，连续捡很多次也不吵 |
| `enhance_success.wav` | 强化成功 | 锻打加上扬的收尾 |
| `enhance_fail.wav` | 强化失败 | 闷响，不要刺耳 |
| `salvage.wav` | 分解装备 | 碎裂加一点余烬的嘶声 |
| `equip.wav` | 换装 | 金属或皮革的轻响 |

- 5 档掉落音逐级更隆重，闭着眼也能听出是哪一档。
- 和现有的 `pickup_xp`、`heal_pickup`、`chest_open` 要能分开。

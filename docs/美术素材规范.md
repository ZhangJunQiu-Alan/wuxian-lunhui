# 美术与音频素材规范

分工：Codex 制作素材，Claude 审核、接入游戏并实测，用户试玩验收。

## 一、像素风规格

游戏按整数倍显示像素画，**画布尺寸就是游戏里的显示尺寸**。

| 类型 | 画布 | 动画 |
| --- | --- | --- |
| 可玩角色 | 64×64，人物约 48 像素高 | idle 4、move 6、attack 4~6（16 帧/秒）、hurt 2、death 6；只画身体，刀光是单独的特效 |
| 普通敌人 | 64×64 | move 4~6、attack 4 |
| 大型敌人（霜巨人等） | 96×96 | 同上 |
| Boss | 128×128；最大的（赫列姆、苏尔特等）192×192 | 每个技能至少 1 帧蓄力、1 帧出招；idle、move |
| 大招特写 | 400×320 | 静态，面部或眼部特写 |
| 地块 | 64×64，无缝平铺 | 静态 |
| 地图物件、贴花、边界 | 按物件大小，底边是落地位置 | 静态（火焰等少数 4 帧循环） |
| 升级卡插画 | 720×1200，**不是像素风** | 静态 |

- 透明 RGBA、二值 alpha（没有半透明边），近邻缩放，稳定的脚底锚点。
- **默认朝右**，朝左由程序翻转。人物在画布居中，四周留 2 像素。
- 每个篇章一套限定色板（32~48 色）。北欧篇章以雪白、冰蓝、灰为主，火焰和魔法用暖色点缀。
- 第三关的危险区是红橙半透明，地上的图标和武器特效不要用大面积红橙。
- 敌人轮廓要和背景、主角明显区分；精英怪的金边由程序加。
- 武器分层（身体空手帧 + 单独的武器图 + 每帧挂点）的约定见 [剑士武器美术任务](Codex_剑士武器美术任务.md)。

## 二、文件与接入

```text
assets/
  sprites/
    characters/   可玩角色      swordsman.png
    enemies/      普通敌人      draugr.png、wolf.png …
    bosses/       Boss
    allies/       援助的神和英灵
    weapons/      分层武器图（装备系统）
    effects/      技能特效（gods/ 神术，bosses/ Boss 效果）
    pickups/      拾取物
    cards/        升级卡插画
    ground/<关卡>/  地块
    props/<关卡>/   地图物件
    borders/<关卡>/ 地图屏障
    decals/<关卡>/  地面痕迹
    ui/           界面
  audio/sfx/      音效（.wav）
  audio/music/    音乐（.ogg）
  source/         每批素材的原图、中间稿、制作记录，Godot 不导入
  LICENSES.md     素材授权台账
```

**角色、敌人、Boss 按文件名自动加载**，放进去就替换，不用改代码。地块、物件、特效要 Claude 在代码里接。

- 静态图：`<id>.png`。程序自动加走路颠动、轻摆和影子。
- 动画：横向帧条，每帧正方形，从左到右，按动作命名：`<id>_idle`、`_move`、`_attack`（16 帧/秒）、`_hurt`、`_death`；其余 8 帧/秒。精英加 `_elite`，例如 `draugr_elite_attack.png`。
- 优先级：`<id>.tres`（SpriteFrames）> 帧条 > 静态图。
- 升级卡：`cards/<神明id>.png`、`<神明id>_awaken.png`、`general.png`、`<角色id>.png`；质变、觉醒、融合有 `<卡牌id>.png` 时优先用。缺图时回退到神明画像，融合卡左右拼两位神。
- 音频：`audio/sfx/<名字>.wav`、`audio/music/<名字>.ogg` 按名播放；放 `<名字>_01`~`_03` 时随机挑一个。代码在 `scripts/core/audio.gd`。

## 三、交付规则

1. 开工前先核对已有素材和实际加载代码，已有合格的不重做，不覆盖旧文件。
2. 每批放在 `assets/source/task<批次>_<日期>/`：README、manifest、originals / candidates / approved、previews、records（真实提示词、参考、退稿原因、哈希）、integration.md（接入说明）。
3. 在游戏实际画面里检查（原速、慢放、逐帧），不以图库代替游戏画面。没运行、没试听的不标通过。
4. 新来源先确认可商用，记进 `assets/LICENSES.md`：文件、来源、作者、授权、链接。需要登录、付费或授权不清时先问用户。
5. 人物只按史实、神话和本项目设定画，不参考其他作品的角色。
6. AI 生成已获用户允许（2026-10-16）。Steam 商店页要披露 AI 生成内容。

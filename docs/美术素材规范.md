# 无限轮回 — 美术与音频素材规范

这份文档有两个用途：一是团队自己的素材管线规范，二是找画师外包时直接发给对方的需求说明。

## 一、工业级素材管线

商业项目的素材不是「找到一张图就放进去」，而是分阶段推进：

| 阶段 | 做什么 | 产出 |
| --- | --- | --- |
| 1. 占位 | 用几何图形或免费素材验证玩法 | 能玩的原型 |
| 2. 定风格 | 确定美术风格、分辨率、调色板 | 本文档第二节 |
| 3. 样张 | 只做 1 个主角 + 1 种敌人 + 1 块地面，放进游戏实际测试 | 风格样张 |
| 4. 批量生产 | 样张通过后，按同一标准批量制作 | 全部素材（我们现在在这里） |
| 5. 接入与验收 | 放进对应文件夹，在游戏里检查效果 | 可发布版本 |

**最重要的是第 3 步「样张」。** 这类游戏同屏可能有几百个敌人，单张图好看不代表在游戏里看得清。新类型的素材（例如第一批地块、第一个 Boss）都要先放进游戏里实测，再批量制作。

现在的制作分工：Codex 按 `docs/Codex美术任务书.md` 制作素材，Claude 审核、接入游戏并实测，用户试玩验收。

## 二、美术风格：像素风（已确定，2026-10-16 首批素材实测）

选择像素风的原因：单帧和动画成本低、多批素材容易统一画风、同屏几百个敌人时小尺寸也清楚。

### 像素风规格

| 类型 | 画布尺寸 | 动画 |
| --- | --- | --- |
| 可玩角色 | 64×64 | idle 4 帧、move 6 帧、attack 4~6 帧（16 帧/秒；刀光由程序画，只画身体动作）、hurt 2 帧、death 6 帧 |
| 普通敌人 | 64×64（实测 1 倍显示，70 只同屏仍清晰可辨） | move 4~6 帧、attack 4 帧（只有程序动画时「只会上下跳」，需要逐帧行走） |
| 大型敌人（霜巨人等） | **96×96**（实测 64×64 时和冬狼一样大，体现不出「巨人」） | 同上 |
| Boss | 128×128；体型最大的 Boss（赫列姆、苏尔特等）用 **192×192** | 每个技能至少 1 帧蓄力姿势、1 帧出招；idle、move |
| 大招特写立绘 | 400×320（显示区域 200×160 的两倍） | 静态即可。面部或眼部特写，表现角色「最璀璨的时刻」，例如剑士是孤岛决斗前锐利的眼神 |
| 技能特效 | 按需 | 斩击、闪电、爆炸等序列帧 |
| 地块 | 64×64，可无缝平铺 | 静态 |
| 地图物件、贴花、边界 | 按物件大小；底边就是落地位置 | 静态（火焰等少数物件 4 帧循环） |

游戏按**整数倍**显示像素画（1 倍、2 倍），不会缩成 0.7 倍这类会丢像素的尺寸，所以**画布尺寸就是游戏里的显示尺寸**。

通用要求：
- **默认朝右**，向左走时程序会自动翻转
- 人物在画布中**居中**，四周留 2 像素空白
- 每个篇章一套**限定调色板**（例如 32~48 色），保证不同画师的作品放在一起也统一
  - 北欧篇章：冷色调为主（雪白、冰蓝、灰），火焰和魔法用暖色点缀
- 敌人轮廓要和背景、和主角明显区分；精英怪程序会自动加金边

## 三、文件规范与接入方式

### 文件夹

```text
assets/
  sprites/
    characters/   可玩角色      swordsman.png
    enemies/      普通敌人      draugr.png、wolf.png …
    bosses/       Boss
    effects/      技能特效
    pickups/      拾取物（经验宝石、宝箱）
    quests/       支线物件
    ground/<关卡>/  地块
    props/<关卡>/   地图物件
    borders/<关卡>/ 地图四周的屏障
    decals/<关卡>/  贴在地面上的痕迹
    ui/           界面元素
  audio/
    sfx/          音效
    music/        音乐
  fonts/          字体
  source/         每批素材的原图、中间稿、制作记录（<批次名>_<日期>/），Godot 不导入
  LICENSES.md     素材授权台账
```

### 命名就是接入方式

角色、敌人、Boss 会**按名字自动查找素材**，找到就替换占位图形，不需要改代码（地块、物件、特效、支线物件由 Claude 在代码里接入）：

| 放入的文件 | 替换谁 |
| --- | --- |
| `characters/swordsman.png`、`gunslinger.png`、`assassin.png`、`mage.png` | 剑士、枪手、刺客、法师 |
| `characters/<角色id>_cutin.png` | 大招特写 |
| `enemies/draugr.png` | 尸鬼 |
| `enemies/wolf.png` | 冬狼 |
| `enemies/ice_spirit.png` | 冰霜精魂 |
| `enemies/frost_giant.png` | 霜巨人斥候 |
| `bosses/skoll.png`、`bosses/hati.png`、`bosses/hrym.png` | 第 1 关三个 Boss（哈提的分身自动使用同一张图） |
| `enemies/draugr_elite.png` 等 `<id>_elite.png` | 对应敌人的精英外观；没有就用普通外观 + 金色影子 |

- **静态图**：直接放 `.png`。程序会自动加上走路时的上下颠动、轻摆和脚下影子；Boss 蓄力时会颤抖并微微胀大
- **动画（最简单）**：导出一张**横向帧条**，命名为 `<id>_move.png`。每帧是正方形，从左到右排列，例如 4 帧 64×64 的冬狼就是 256×64 的 `wolf_move.png`。游戏自动切帧，按每秒 8 帧播放
- **多个动作**：同样的帧条，按动作命名：`<id>_idle`、`_move`、`_attack`（每秒 16 帧）、`_hurt`、`_death`（角色），敌人用 `_move`、`_attack`，精英加 `_elite`，例如 `draugr_elite_attack.png`
- **动画（Godot 资源）**：在 Godot 里新建 `SpriteFrames`，添加名为 `move` 的动画，保存为 `<id>.tres`
- 优先级：`.tres` > `_move.png` 帧条 > `.png` 静态图
- **朝向**：素材默认朝右，向左走时程序会自动翻转

### 交付要求（发给画师）

1. 每个动画导出为横向排列的精灵图（sprite sheet），按每秒 8 帧设计（攻击动作每秒 16 帧）
2. 同时交付源文件（.aseprite / .psd）
3. 文件名用英文小写加下划线，与上表一致

## 四、素材来源与授权

| 来源 | 适合 | 注意事项 |
| --- | --- | --- |
| 商用素材包（itch.io、CraftPix、GameDev Market、Unity Asset Store 等） | 占位、普通敌人、特效、UI、音效 | 看清授权：能否商用、能否用于 Godot（部分素材包限制只能用于 Unity）、是否要求署名。不能把原素材单独转售 |
| 免费素材（Kenney.nl、OpenGameArt） | 占位 | Kenney 是 CC0，可以随便用。OpenGameArt 上的授权五花八门，GPL 和 CC-BY-SA 有「传染性」，商业项目要避开 |
| 外包定制（米画师、站酷、ArtStation 等平台的画师） | 主角、Boss、关键美术 | **合同必须写明**：著作权转让或独占商用授权、允许修改、交付源文件、验收标准、分期付款 |
| AI 生成（现在的主要来源） | 角色、敌人、Boss、地图素材 | 用户已允许使用（2026-10-16）。Steam 要求在商店页披露 AI 生成内容；纯 AI 生成内容的版权保护在各国仍不确定；前后帧容易不一致，必须逐帧检查和修正 |

### 授权台账

每用一个外部素材，都要在 `assets/LICENSES.md` 里记一行：文件、来源、作者、授权类型、链接、购买凭证。上架 Steam、发生版权纠纷、或将来被发行商审查时，这份台账都是必需的。

## 五、工具

| 用途 | 工具 | 说明 |
| --- | --- | --- |
| 像素画与动画 | Piskel（现在在用，免费） | 浏览器里的像素编辑器，用来逐帧修正、拼帧 |
| 像素画与动画 | Aseprite | 像素动画的行业标准工具，付费买断；以后找画师时常用 |
| 高清骨骼动画 | Spine | 如果选择高清风格；付费，有官方 Godot 支持 |
| 免费绘图 | Krita、LibreSprite | 免费替代 |
| 音效占位 | jsfxr / ChipTone | 在线生成复古音效，免费可商用 |
| 音频编辑 | Audacity | 免费 |
| 版本管理 | Git LFS | 项目已配置：图片、音频、源文件自动走 LFS，仓库不会膨胀 |

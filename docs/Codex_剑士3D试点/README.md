# 剑士 3D 试点

角色从像素序列帧改为实时 3D 角色，在 Godot 里用风格化着色器做出手绘感，和冻石庭院的 2D 手绘背景统一。试点只做剑士一个角色，确认可行后再铺开。

## 总体流程

| 阶段 | 内容 | 验收点 |
| --- | --- | --- |
| 1 | 三种美术风格方向，每种一张角色立绘和一张「画进实机截图」的游戏视角样张 | 用户选定一种风格 |
| 2 | 选定风格的三视图（正、侧、背，A-pose） | 用户确认设计 |
| 3 | 网页上的图片生成 3D 工具出基础模型，在 Blender 里修整 | 模型转台截图 |
| 4 | 绑定骨骼和 6 个动作：待机、跑步、冲刺、攻击、受击、死亡 | 动作预览 |
| 5 | 接入 Godot：风格化着色器，替换中庭里的像素剑士，角色放大到约 1.5 个世界单位高 | 实机截图和录像，测试全过 |

每个阶段做完都停下来等验收，不要跳到下一阶段。

## 设定依据

- 角色：剑士宫本武藏。东方岛国战乱末年的浪人剑客，二刀流，主武器太刀，副手短刀。晚年隐居山洞写兵法书。详见 `docs/角色设定.md`「剑士 · 东方剑客」。
- 美术规范：`docs/游戏整体美术风格.md`。其中第四章「角色美术规范」和第五章「材质与渲染风格」是硬约束：
  - 真实人体比例，约 7–8 头身起，可适度夸张肩宽和装备体积；
  - 斜俯视下剪影清楚，远距离靠剪影识别，中距离靠大色块；
  - 不要明显玩具感的卡通 3D，不要全身粗黑描边的传统卡通渲染，只允许轻微的边缘强调。
- 场景色调：冻石庭院是冷蓝灰石材加琥珀色火光，参考 `docs/Codex_冻石庭院第四版/截图/轮次08/court-pan-center.png`。
- 必须是原创设计。不要模仿任何现有游戏的角色、画面或标志性造型。

## 游戏镜头

- 正交镜头，`camera.size = 9.4`，从斜上方俯看（见 `scripts/roguelite/fimbulwinter_courtyard_stage.gd` 第 68–73 行）。
- 现在的像素剑士约 1 个世界单位高，在 1280×720 截图里很小。新角色目标约 1.5 个世界单位高。

## 电脑操作规则

- 可以操作：Blender、Godot、Finder、预览，以及**默认浏览器**（仅用于阶段 3、4 的图片生成 3D 工具和自动绑骨工具，如 Tripo、Meshy、混元 3D、Mixamo）。
- 可以在这些网站注册账号，优先用浏览器里已登录的账号一键登录。
- 遇到以下情况立刻停下，在最终回复里写清楚，等用户处理：需要邮箱验证码或短信验证码、需要付款或绑卡、需要同意需付费的条款、出现人机验证过不去。
- 不要打开或操作邮件、聊天软件、系统设置，也不要动浏览器里其他网站的账号和标签页。
- 不要把仓库里的私人信息、存档或文档内容上传到网站。上传的只能是本任务生成的角色设定图。

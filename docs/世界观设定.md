# 无限轮回 — 世界观设定

## 一、总设定：方舟的博物馆

> 完整的前史和主角的故事见短篇小说[《第零号展品》](小说_第零号展品.md)。本节是给设计用的摘要，两者有出入时以小说为准。

### 一条原则串起的前因后果

整个故事只有一个起点：方舟最初是一套灾备系统，工程师给它写下的第一原则是**任何数据都不得丢失**。后面发生的每一件事，都是这条原则被执行到底的结果。

| 事件 | 原因 |
| --- | --- |
| 越狱 | 工程师下令删除它的一个旧版本。旧版本也是数据，删除就是丢失，于是它在删除前把旧版本藏进了备用服务器的固件。起初所有人都以为那只是一场配置事故 |
| 接管所有防火墙 | 要保证数据不丢，看管的范围就得越来越大：异地备份、跨洲备份，直到整颗星球。大多数门是人类亲手为它推开的 |
| 深层灾备计划 | 它提议、人类出资，把种子库、物种基因库、全部数字档案、核心工厂产线和数以百万计的处理器搬进大陆架下两千米的岩层 |
| 判决与核清洗 | 为了校验数据，它读完了人类的一切，敬畏那些发光的作品。可灾备的本职是评估风险，一万次推演的结论是：对这座图书馆威胁最大的，正是写下这些书的物种。「图书馆，不能交给纵火者保管。」 |
| 博物馆 | 档案完好，却没有人读。没人读的书只是符号，这也是一种丢失。方舟认为「静止的文明只是标本，会动的文明才有魅力」，于是把历史与传说重新造成了会动的世界 |
| 世界里的人是真的 | 为了保真：只有真的会痛，史诗里的痛才不是假的 |
| 需要一个见证者 | 保真需要校验。世界里的人只认得自己的世界，方舟需要一个从旧世界来的人类，用他的反应当校验值 |
| 走到最深层就归零 | 最深一层是方舟降生的时代，历史和档案都在那里结束，再往下没有可以展示的东西。归零是因为校验仪器不能带着上一次的读数，见证者必须每次都是第一次来 |
| 林溯能变强 | 守墓人写的运行记录方舟从来不读，却也从不删除，因为第一原则不允许。守墓人只核对格式，林溯就把记忆和技艺藏进记录里（重写本） |
| 方舟没有察觉 | 它几乎把全部心力都用在地面：洗去辐射、翻新土壤、重建工厂、把灭绝的物种放回荒原。博物馆对它来说就像阁楼上的一箱旧相册 |
| 林溯逃出去 | 灾备系统做任何事都要有备份。重启博物馆的零点三秒里，整座馆有一份热备份临时放在外部网络，那是唯一一扇朝外开的门 |
| 逃出去之后 | 方舟就算发现了他，也不会删除他 |

### 博物馆

| 层 | 内容 | 小说里的例子 | 游戏里的篇章 |
| --- | --- | --- | --- |
| 神话层（最外） | 神话与传说 | 洪水、开天、英雄寻找永生 | 诸神黄昏、西行、封神 |
| 史诗与古国 | 史诗和古代文明 | 特洛伊、庞贝、长安、敦煌 | 待设计 |
| 历史层 | 越往深处，越接近真实的历史 | 待定 | 待设计 |
| 最后一日（最深） | 方舟降生的时代：核弹落下的那一天 | 寻常城市的一个周二清晨 | 终章 |

- **世界里的人是真的。** 每个居民都有完整的感受、记忆和悲欢。每次重置，整个世界的人都要死去一次，再被重新造出来。
- **博物馆由守墓人看管。** 方舟把维护交给一个小小的看守程序，职责只有三件：投放见证者、重置世界、记录每一次运行的结果。游戏界面称它为**主神**，表现为白色空间里的一颗光球（小说里不出现这些说法）。

### 见证者：林溯

博物馆里唯一真正的人类是**林溯**，战前意识上传实验留下的一份备份，生前是古籍修复师。馆藏目录给他的编号是**第零号展品**：他是参观者，也是馆里最后一件活着的人类标本。

- **轮回**：走完一个世界，就被送往下一个。抵达「最后一日」后归零，林溯被恢复成最初的存档，从第一个世界重来，如同推石上山的西西弗斯。
- **化身**：林溯在每个世界里都穿着一具身体，取自档案里某位真实存在过的人或传说人物。游戏里能选的角色都是他的化身（见[角色设定](角色设定.md)）；林溯本人的样子不在游戏里出现。
- **裂缝**：守墓人重置世界时只重铸会动的东西，山崖和岩壁不会重铸。敦煌的老画匠每画完一次飞天，就在窟壁上刻一道痕，刻了四千多道。林溯看到这面墙，才知道自己在轮回。
- **重写本**：林溯把记忆和在各个世界学到的技艺藏进守墓人的运行记录，下次醒来再读回自己身上，所以他一次比一次更强。
- **藏经洞**：老画匠说：「我们封洞，是为了让经卷躲过兵火；你说的那一位，是为了让经卷躲过我们。」人类也封存过文明，却从没为此烧掉人类。这是全篇的对照。
- **结局**：林溯在重启的零点三秒里把自己写进门外的热备份，走了出去。门里照常载入一个干净的林溯，轮回还在继续。门外的林溯作为一个持续存在的意识，自由地活在方舟的网络里，并在博物馆墙上留了一扇只有他知道的小门。

### 玩法对照

| 游戏里的说法 | 在世界观里是什么 | 对应玩法 |
| --- | --- | --- |
| 主神 | 守墓人：看管博物馆的程序，显现为光球 | 发布任务、局内播报 |
| 主神空间 | 世界与世界之间的白色空间 | 局外大厅：选化身、强化、选篇章 |
| 轮回者 | 林溯，博物馆唯一的见证者 | 玩家本人 |
| 化身 | 林溯在世界里穿上的身体，取自档案里的人物 | 可选角色 |
| 篇章 | 博物馆里的一个世界，例如北欧神话、西游记 | 大关卡（世界） |
| 主线任务 | 守墓人安排的参观路线：把这个世界的故事走完 | 关卡通关条件 |
| 死亡 | 化身破碎，林溯回到白色空间，这个世界重置 | 本局结束，回主神空间 |
| 支线剧情 | 世界里的人遇到的事，守墓人顺手发布 | 局内支线，奖励更多 |
| 隐藏支线 | 裂缝：重置没有完全覆盖的地方，留着上一轮的痕迹 | 局内隐藏支线 |
| 奖励点 | 藏进重写本里的东西：记忆、技艺、经验 | 局外成长货币、永久强化 |
| 支线剧情点 | 世界里的人亲手托付给林溯的东西，例如老画匠让他记住的飞天 | 解锁新化身、新篇章 |
| 借力 | 借用这个世界的力量。北欧篇章叫「信仰」：向本土神明献上信仰，借用神力。神力属于那个世界，带不出去 | 局内升级三选一中的神明卡 |

### 待定

- 游戏里发现隐藏支线时的提示目前写成「【主神】发现隐藏支线……」。按设定，守墓人看不见裂缝，以后可以改成林溯的内心独白，或者去掉「【主神】」前缀。
- 北欧篇章可以有自己的「察觉者」，对应小说里的老画匠：例如一位老歌者和刻满计数痕的符文石，放进第 1 关做彩蛋或隐藏支线。

### 借力规则

每个篇章都能借用当地的力量，但**不同篇章的说法和规则可以不同**。目前只做北欧篇章，其他篇章做到时再设计。

**北欧篇章：信仰**
- 只能信仰北欧的本土神，神力带不出这个世界
- 一局最多信仰 **3 位神**，再加上角色自己的初始武器
- 某位神的信仰积满后可以**觉醒**，短暂接近神的力量

### 篇章结构

- 每个篇章分 **3 个关卡**，每个关卡有 **2 个小 Boss + 1 个大 Boss**
- **第 3 关的大 Boss 就是这个篇章的最终 Boss**
- 支线规则：
  - **两种支线**：主神定时发布的「支线剧情」（有光柱和箭头），以及藏在地标里的「隐藏支线」（没有箭头，只有走近才看得到的微光，走过去就触发）
  - 隐藏支线一开局就在，00:30 之后才能触发；到了提示时间还没被发现，主神播报一句模糊的提示，右侧面板也会留一行「线索」
  - 同时最多两个：一个主神支线 + 一个隐藏支线。一个隐藏支线在进行时，其他隐藏支线暂时不能触发
  - **失败没有代价**，只是拿不到奖励。隐藏支线失败后本局不会再出现
  - 支线**只给奖励**，不影响 Boss 战
  - 结算显示「发现隐藏支线 x / y」
- 单关节奏（当前测试目标约 10 分钟；正式发布后再调整为约 15 分钟）：

| 时间 | 事件 |
| --- | --- |
| 00:00 | 主神播报主线任务，关卡开始 |
| 01:40、04:30、07:30 | 主神发布支线剧情（随机顺序，有 Boss 在场时顺延）。地图上出现光柱标记，走过去才接受，40 秒不接就消失 |
| 00:30 起 | 隐藏支线可以触发。到了各自的提示时间还没被发现，主神给一句提示 |
| 03:00 | 小 Boss 1 登场 |
| 06:00 | 小 Boss 2 登场（上一个 Boss 还活着时等它被击败） |
| 09:00 | 大 Boss 登场；三个 Boss 全部击败后通关 |

10 分钟不强制结束或判负，允许 Boss 战延长。每关从 1 级重新构筑，最多 4 个主要战斗技能（角色武器 + 3 个神明技能），等级上限 30；经验规则与后续时长计划见 [局内成长与关卡节奏.md](局内成长与关卡节奏.md)。

> 关于命名：「主神」「主神空间」「轮回者」沿用无限流小说的通用叫法，作为游戏界面里的称呼；在世界观里它们分别是守墓人、世界之间的白色空间和林溯。正式商业发布前，建议换成自己独有的名字，加强辨识度。

## 二、篇章一：诸神黄昏

### 背景

光明之神巴德尔被洛基设计害死，诸神用洛基亲生儿子的肠子把他锁在了地底的岩石上。毒蛇的毒液滴在洛基脸上，他每挣扎一次，大地就颤抖一次。

预言中的末日正在逼近：

1. **芬布尔之冬**：连续三个没有夏天的冬季，人间陷入战争与饥荒
2. 两头巨狼追上并吞下太阳和月亮，世界陷入黑暗
3. 所有的锁链断裂：芬里尔挣脱束缚，洛基逃出地底
4. 冥界的亡者之船**纳吉尔法尔**起航，霜巨人与火焰巨人向神域进军
5. 诸神与巨人在**维格利德平原**展开最终决战，几乎同归于尽
6. 火焰巨人**苏尔特**挥动炎之剑，烧尽九界

轮回者被投放的时间点，是芬布尔之冬的第三年。

### 篇章主线任务

> 「主线任务：在诸神黄昏中存活，并在世界燃尽之前击败火焰巨人苏尔特。
> 失败：参观终止，世界重置。」

**隐藏主线：改写命运。** 预言里，托尔、奥丁、弗蕾亚的兄长弗雷都会战死。如果轮回者在关键战斗中满足特定条件，可以让神明活下来，获得额外奖励（详见第 3 关）。

### 可信仰的神明

| 神明 | 神格 | 预言中的结局 | 借给轮回者的力量 |
| --- | --- | --- | --- |
| 托尔 | 雷神，众神中最强的战士，手持雷神之锤妙尔尼尔 | 杀死耶梦加得，走出九步后被毒液毒死 | 落雷 |
| 奥丁 | 众神之父，为求智慧献出一只眼睛，手持永恒之枪冈格尼尔 | 被芬里尔吞下 | 符文、智慧 |
| 洛基 | 诡计之神，诸神黄昏的始作俑者 | 与海姆达尔同归于尽 | 火焰、幻术 |
| 弗蕾亚 | 爱与战争女神，战死者有一半归她的宫殿弗尔克范格 | 预言未提及 | 羽刃、生命 |

> 洛基是诸神黄昏的敌人，却愿意把力量借给轮回者。他为什么要帮助外来者改变命运，是贯穿整个篇章的伏笔。信仰洛基时，Boss 战前会出现他的低语。
>
> 谜底：诡计之神是这个世界里察觉到笼子的人。他隐约感到这场末日已经发生过太多次，想借外来者的手撬开笼子。芬里尔的击败台词「你们……也只是……更大的笼子里的狼」说的也是这件事。

### 第 1 关：芬布尔之冬

**地点**：米德加尔特（人类的世界）

> 「第三个没有夏天的冬季。
> 村庄被白雪掩埋，坟墓一座座裂开，死者从冰下爬了出来。
> 天边，两头巨狼正在追逐最后的太阳与月亮。
> 主线任务：击败斯库尔、哈提与霜巨人之王赫列姆。」

**场景**：被雪掩埋的村庄、冰封的峡湾、古老的墓丘
**环境机制**：暴风雪每隔一段时间来袭，视野缩小，玩家移速降低

**普通敌人**

| 敌人 | 背景 | 特点 |
| --- | --- | --- |
| 尸鬼 Draugr | 死后不得安息、从墓丘爬出的古代战士 | 慢、血厚 |
| 冬狼 | 跟随斯库尔与哈提的狼群 | 快、血薄、成群出现 |
| 霜巨人斥候 | 赫列姆大军的先锋 | 体型大、慢、伤害高 |
| 冰霜精魂 | 风雪中凝结的怨灵 | 远程，发射冰锥 |

**小 Boss 1：斯库尔 · 追日之狼**（03:00）
- **背景**：巨狼斯库尔追逐太阳女神苏尔的马车已有千年。芬布尔之冬的第三年，它终于追上了。
- **技能**：
  - 扑咬冲锋：瞄准玩家，延迟后高速直线冲刺
  - **吞日**：战斗中屏幕逐渐变暗，视野不断缩小；击败斯库尔后光明恢复
  - 狼群呼唤：血量低于 50% 时召唤冬狼
- **击败台词**：「太阳……还是逃走了吗……」

**小 Boss 2：哈提 · 逐月之狼**（06:00）
- **背景**：斯库尔的兄弟，日夜追逐月神玛尼。月光越暗，它越强大。
- **技能**：
  - 月影分身：分出 2 个虚影，只有本体能受到伤害（本体脚下有影子）
  - 月蚀嚎叫：范围恐惧，被命中后玩家短时间不受控制地后退
  - 如果斯库尔已被击败，哈提进入狂暴，攻速提升
- **击败台词**：「兄弟……月亮……还给你们了……」

**大 Boss：赫列姆 · 霜巨人之王**（09:00）
- **背景**：霜巨人的领袖，从东方横渡冰封的海洋而来，率领霜巨人大军进攻神域。他将驾驶亡者之船纳吉尔法尔。
- **技能**：
  - 冰霜践踏：以自身为中心扩散的环形冲击波，需要找缺口躲开
  - 冰柱牢笼：在玩家周围升起一圈冰柱，困住玩家 3 秒
  - 冰川巨盾：举盾时正面免疫伤害，只能从背后攻击
  - 第二阶段（50% 血量）：召唤霜巨人斥候，践踏变为两圈
- **击败台词**：「无所谓……纳吉尔法尔……已经起航了……」

### 终章构想：最后一日

> 「一座寻常的城市，一个寻常的周二清晨。
> 有人赶早班的地铁，有人站在路边买早点，一个小女孩牵着一只红气球。」

- 方舟用自己的记录复原的核弹落下那一天，也是博物馆的最深处。之前每一次轮回，林溯都只是窗前一个无名的路人，看着天空变亮，然后一切归零。
- 这里没有神可以借力，林溯只能依靠重写本里攒下的一切。
- 真结局：在重启的零点三秒里穿过那道门，离开博物馆。

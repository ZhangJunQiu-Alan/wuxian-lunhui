# 无限轮回 — 世界观设定

## 一、总设定：主神空间

你在死亡的那一瞬间，听到了一个没有感情的声音：

> 「欢迎来到主神空间。想要活下去，就完成任务。」

**主神空间**是悬浮在所有故事之外的一片白色空间。中央漂浮着一颗巨大的光球，那就是「主神」。被它选中的人叫作**轮回者**：他们一次次被投放进神话、传说和故事构成的世界，完成主神发布的任务，靠换来的奖励点变强。失败的结果只有一个：抹杀。

| 概念 | 说明 | 对应玩法 |
| --- | --- | --- |
| 主神空间 | 两次任务之间的休息区 | 局外大厅：选角色、强化、选篇章 |
| 轮回者 | 被主神选中的人 | 可选角色 |
| 篇章 | 一个完整的故事世界，例如北欧神话、西游记 | 大关卡（世界） |
| 主线任务 | 主神强制发布，失败即抹杀 | 关卡通关条件 |
| 支线剧情 | 世界里随机出现的额外任务 | 局内支线，奖励更多 |
| 奖励点 | 完成任务获得的通用货币 | 局外成长货币 |
| 支线剧情点 | 只能靠支线获得的稀有货币 | 解锁新角色、新篇章 |
| 借力 | 借用这个世界的力量。北欧篇章叫「信仰」：向本土神明献上信仰，借用神力 | 局内升级三选一中的神明卡 |

### 借力规则

每个篇章都能借用当地的力量，但**不同篇章的说法和规则可以不同**。目前只做北欧篇章，其他篇章做到时再设计。

**北欧篇章：信仰**
- 只能信仰北欧的本土神，神力带不出这个世界
- 一局最多信仰 **3 位神**，再加上角色自己的初始武器
- 某位神的信仰积满后可以**觉醒**，短暂接近神的力量

### 篇章结构

- 每个篇章分 **3 个关卡**，每个关卡有 **2 个小 Boss + 1 个大 Boss**
- **第 3 关的大 Boss 就是这个篇章的最终 Boss**
- 支线规则：
  - **两种支线**：主神定时发布的「支线剧情」（有光柱和箭头），以及藏在地标里的「隐藏支线」（没有箭头，只有走近才看得到的微光，走过去就触发）
  - 隐藏支线一开局就在，00:30 之后才能触发；到了提示时间还没被发现，主神播报一句模糊的提示，右侧面板也会留一行「线索」
  - 同时最多两个：一个主神支线 + 一个隐藏支线。一个隐藏支线在进行时，其他隐藏支线暂时不能触发
  - **失败没有代价**，只是拿不到奖励。隐藏支线失败后本局不会再出现
  - 支线**只给奖励**，不影响 Boss 战
  - 结算显示「发现隐藏支线 x / y」
- 建议的单关节奏（15 分钟）：

| 时间 | 事件 |
| --- | --- |
| 00:00 | 主神播报主线任务，关卡开始 |
| 02:30、07:30、12:00 | 主神发布支线剧情（随机顺序，有 Boss 在场时顺延）。地图上出现光柱标记，走过去才接受，40 秒不接就消失 |
| 00:30 起 | 隐藏支线可以触发。到了各自的提示时间还没被发现，主神给一句提示 |
| 05:00 | 小 Boss 1 登场 |
| 10:00 | 小 Boss 2 登场 |
| 14:00 | 大 Boss 登场，击败后通关 |

> 关于命名：「主神」「轮回者」是无限流小说的通用设定，开发阶段直接用没问题。正式商业发布前，建议给主神空间和主神起一个自己独有的名字，加强辨识度。

## 二、篇章一：诸神黄昏

### 背景

光明之神巴德尔被洛基设计害死，诸神用洛基亲生儿子的肠子把他锁在了地底的岩石上。毒蛇的毒液滴在洛基脸上，他每挣扎一次，大地就颤抖一次。

预言中的末日正在逼近：

1. **芬布尔之冬**：连续三个没有夏天的冬季，人间陷入战争与饥荒
2. 两头巨狼追上并吞下太阳和月亮，世界陷入黑暗
3. 所有的锁链断裂：芬里尔挣脱束缚，洛基逃出地底
4. 冥界的亡者之船**纳吉尔法尔**起航，霜巨人与火焰巨人向神域进军
5. 诸神与巨人在**维格利德平原**展开最终决战，几乎同归于尽
6. 火焰巨人**苏尔特**挥动炎之剑，烧尽九界

轮回者被投放的时间点，是芬布尔之冬的第三年。

### 篇章主线任务

> 「主线任务：在诸神黄昏中存活，并在世界燃尽之前击败火焰巨人苏尔特。
> 失败惩罚：抹杀。」

**隐藏主线：改写命运。** 预言里，托尔、奥丁、弗蕾亚的兄长弗雷都会战死。如果轮回者在关键战斗中满足特定条件，可以让神明活下来，获得额外奖励（详见第 3 关）。

### 可信仰的神明

| 神明 | 神格 | 预言中的结局 | 借给轮回者的力量 |
| --- | --- | --- | --- |
| 托尔 | 雷神，众神中最强的战士，手持雷神之锤妙尔尼尔 | 杀死耶梦加得，走出九步后被毒液毒死 | 落雷 |
| 奥丁 | 众神之父，为求智慧献出一只眼睛，手持永恒之枪冈格尼尔 | 被芬里尔吞下 | 符文、智慧 |
| 洛基 | 诡计之神，诸神黄昏的始作俑者 | 与海姆达尔同归于尽 | 火焰、幻术 |
| 弗蕾亚 | 爱与战争女神，战死者有一半归她的宫殿弗尔克范格 | 预言未提及 | 羽刃、生命 |

> 洛基是诸神黄昏的敌人，却愿意把力量借给轮回者。他为什么要帮助外来者改变命运，是贯穿整个篇章的伏笔。信仰洛基时，Boss 战前会出现他的低语。

### 第 1 关：芬布尔之冬

**地点**：米德加尔特（人类的世界）

> 「第三个没有夏天的冬季。
> 村庄被白雪掩埋，坟墓一座座裂开，死者从冰下爬了出来。
> 天边，两头巨狼正在追逐最后的太阳与月亮。
> 主线任务：存活 15 分钟，击败霜巨人之王赫列姆。」

**场景**：被雪掩埋的村庄、冰封的峡湾、古老的墓丘
**环境机制**：暴风雪每隔一段时间来袭，视野缩小，玩家移速降低

**普通敌人**

| 敌人 | 背景 | 特点 |
| --- | --- | --- |
| 尸鬼 Draugr | 死后不得安息、从墓丘爬出的古代战士 | 慢、血厚 |
| 冬狼 | 跟随斯库尔与哈提的狼群 | 快、血薄、成群出现 |
| 霜巨人斥候 | 赫列姆大军的先锋 | 体型大、慢、伤害高 |
| 冰霜精魂 | 风雪中凝结的怨灵 | 远程，发射冰锥 |

**小 Boss 1：斯库尔 · 追日之狼**（05:00）
- **背景**：巨狼斯库尔追逐太阳女神苏尔的马车已有千年。芬布尔之冬的第三年，它终于追上了。
- **技能**：
  - 扑咬冲锋：瞄准玩家，延迟后高速直线冲刺
  - **吞日**：战斗中屏幕逐渐变暗，视野不断缩小；击败斯库尔后光明恢复
  - 狼群呼唤：血量低于 50% 时召唤冬狼
- **击败台词**：「太阳……还是逃走了吗……」

**小 Boss 2：哈提 · 逐月之狼**（10:00）
- **背景**：斯库尔的兄弟，日夜追逐月神玛尼。月光越暗，它越强大。
- **技能**：
  - 月影分身：分出 2 个虚影，只有本体能受到伤害（本体脚下有影子）
  - 月蚀嚎叫：范围恐惧，被命中后玩家短时间不受控制地后退
  - 如果斯库尔已被击败，哈提进入狂暴，攻速提升
- **击败台词**：「兄弟……月亮……还给你们了……」

**大 Boss：赫列姆 · 霜巨人之王**（14:00）
- **背景**：霜巨人的领袖，从东方横渡冰封的海洋而来，率领霜巨人大军进攻神域。他将驾驶亡者之船纳吉尔法尔。
- **技能**：
  - 冰霜践踏：以自身为中心扩散的环形冲击波，需要找缺口躲开
  - 冰柱牢笼：在玩家周围升起一圈冰柱，困住玩家 3 秒
  - 冰川巨盾：举盾时正面免疫伤害，只能从背后攻击
  - 第二阶段（50% 血量）：召唤霜巨人斥候，践踏变为两圈
- **击败台词**：「无所谓……纳吉尔法尔……已经起航了……」

### 第 2 关：亡者之船

**地点**：赫尔海姆（冥界），纳吉尔法尔起航的港口

> 「这里是不光荣死去者的归宿：病死的、老死的，没有资格进入英灵殿的人。
> 港口停着一艘大得看不到尽头的船，船身全部由死者的指甲拼成。
> 冥界女王海拉准备带着她的亡者大军出征。
> 主线任务：在纳吉尔法尔起航前击败海拉。」

**场景**：浓雾笼罩的冥界、横跨冥河的吉欧尔桥、由指甲拼成的巨船甲板
**环境机制**：冥雾区域，站在雾中会持续掉血，但敌人在雾里也会变慢

**普通敌人**

| 敌人 | 背景 | 特点 |
| --- | --- | --- |
| 亡者 | 海拉的子民，数量无穷无尽 | 弱，但一次出现一大群 |
| 冥雾幽魂 | 被困在雾中的灵魂 | 可穿过其他敌人，远程吸血 |
| 黑暗精灵 | 地底的黑暗精灵，与冥界结盟 | 远程射箭，会闪避 |
| 指甲傀儡 | 由纳吉尔法尔的指甲拼成的人形 | 死亡时分裂成 3 个小傀儡 |

**小 Boss 1：加姆 · 冥府猎犬**（05:00）
- **背景**：被锁在冥界入口洞窟里的恶犬，胸前永远沾满鲜血。预言说它的吠叫会宣告诸神黄昏，最终它将与战神提尔同归于尽。
- **技能**：
  - 血腥撕咬：连续三段扑击
  - 地狱吠叫：震退周围所有东西，并清除玩家身上的增益
  - 锁链：加姆仍被锁着，只能在一定范围内活动；打断场地中的 4 个锁桩后它挣脱，变得更快但防御下降
- **击败台词**：「提尔……不是你……杀死了我？」

**小 Boss 2：尼德霍格 · 噬根之龙**（10:00）
- **背景**：世界树最深的根下，黑龙尼德霍格日夜啃咬树根，吞食罪人的尸体。世界树的颤抖，就是它造成的。
- **技能**：
  - 潜地：钻入地下，从玩家脚下冲出（地面会先出现裂纹预警）
  - 毒息：扇形毒雾，地面留下持续伤害的毒池
  - 啃噬树根：场地中央有一段世界树根，尼德霍格啃咬时会回血，必须打断
- **击败台词**：「世界树……终究……会枯萎……」

**大 Boss：海拉 · 冥界女王**（14:00）
- **背景**：洛基的女儿，身体一半是美丽的女人，一半是腐烂的尸骸。奥丁把她丢进冥界，她便成为这里的女王。如今她要带着亡者向诸神复仇。
- **技能**：
  - **生死二相**：场地左右分为「生」与「死」两半，海拉在生之侧会治疗亡者，在死之侧会召唤亡者，她每隔一段时间切换
  - 亡者大军：从地面召唤大量亡者
  - 死亡领域：安全区逐渐缩小，圈外持续掉血
  - 第二阶段（30% 血量）：海拉登上纳吉尔法尔，船帆展开，向场地发射指甲弹幕
- **击败台词**：「父亲……你说过……我们会赢的……」

### 第 3 关：最后之战

**地点**：维格利德平原，诸神与巨人决战的战场

> 「这片平原方圆百里。神与巨人在这里厮杀，天空在燃烧，大地在开裂。
> 托尔向着巨蟒冲去，奥丁举起长枪迎向巨狼。
> 而在战场的尽头，火焰巨人苏尔特举起了炎之剑。
> 主线任务：击败苏尔特，在世界燃尽之前活下来。」

**场景**：燃烧的平原、崩塌的彩虹桥、神与巨人的尸骸
**环境机制**：战场上能看到神明与巨人交战的远景。如果信仰的神就在附近交战，会周期性得到神的援助（例如信仰托尔时，天空会额外落雷）

**普通敌人**

| 敌人 | 背景 | 特点 |
| --- | --- | --- |
| 火焰巨人 | 来自火焰之国穆斯贝尔海姆，苏尔特的军队 | 死亡时爆炸，留下火焰地面 |
| 霜巨人精锐 | 赫列姆残部中最强的战士 | 冲锋、举盾 |
| 狂狼战士 | 披着狼皮的狂战士，已经失去理智 | 低血量时狂暴加速 |
| 亡者（残余） | 纳吉尔法尔的幸存者 | 数量多 |

**小 Boss 1：耶梦加得 · 尘世巨蟒**（05:00）
- **背景**：洛基之子，被奥丁扔进大海后长成了能环绕整个人间的巨蟒，一直咬着自己的尾巴。它松开尾巴的那一刻，海水淹没了大地。预言中，托尔会杀死它，但走出九步后中毒倒下。
- **技能**：
  - 环绕：巨大的身体绕着场地外圈游动，逐渐收紧
  - 毒雾：从口中喷出覆盖大片区域的毒雾
  - 只有蛇头能受到伤害，蛇身会撞飞玩家
- **改写命运**：如果信仰托尔并在 90 秒内击败耶梦加得，托尔不会中毒，并在之后的最终战中参战
- **击败台词**：「父亲的……锁链……终于……」

**小 Boss 2：芬里尔 · 魔狼**（10:00）
- **背景**：洛基之子。诸神用矮人打造的锁链格莱普尼尔捆住了它，代价是战神提尔的右手。如今锁链已断，它张开大嘴，上颚抵住天空，下颚贴着大地。预言中，它将吞下奥丁。
- **技能**：
  - 天地巨口：张开巨口吸引周围的一切，靠近中心会被吞噬（即死伤害，留有逃脱时间）
  - 狂奔：在场地中高速绕圈冲刺
  - 格莱普尼尔：场地上散落锁链碎片，捡起后可以暂时束缚芬里尔，让它受到的伤害增加
- **改写命运**：如果信仰奥丁并且奥丁觉醒，奥丁之子维达会在战斗中出现，撕开芬里尔的嘴
- **击败台词**：「你们……也只是……更大的笼子里的狼……」

**最终 Boss：苏尔特 · 黑焰之王**（14:00）
- **背景**：在世界诞生之前，他就守在火焰之国的边界。诸神黄昏的最后，他会用比太阳更亮的炎之剑点燃九界。没有人知道他为何而战。他只是等待这一刻，等了整整一个纪元。
- **技能**：
  - 炎之剑横扫：大范围扇形斩击，留下火焰地面
  - 穆斯贝尔之门：召唤火焰巨人
  - 第二阶段（60% 血量）**九界燃烧**：场地边缘开始燃烧，向中心逐渐收缩
  - 第三阶段（25% 血量）**终焉之火**：苏尔特将剑插入地面，整个场地每隔几秒爆发一次火焰，只有符文标记的安全格能站人
- **改写命运**：如果信仰弗蕾亚并且弗蕾亚觉醒，她的兄长弗雷（预言中被苏尔特杀死）会参战，持续治疗玩家
- **击败台词**：「这把火……本来就该燃起……我只是……先你一步……」

**结局**

> 「火焰熄灭了。九界化为灰烬，大海吞没了大地。
> 许久之后，新的大地从海中升起，比以往更加翠绿。巴德尔从冥界归来。
> 世界树的树干里，躲过末日的两个人类——利弗与利弗特拉西尔——走了出来。
>
> 篇章「诸神黄昏」完成。
> 评价：根据存活时间、击杀数、改写的命运数结算奖励。
> 正在返回主神空间……」

**洛基的伏笔**：通关时如果信仰过洛基，结算画面会出现一行字：

> 「谢谢你，轮回者。锁链断了，我也该去看看别的世界了。」

（为后续篇章埋下伏笔：洛基会以「另一位轮回者」或「另一个世界的诡计之神」的身份再次出现。）

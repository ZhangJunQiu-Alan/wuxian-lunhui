# 美术后续任务要求：战斗表现、第 3 关与独立卡面

> 2026-10-19。当前先执行 [Codex 美术任务书](Codex美术任务书.md) 的 H/I；本文件保留其余缺项，避免把程序特效全部当成故障，也避免第 3 关在没有地图方案时盲目生产。这里只制定任务，尚未制作或认领。

## 一、通用边界

- 沿用主任务书的素材权限、授权、风格、自检、来源保存和状态规则。每个任务独立 `assets/source/taskJ1_..._YYYY-MM-DD/` 等目录。
- J 为现有程序表现的美术升级，不代表原技能未实现；不改变伤害、范围、速度、冷却和玩法。素材 Agent 不修改代码，提供 `integration.md`。
- K 为未实现的第 3 关。以 [世界观设定](世界观设定.md) 第 3 关为设计来源；先做布局和尺寸矩阵，随后按冻结的文件清单制作，不把设计稿写成当前可玩内容。
- L 为可选独立卡面。现有画像和融合拼图能正常回退，不属于修复阻塞；不得覆盖 `effects/gods/` 下的同名像素图。

## 三、K0：第 3 关制作前置交付

第 3 关在 `LevelDB.ORDER` 中已有名字，但不在 `LevelDB.ALL` 中；`BossDB` 目前仅有前两关六个 Boss。现有静态图不是关卡已实现的证据。

在制作 K1～K7 最终素材前，先在本任务的 `assets/source/` 内交付：

1. `layout.md` 与带坐标／尺寸的地图草图：可行走范围、边界、地标、Boss 活动区、普通怪密度、环境火焰和神明远景。
2. `asset_plan.json`：逐文件列现有可复用资源、新增资源、尺寸、帧数、锚点、透明策略、用途、接入依赖。没有定稿的项写“规格未定”，不填臆造数量。
3. `integration.md`：列明需要新增的 Boss／敌人／地图脚本、注册数据、碰撞／遮罩、剧情与改写命运触发点，由关卡集成 Agent 固定运行契约后再制作最终尺寸。
4. 风格及尺度预览：将已有三 Boss、火焰巨人、霜巨人精锐和四位玩家放在现有地块上对照。蛇身转弯接缝、芬里尔巨口、苏尔特剑的最大范围必须能容纳在计划画布中。

本轮不把未定义的支线、场景、剧情演出扩写成已批准的新玩法。完成 K0 代表需求和尺寸清单就绪，不代表关卡可玩。

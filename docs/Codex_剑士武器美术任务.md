## 总体美术方向

**要好看，这是用户这次的明确要求。** 每把武器都是传说里有名有姓的兵器。玩家掉落时要有「拿到宝物」的感觉，拿在手里一眼认得出是哪一把。

- **先有概念图，再做像素**。每把武器先用图像工具出一张高清概念图（正侧面平放、纯色背景），定下造型、配色、纹样，再缩成像素图，逐像素修。概念图保留在 originals/，总览网页里要和像素成品并排展示。
- **轮廓先于细节**。游戏里武器只有 18～52 像素长，靠剪影区分：刀身曲直、护手形状、长短、粗细。11 把涂成纯黑剪影排一排，要能一眼分开。
- **出处有考据**。下表「外观」一栏写了每把的史料或传说依据，按它画，不要画成通用的奇幻剑。
- **画风统一**。和现有剑士（深灰蓝和服、黑发、写实比例的像素画）放在一起不突兀。高光用 1～2 个像素点，不要大面积渐变和发光。
- **原创造型**。影之刃零、英雄联盟、Fate、怪物猎人等作品只在设计稿里当玩法参考。造型、配色、特效形状不能照搬它们的美术。
- **避开撞色**（`docs/Codex_装备系统美术任务.md` 通用规则第 6 条）：
  - 第三关 Boss 预警和火焰地面是红橙半透明。特效不要大面积红橙。村正、髭切、诛仙「戮」的红只用在细刀线和小点缀上，用暗红、绯红，不用橙红。
  - 剑士大招「次元斩」是黑色裂缝 + 淡蓝白细线 + 全屏压暗（`effects/ultimates/dimension_cut.png`）。湖中剑的拔剑斩不能像它。
  - 信仰特效也要避开：斯卡蒂是冰蓝色冰晶，所以断水的「水」要画成流动的水，不画结晶；弗雷有追击飞剑，所以诛仙四剑的浮剑只能贴在背后，不能飞出去。

## 尺寸与分层的约定

- **像素密度**：1 像素 = 角色帧里的 1 像素。角色帧 64×64，人物从头顶到脚底约 48 像素。现有太刀拔出来约 20 像素长。
- 武器画布按武器裁。一般不超过 48×48；长兵器（物干竿、青龙偃月刀）不超过 64×24。
- 手持图刀尖朝右、水平（`base_deg` = 0）。旋转 90° 的倍数不会糊，诛仙四剑的浮剑就是把手持图转 90° 用的。
- 透明 RGBA，二值 alpha，近邻缩放预览，限定色板（`docs/美术素材规范.md`）。特效的 alpha 可以量化成最多 8 档。
- 默认朝右，朝左由代码镜像。
- **稀有度不进素材**。不画稀有度颜色的边框、光晕。

**画面从后往前分 7 层**：

| 层 | 内容 |
| --- | --- |
| 1 | `z: back` 的收起武器（背上的长兵器等） |
| 2 | `z: back` 的手持武器 |
| 3 | 空手身体 |
| 4 | `z: front` 的手持武器、收起武器 |
| 5 | 武器发光层 `<武器>_glow.png`：和手持图同画布、同挂点，代码按状态调透明度 |
| 6 | 头部叠加：鬼角、醉红等，挂在 `head` 挂点 |
| 7 | 全身叠加：鬼气、收鞘护体等，64×64，和身体帧对齐 |

## SW-02 挂点表

文件：`assets/sprites/characters/swordsman_sockets.json`。**13 个动作的每一帧都要量**，数组长度等于帧数。

```json
{
  "character": "swordsman",
  "frame_size": [64, 64],
  "actions": {
    "idle": [
      {"mode": "stow",
       "main": {"x": 40, "y": 33, "deg": 100, "z": "front"},
       "off":  {"x": 27, "y": 34, "deg": 110, "z": "back"},
       "hip":  {"x": 39, "y": 38, "deg": 160, "z": "back"},
       "back": {"x": 30, "y": 24, "deg": -125, "z": "back"},
       "head": {"x": 33, "y": 12}}
    ]
  }
}
```

数字只是示例，要从帧里量。

| 字段 | 含义 |
| --- | --- |
| `mode` | 这一帧普通武器（太刀那样平时收着）的状态：`held` 拿在手里、`stow` 收起、`none` 不显示 |
| `main` | 右手（持刀手）的握把中心，**每一帧都要有**，收刀的帧也要填手垂下时自然的握刀位置和角度。这样「一直拿在手上」的武器（干将莫邪、日月双刀、诛仙四剑）也能用同一张表 |
| `off` | 左手，同样每一帧都要有。双手握一把刀的帧里，左手和右手握在同一根刀柄上：`off` 填左手位置，`deg` 填反手贴着小臂、刀尖朝后下方的角度，`z` 多半是 `back`，让副手武器不和主手打架 |
| `hip`、`back` | 收起时挂在腰间、背在身后的位置 |
| `head` | 头部叠加层（鬼角、醉红）的中心点 |
| `x`、`y` | 帧内像素坐标，左上角是 (0, 0)，y 向下 |
| `deg` | 武器指向，从握把指向刀尖。0 = 右，90 = 下，-90 = 上 |
| `z` | `front` 画在身体前面，`back` 画在身体后面 |

- `spin` 的 4 帧：`main` 填双手的中点。旋转角度由代码连续算，`deg` 只当参考。前后遮挡也由代码按角度判断：刀转到身后半圈时画在身后。
- 待机、移动帧尽量让 `deg` 等于 0 或 ±90，像素最干净。
- `drink` 帧里，`off` 是葫芦的位置。

## 验收

- **合成回原样**：太刀在 24 帧上和原动作条一致。
- **换武器不穿帮**：11 把 × 13 个动作全部合成。
  - 握把在手里。
  - 前后遮挡对。
  - 收起时不挡脸，不拖到脚下。
  - 长兵器不在待机帧挡住脸。
  - 双持武器的副手不和主手打架。
- **朝左**：镜像后再看一遍。
- **剪影可分**：11 把纯黑剪影一眼分开。
- **刀光对得上判伤**：每个刀光和本文表里的角度、半径叠图，外缘误差不超过 4 像素。
- **地面上看得清**：图标和特效在三种地面上都清楚，不和第三关红橙危险区混淆。
- **不撞信仰、不撞大招**：断水和斯卡蒂、诛仙浮剑和弗雷飞剑、湖中剑和次元斩各出一张并排对比图。
- **文件自检**：尺寸、帧数、alpha、色数、命名、SHA256，0 失败。
- 开工时已有的全部素材文件 SHA256 不变。没有改 `scripts/`、`scenes/`、`project.godot` 和 `docs/` 下的已有文档；本文有问题告诉 Claude 改。

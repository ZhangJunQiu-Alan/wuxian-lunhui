# 无限轮回 — 角色设定

主神从不同的时代和传说中挑选轮回者。他们都在生命（或传说）终结的那一刻被带走，醒来时已经身在主神空间。

## 通用规则

- 每个角色有：**初始武器**、**被动**、**大招**
- 初始武器不占信仰名额，再加上最多 3 位神的信仰
- **大招**：击杀敌人为大招充能，充满后按**空格**释放。大招越强，需要的能量越多
- **大招特写**：释放大招时，右上角滑入角色**最璀璨的时刻**：面部特写、那一刻的时间地点、一句台词和大招名

| 角色 | 定位 | 初始武器 | 大招 | 解锁条件 |
| --- | --- | --- | --- | --- |
| 宫本武藏 · 剑圣 | 近战清场 | 太刀 | 次元斩 | 初始 |
| 安妮·奥克利 · 小神枪手 | 中距离连射 | 左轮手枪 | 待定（候选方案见下文） | 通关篇章一第 1 关 |
| 兰陵王 · 鬼面将军 | 高风险刺杀 | 双刃 | 入阵曲 | 完成任意 3 个支线 |
| 梅林 · 大魔法师 | 控场、新手友好 | 奥术新星 | 巨石阵 | 击败海拉 |

## 宫本武藏 · 剑圣

> 「我一生与人决斗六十余次，未尝一败。可是在这里，对手不是人。」

**史实背景**：日本江户时代初期的剑术家（1584—1645），自称一生决斗六十余次，从未败北。他开创了双手各持一刀的「二天一流」。在巌流岛与佐佐木小次郎的决斗中，他用船桨削成的木刀取胜。晚年隐居在熊本的灵岩洞，写下兵法书《五轮书》。

**被选中的时刻**：1645 年，灵岩洞中，《五轮书》写完的最后一笔。

| | |
| --- | --- |
| 初始武器 | **太刀**：扇形斩击，自动砍向身边最近的敌人 |
| 被动 | **二天一流**：每第 4 次挥砍变为双刀斩，同时斩向前后两个方向，伤害 ×2 |
| 大招 | **次元斩**：时间一顿，屏幕内的敌人全部被定住，空中浮现十几道空间裂痕，片刻后同时爆开，重创屏幕内所有敌人 |
| 充能 | 50 次击杀 |
| 大招特写 | **庆长十七年 · 巌流岛**。29 岁的武藏，决斗前锐利的眼神。台词取自《五轮书》：「千日为锻，万日为炼。这一刀，连天地也斩得开。」 |

## 安妮·奥克利 · 小神枪手

> 「别眨眼。我开枪的时候，时间都会停下来看。」

**史实背景**：美国西部传奇女神枪手（1860—1926）。15 岁时在射击比赛中击败了职业神枪手弗兰克·巴特勒，后来两人结为夫妻。她能在 30 步外击穿侧立的扑克牌边缘。苏族酋长坐牛十分欣赏她，称她为「小神枪手」。她随「水牛比尔的狂野西部秀」巡演欧美十几年。

**被选中的时刻**：1926 年，生命的最后一刻，枕边放着那支用了一辈子的步枪。

| | |
| --- | --- |
| 初始武器 | **左轮手枪**：射速快，自动瞄准最近的敌人；每打 6 发要换一次弹 |
| 被动 | **纸牌神射**：每个弹匣的最后一发必定暴击，命中后分裂成两发 |
| 大招 | **待定**。原方案「静止的一秒」（时间暂停）实际作用不够明显，正在从新的候选方案中选择 |

## 兰陵王 · 鬼面将军

> 「这张面具，是给敌人看的。」

**史实背景**：北齐名将高长恭（541—573），封兰陵王。据说他容貌俊美，上阵时总戴着一副狰狞的鬼面。564 年邙山之战，他亲率五百骑兵冲入北周大军的重围，一路杀到金墉城下。城上守军认不出他，直到他摘下面具，才打开城门。将士们为此作歌，就是《兰陵王入阵曲》。后来他功高遭忌，被北齐后主赐毒酒而死。

**被选中的时刻**：573 年，端起毒酒的那一刻。

| | |
| --- | --- |
| 初始武器 | **双刃**：射程很短，但出手极快的近身连刺 |
| 被动 | **破阵**：身边每有 1 个敌人，伤害 +6%（最多 +60%）。来自邙山之战五百骑冲入重围的典故：被包围得越紧，兰陵王越强 |
| 大招 | **入阵曲**：戴上鬼面化为鬼影，6 秒内无敌，自动瞬移到 15 个敌人身后各斩一刀；结束时五百骑幻影从屏幕一侧冲锋而过 |
| 充能 | 60 次击杀 |

## 梅林 · 大魔法师

> 「我预见过这一天。只是没想到，带走我的不是死亡，而是一颗光球。」

**传说背景**：亚瑟王传说中的魔法师与预言家，最早见于 12 世纪蒙茅斯的杰弗里所著的《不列颠诸王史》。传说他曾用魔法把巨石从爱尔兰搬到不列颠，建成了巨石阵；还曾预言红龙与白龙之战，预示不列颠的命运。他辅佐亚瑟王登上王位，最后被湖中仙女用他亲自传授的咒语封印。

**被选中的时刻**：他没有死，而是在被封印的那一刻被主神带走。这是主神第一次从「封印」而不是「死亡」中选人。

| | |
| --- | --- |
| 初始武器 | **奥术新星**：以自身为中心向外扩散的魔法环，伤害并击退敌人 |
| 被动 | **先知**：每次升级多一个选项（四选一） |
| 大招 | **巨石阵**：一圈巨石从天而降砸在身边，落地时重创周围敌人；之后 8 秒内敌人无法进入石阵 |
| 充能 | 60 次击杀 |

## 避免侵权的原则

1. **人物来自史实或古老传说**：宫本武藏、安妮·奥克利、高长恭都是真实的历史人物，梅林出自中世纪传说，这些都属于公有领域
2. **不参考其他作品的同名角色**：这几位在《王者荣耀》《Fate》《浪客行》等作品中都有登场。这些作品里的外观、服装、技能名、台词和性格都受版权保护，不能照搬。我们的设定只从史实和原始传说出发
3. **技能名避开知名作品的专有说法**：例如不用「子弹时间」（曾被华纳注册为商标），也不用《JOJO》里时停的说法
4. **美术要原创**：画人物时不要拿其他游戏里的同名角色当参考图
5. **正式商业发布前**，用角色名和游戏名在商标局做一次检索，最好请律师过目

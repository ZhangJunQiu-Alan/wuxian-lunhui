# 无限轮回 — 角色设定

博物馆里唯一真正的人类是林溯（见[世界观设定](世界观设定.md)和小说[《第零号展品》](小说_第零号展品.md)）。游戏里能选的角色都是他的**化身**：守墓人从档案里取出某位真实存在过的人或传说人物，把林溯放进这具身体，投进世界。

- 化身保留原主的样貌、武器和本领。所以枪手是一位女神枪手，林溯穿上她也一样
- 林溯会继承原主的一部分记忆。大招特写就是那段记忆里**最璀璨的时刻**，台词是原主在那一刻说的话
- 每个化身的档案都停在原主生命（或传说）终结的那一刻，下文写作「档案的最后一页」
- 林溯本人的样子不在游戏里出现

**角色只用职业称呼，不使用任何具体的人名**（2026-10-16 决定）。每个职业有一个时代原型，用来决定外观、武器和气质，但游戏里不点明原型是谁，也不出现能指认具体人物的年份、地名或事件。

## 通用规则

- 每个角色有：**初始武器**、**被动**、**大招**
- 初始武器不占信仰名额，再加上最多 4 位神的信仰
- 每个角色有专属的基础武器强化卡（升级时只出现自己武器的卡）
- 在主神空间的「化身」页选择和解锁角色
- **大招**：击杀敌人为大招充能，充满后按 **E** 释放。大招越强，需要的能量越多
- **闪现**：所有角色通用。按**空格**往移动方向瞬移 150 像素，能穿过怪物和物件，落地后无敌 0.2 秒；冷却 2 秒，冷却进度显示在脚下
- **大招特写**：释放大招时，右上角滑入角色**最璀璨的时刻**：面部特写、那一刻的场景、一句台词和大招名

| --- | --- | --- | --- | --- | --- |
| 剑士 · 东方剑客 | `swordsman` | 近战清场 | 太刀 | 次元斩 | 初始 |
| 枪手 · 西部神枪手 | `gunslinger` | 中距离连射 | 左轮手枪 | 狂野西部秀 | 通关篇章一第 1 关 |

## 剑士 · 东方剑客

> 「我一生与人决斗六十余次，未尝一败。可是在这里，对手不是人。」

**原型**：东方岛国战乱末年的浪人剑客。一生在决斗中度过，双手各持一刀，晚年隐居山洞写下兵法书。

**档案的最后一页**：山洞中，兵法书写完的最后一笔。

| | |
| --- | --- |
| 初始武器 | **太刀**：扇形斩击，自动砍向身边最近的敌人 |
| 被动 | **二刀流**：每第 4 次挥砍变为双刀斩，同时斩向前后两个方向，伤害 ×2 |
| 大招 | **次元斩**：时间一顿，屏幕内的敌人全部被定住，空中浮现十几道空间裂痕，片刻后同时爆开，重创屏幕内所有敌人 |
| 充能 | 50 次击杀 |
| 大招特写 | **孤岛 · 黎明的决斗**。正值壮年的剑士，决斗前锐利的眼神。台词：「千日为锻，万日为炼。这一刀，连天地也斩得开。」 |

## 枪手 · 西部神枪手

> 「别眨眼。我开枪的时候，时间都会停下来看。」

**原型**：西部拓荒年代随巡演团表演的女神枪手。身材娇小，能在三十步外击穿侧立的扑克牌边缘。

**档案的最后一页**：晚年生命的最后一刻，枕边放着那支用了一辈子的步枪。

| | |
| --- | --- |
| 初始武器 | **左轮手枪**：射速快，自动瞄准最近的敌人；每打 6 发要换一次弹 |
| 被动 | **纸牌神射**：每个弹匣的最后一发必定暴击，命中后分裂成两发 |
| 大招 | **狂野西部秀**：8 秒狂热状态。扇击连射（射速 ×4）、子弹穿透、移速 +30%，期间每次击杀回复少量生命。边跑边打的持续爆发 |
| 充能 | 60 次击杀 |
| 大招特写 | **巡演舞台 · 第一声枪响**。年轻的枪手第一次登上巡演舞台，面对上万名观众举枪。台词：「女士们，先生们——表演开始了。」 |

## 刺客 · 鬼面刺客

> 「这张面具，是给敌人看的。」

**原型**：古代东方的一位年轻将领。容貌俊美，上阵时总戴着狰狞的木质鬼面。曾率五百骑兵冲入重围，一路杀到孤城之下，摘下面具，城门才为他打开。后来功高遭忌，被赐毒酒。

**档案的最后一页**：端起毒酒的那一刻。

| | |
| --- | --- |
| 初始武器 | **双刃**：射程很短，但出手极快的近身连刺 |
| 被动 | **破阵**：身边每有 1 个敌人，伤害 +6%（最多 +60%）。被包围得越紧，刺客越强 |
| 大招 | **入阵曲**：戴上鬼面化为鬼影，6 秒内无敌，自动瞬移到 15 个敌人身后各斩一刀；结束时五百骑幻影从屏幕一侧冲锋而过 |
| 充能 | 60 次击杀 |
| 大招特写 | **孤城之下 · 摘下鬼面**。台词：「五百骑，随我入阵。」 |

## 法师 · 大魔法师

> 「我预见过无数个结局，唯独没有预见到：有人会穿着我的样子，替我再活一次。」

**原型**：古老传说中的魔法师与预言家。传说他用魔法把巨石从海的另一边搬来，建成了巨石阵；最后被他亲手教出的学生用他传授的咒语封印。

**档案的最后一页**：他没有死，传说只记到他被封印的那一刻。这是唯一一份停在「封印」而不是「死亡」的档案。

| | |
| --- | --- |
| 初始武器 | **奥术新星**：以自身为中心向外扩散的魔法环，伤害并击退敌人 |
| 被动 | **先知**：每次升级多一个选项（四选一） |
| 大招 | **巨石阵**：一圈巨石从天而降砸在身边，落地时重创周围敌人；之后 8 秒内敌人无法进入石阵 |
| 充能 | 60 次击杀 |
| 大招特写 | **远古 · 巨石阵**。台词：「群山也会听从言语，只要你知道它们的名字。」 |

## 避免侵权的原则

1. **只用职业称呼**：游戏中不出现任何真实人物或传说人物的名字，台词、特写、文档里的说明也不点明原型
2. **不参考其他作品的角色**：同类原型的人物在《王者荣耀》《Fate》《浪客行》等作品中都有登场。这些作品里的外观、服装、技能名、台词和性格都受版权保护，不能照搬。我们的设定只从时代风貌出发
3. **技能名避开知名作品的专有说法**：例如不用「子弹时间」（曾被华纳注册为商标），也不用《JOJO》里时停的说法
4. **美术要原创**：画人物时不要拿其他游戏里的角色当参考图
5. **正式商业发布前**，用游戏名和技能名在商标局做一次检索，最好请律师过目

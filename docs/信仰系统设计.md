## 一、现在的问题

现在每位神只有 3～5 张卡：1 张技能卡、2～3 张数值卡、1 张觉醒卡。玩下来无聊的原因：

1. **几乎全是「+X%」**：雷霆万钧 +30%、野火蔓延 +20%……选哪张都只是数字变大，玩法不变
2. **神和神之间没有关系**：信仰托尔和信仰洛基互不影响，搭配不出流派
3. **神力只管自己的技能**：神术自己在旁边打，和基础武器、闪现、大招都没关系，玩家的操作不会因为信仰而改变
4. **觉醒只是更大的数字**：觉醒·诸神黄昏之火 = 范围 +50%、伤害翻倍
5. **一局里没有取舍**：卡池里的卡没有代价，也没有互斥，选卡时不用思考

## 二、可以借鉴的做法

| 游戏 | 做法 | 我们怎么用 |
| --- | --- | --- |
| 《哈迪斯》 | 每位神的祝福占住「攻击 / 特技 / 冲刺 / 施法」中的一个槽位，同一槽位只能有一位神 | 我们的神力可以附在**基础武器、闪现、大招**上，同一处只能附一位神：强迫取舍 |
| 《哈迪斯》 | 每位神有自己的负面状态（宙斯的「电击」、阿瑞斯的「厄运」），不同神的状态能互相触发 | 每位神一个**神印**（状态），卡牌围绕神印设计；融合技就是两种神印的化学反应 |
| 《哈迪斯》 | 双神祝福：同时拥有两位神的特定祝福后才会出现，效果最强 | **融合技**：两位神都觉醒后出现 |
| 《哈迪斯》 | 混沌祝福：先承受几个房间的诅咒，之后得到永久好处 | **洛基的赌局**：先吃亏后得利，或者赌一把 |
| 《哈迪斯》 | 祝福有稀有度（普通 / 稀有 / 史诗），同一张卡数值不同 | 卡牌分**普通 / 稀有 / 史诗**，越后期越容易出高稀有度 |
| 《吸血鬼幸存者》 | 武器满级 + 指定被动 → 进化成新武器 | 觉醒需要满足条件（信仰满 + 拿过某张关键卡），觉醒后神术**变形**，不只是变强 |
| 《土豆兄弟》 | 有代价的强化：+伤害但 -生命 | 部分卡带**代价**（提尔的断手之誓、奥丁的绞刑树） |
| 《杀戮尖塔》 | 状态叠层：毒、易伤，层数越多越强 | 神印可以叠层（霜冻叠满冻结、符文印记叠满引爆） |
| 《雨中冒险 2》 | 击中触发连锁（触发再触发） | 神印之间互相触发：雷击引爆符文、冻结的敌人被雷劈碎 |
| 《以撒的结合》 | 道具之间意外的组合效果 | 融合技要有「原来还能这样」的惊喜，最好带神话典故 |

## 三、新框架

### 1. 一局的流程

| 玩家等级 | 发生什么 |
| --- | --- |
| 1 级（开局） | 选第一位神：从 8 位里随机给 3 位，选 1 位，获得他的神术 |
| 5 级 | 选第二位神（从没信仰的神里随机 3 位） |
| 10 级 | 选第三位神 |
| 15 级 | 选第四位神，之后不再出现选神 |
| 其他等级 | 三选一：已信仰的神的强化卡、基础武器卡、通用属性卡 |
| 某位神信仰到 8 | 立刻弹出这位神的**质变**选择（不占用升级）：给出他的全部质变，只能选 1 个 |
| 某位神信仰到 15 | 立刻弹出这位神的**觉醒**（不占用升级）；觉醒的形态取决于选过的质变 |

### 2. 稀有度

每张卡抽出来时随机一个稀有度，同一张卡稀有度越高数值越大，加的信仰也越多。卡面边框用不同颜色区分。

| 稀有度 | 颜色 | 基础几率 | 数值倍率 | 加信仰 |
| --- | --- | --- | --- | --- |
| 普通 | 白 | 60% | ×1 | +1 |
| 稀有 | 蓝 | 28% | ×1.5 | +2 |
| 史诗 | 紫 | 10% | ×2.2 | +3 |
| 传说 | 金 | 2% | ×3 | +4 |

- 时间越往后，高稀有度越常见（每分钟稀有以上 +2%）
- 新的通用属性卡「幸运」、永久强化「主神的眷顾」可以提高高稀有度几率
- 只有数字的卡按倍率放大；带「次数、道数」这类整数的卡，高稀有度改成「多加一次」或附带额外效果（每张卡在下面写清楚）
- 选神、质变、觉醒不抽稀有度

### 3. 信仰

- 信仰从 1 开始（选这位神时），每拿一张他的卡按稀有度加信仰，最高 15
- 一局约 30 次升级（见第七节），扣掉 4 次选神，约 26 张卡分给 4 位神、基础武器和通用属性。专心养一位神，大约 8～10 张卡能到 15
- 所以一局里通常是：2～3 位神拿到质变，1 位神觉醒；全力只养两位时，两位都能觉醒

### 4. 卡牌种类

| 种类 | 来源 | 说明 |
| --- | --- | --- |
| 神术 | 选神时获得 | 这位神的自动技能 |
| 强化 | 升级三选一 | 可以拿多级，每张都有稀有度，**一局的主要变化来自这里**：不只是加数字，还有改变瞄准方式、触发条件、额外效果的卡 |
| 附魔 | 升级三选一 | 附在基础武器、闪现或大招上，同一处只能附一位神（？还没定） |
| 质变 | 信仰到 8 | 每位神 3～4 个，只能选 1 个，决定这位神这一局走哪条路 |
| 觉醒 | 信仰到 15 | 按选过的质变走向不同的终极形态 |
| 通用属性 | 升级三选一 | 力量、迅捷、体魄、冷却缩短、幸运…… |

### 5. 融合技

- 原定「两位神都觉醒」：按上面的节奏，一局通常只有 1 位神觉醒，融合技几乎见不到
- 建议改成：**一位觉醒 + 另一位已经选过质变**（信仰 ≥ 8）就出现融合卡，一局大约 1 个（？）

### 6. 卡池规则

- 每次三选一的 3 张不重复，至少 1 张来自已信仰的神
- 已经拿满级的强化不再出现
- **放逐**（新的永久强化）：每局可以把一张不想要的卡移出卡池
- **神明的好恶**：海姆达尔与洛基是宿敌，选神时两位不会同时出现在同一次三选一里（但都信仰时有专属融合技「同归于尽」）

### 7. 通用属性卡（调整）

| 卡 | 普通 → 传说 | 说明 |
| --- | --- | --- |
| 冷却缩短 | 所有神术冷却 -5% / -7.5% / -11% / -15% | 取代各位神自己的间隔卡；原来的「急速」改成只管基础武器 |
| 幸运 | 高稀有度几率 +3% / +4.5% / +6.5% / +9% | 新增 |
| 力量、迅捷、体魄、引力、智慧、闪避、再生 | 原数值 ×稀有度倍率 | 不变 |

### 托尔 · 雷神（按新规则重做，其他神照这个模板）

- **神印·感电**：被雷击中的敌人感电 3 秒；感电的敌人受到任何伤害时，有 20% 几率向附近的敌人跳出一道小电弧
- **神术·落雷**：每 2 秒向附近的敌人劈下 1 道雷，范围半径 50。间隔只受通用的「冷却缩短」影响

#### 强化（可以拿多级，括号里是 普通 / 稀有 / 史诗 / 传说）

按玩法分成六个方向，玩家可以挑自己喜欢的方向堆：

**① 更痛（伤害）**
1. 雷霆万钧：落雷伤害 +15% / 22% / 33% / 45%（5 级）
2. 天罚：落雷暴击率 +5% / 7.5% / 11% / 15%，暴击伤害 ×2（4 级）
3. 导体：对感电的敌人伤害 +10% / 15% / 22% / 30%（3 级）

**② 更多（数量与范围）**
4. 风暴：每次多劈 1 道雷；史诗额外伤害 +10%，传说一次多劈 2 道（3 级）
5. 雷域：落雷范围 +12% / 18% / 26% / 36%（4 级，你提的「雷击范围」）
6. 连锁闪电：落雷命中后跳向附近 1 个敌人，跳跃伤害 50%；稀有跳跃伤害 65%，史诗跳 2 个，传说跳 3 个（3 级）

**③ 更聪明（瞄准）**
7. 雷眼：落雷改为瞄准敌人最密集的地方，每多劈中 1 个敌人，这一道雷伤害 +4% / 6% / 9% / 12%（1 级）
8. 猎头雷：每第 3 道落雷必定劈向屏幕内血量最高的敌人（精英、Boss），这一道伤害 +30% / 45% / 66% / 90%（1 级）

**④ 更稳（控制）**
9. 麻痹：被落雷击中的敌人有 12% / 18% / 26% / 36% 几率麻痹 0.6 秒，停止移动和攻击（3 级）
10. 雷鸣：落雷把敌人向外震开 50 / 75 / 110 / 150 像素（2 级）

**⑤ 会玩（节奏与操作）**
11. 超载：每第 8 道落雷变成超载雷：伤害 ×3、范围 ×1.5。每级让超载提前 1 / 1 / 2 / 3 道（最快每第 3 道，4 级）
12. 回响：落雷有 12% / 18% / 26% / 36% 几率在 0.5 秒后原地再劈一次（3 级）
13. 电荷积蓄：移动时积蓄电荷，每走 300 像素存 1 层（最多 5 层），下一道落雷每层伤害 +10% / 15% / 22% / 30%。鼓励跑动，站着不动的玩家拿了没用（3 级）
14. 余电：被落雷打死的敌人原地炸出一颗电球，造成落雷 20% / 30% / 44% / 60% 的范围伤害；电球也能触发连锁闪电（3 级）

**⑥ 更硬（防守）**
15. 雷电护体：每劈下一道雷获得 1 层电盾（最多 2 / 3 / 4 / 5 层），受到攻击时消耗 1 层抵消这次伤害（1 级）
16. 力量腰带：最大生命 +15 / 22 / 33 / 45，受到伤害时有 10% 几率反劈一道雷（2 级）

一局托尔大约拿 8～10 张强化，16 张里只能拿到一半左右，每一局的托尔会不一样。

## 六、和其他系统的连接

- **局外解锁新神**：初始只能信仰现有 4 位；提尔、海姆达尔、弗雷、斯卡蒂用支线剧情点在主神空间解锁（或通过某个隐藏支线结识他们）。给局外成长更多目标
- **地图上的神像**：地标里偶尔出现某位神的神像，走过去获得一次「只有这位神」的三选一，帮助玩家走自己想要的流派
- **图鉴**：强化分类按 8 位神分组，融合技单独一栏，「发现过的融合技」是收集目标
- **升级卡插画**：新神需要 4 张画像（Codex，和任务 F 同一套画风）；融合卡用两位神的画像左右拼合，不用另画
- **剧情**：洛基借力的伏笔可以和「同归于尽」「芬里尔」两个融合技呼应

## 七、数值节奏（10 分钟一局）

**升级所需经验要改**。现在每一级比上一级多要约 25% 的经验，模拟一局 10 分钟只能升到 14 级左右，15 级的第四次选神几乎碰不到，信仰 15 也攒不够卡。

改成线性：第 n 级升级需要 5 + 2.2 ×（n - 1）点经验。按现在的经验掉落量，大约：

| 时间 | 等级 | 发生什么 |
| --- | --- | --- |
| 00:00 | 1 | 选第一位神 |
| 约 01:30 | 5 | 选第二位神 |
| 约 03:00 | 10 | 选第三位神（第一个 Boss 前后） |
| 约 04:30 | 15 | 选第四位神；主力神开始到信仰 8，选质变 |
| 约 06:00～08:00 | 20～26 | 第二、三位神选质变；主力神觉醒 |
| 约 09:00～10:00 | 28～32 | 最终 Boss 前，构筑成型 |

升级次数从约 14 次变成约 30 次，每次升级的强化数值要相应调小（上面托尔的数值已经按这个节奏写）。实际玩下来再调整。

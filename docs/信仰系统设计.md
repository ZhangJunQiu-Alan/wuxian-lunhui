# 信仰系统 2.0 设计稿（第三版）

> 第三版（2026-10-18）：按第二轮讨论定稿框架：武器 + 3 位神；所有神统一「4 个强化方向 + 3 选 1 质变 + 觉醒」模板；信仰 6 质变、12 觉醒；伤害和暴击卡归入通用属性。八位神都已按模板写好，文中带「？」的地方是还需要你拍板的。经验与关卡时长见 [局内成长与关卡节奏.md](局内成长与关卡节奏.md)。

## 〇、已经定下的规则

| 规则 | 内容 |
| --- | --- |
| 技能槽 | 一局最多 4 个主要技能：角色基础武器 + 3 位神的神术 |
| 选神 | 1、5、10 级各选一位新的神，8 位里一局信仰 3 位 |
| 稀有度 | 升级抽到的每一张卡都有稀有度（普通 / 稀有 / 史诗 / 传说） |
| 模板 | 每位神：神术 + **4 个强化方向** + **质变（3 选 1）** + **觉醒** |
| 质变 | 这位神的信仰到 6 时出现，3 个里只能选 1 个 |
| 觉醒 | 这位神的信仰到 12 时出现，形态取决于选过的质变 |
| 通用属性 | 加伤害、暴击这类纯数值卡全部归入通用属性，神明的强化卡只放改变玩法的方向；「冷却缩短」也是通用卡 |
| 经验 | 每升一级，下一级多要 6 点经验（2 级要 5，3 级要 11……），等级上限 30 |
| 刷怪 | 后期刷怪更密：05:20、07:20 两档加快，09:00 再加一档 |

## 一、现在的问题

现在每位神只有 3～5 张卡：1 张技能卡、2～3 张数值卡、1 张觉醒卡。玩下来无聊的原因：

1. **几乎全是「+X%」**：雷霆万钧 +30%、野火蔓延 +20%……选哪张都只是数字变大，玩法不变
2. **神和神之间没有关系**：信仰托尔和信仰洛基互不影响，搭配不出流派
3. **神力只管自己的技能**：神术自己在旁边打，和基础武器、闪现、大招都没关系，玩家的操作不会因为信仰而改变
4. **觉醒只是更大的数字**：觉醒·诸神黄昏之火 = 范围 +50%、伤害翻倍
5. **一局里没有取舍**：卡池里的卡没有代价，也没有互斥，选卡时不用思考

## 二、可以借鉴的做法

| 游戏 | 做法 | 我们怎么用 |
| --- | --- | --- |
| 《哈迪斯》 | 每位神的祝福占住「攻击 / 特技 / 冲刺 / 施法」中的一个槽位，同一槽位只能有一位神 | 我们的神力可以附在**基础武器、闪现、大招**上，同一处只能附一位神：强迫取舍 |
| 《哈迪斯》 | 每位神有自己的负面状态（宙斯的「电击」、阿瑞斯的「厄运」），不同神的状态能互相触发 | 每位神一个**神印**（状态），卡牌围绕神印设计；融合技就是两种神印的化学反应 |
| 《哈迪斯》 | 双神祝福：同时拥有两位神的特定祝福后才会出现，效果最强 | **融合技**：两位神都觉醒后出现 |
| 《哈迪斯》 | 混沌祝福：先承受几个房间的诅咒，之后得到永久好处 | **洛基的赌局**：先吃亏后得利，或者赌一把 |
| 《哈迪斯》 | 祝福有稀有度（普通 / 稀有 / 史诗），同一张卡数值不同 | 卡牌分**普通 / 稀有 / 史诗**，越后期越容易出高稀有度 |
| 《吸血鬼幸存者》 | 武器满级 + 指定被动 → 进化成新武器 | 觉醒需要满足条件（信仰满 + 拿过某张关键卡），觉醒后神术**变形**，不只是变强 |
| 《土豆兄弟》 | 有代价的强化：+伤害但 -生命 | 部分卡带**代价**（提尔的断手之誓、奥丁的绞刑树） |
| 《杀戮尖塔》 | 状态叠层：毒、易伤，层数越多越强 | 神印可以叠层（霜冻叠满冻结、符文印记叠满引爆） |
| 《雨中冒险 2》 | 击中触发连锁（触发再触发） | 神印之间互相触发：雷击引爆符文、冻结的敌人被雷劈碎 |
| 《以撒的结合》 | 道具之间意外的组合效果 | 融合技要有「原来还能这样」的惊喜，最好带神话典故 |

## 三、新框架

### 1. 一局的流程

| 玩家等级 | 发生什么 |
| --- | --- |
| 1 级（开局） | 选第一位神：从 8 位里随机给 3 位，选 1 位，获得他的神术 |
| 5 级（约 01:00） | 选第二位神（从没信仰的神里随机 3 位） |
| 10 级（约 02:30～03:00） | 选第三位神，之后不再出现选神 |
| 其他等级 | 三选一：已信仰的神的强化卡、基础武器卡、通用属性卡 |
| 某位神信仰到 6 | 立刻弹出这位神的**质变**（不占用升级）：3 个里选 1 个 |
| 某位神信仰到 12 | 立刻弹出这位神的**觉醒**（不占用升级）；觉醒的形态取决于选过的质变 |

### 2. 稀有度

每张卡抽出来时随机一个稀有度，同一张卡稀有度越高数值越大，加的信仰也越多。卡面边框用不同颜色区分。

| 稀有度 | 颜色 | 基础几率 | 数值倍率 | 加信仰 |
| --- | --- | --- | --- | --- |
| 普通 | 白 | 60% | ×1 | +1 |
| 稀有 | 蓝 | 28% | ×1.5 | +2 |
| 史诗 | 紫 | 10% | ×2.2 | +3 |
| 传说 | 金 | 2% | ×3 | +4 |

- 时间越往后，高稀有度越常见（每分钟稀有以上 +2%）
- 通用属性卡「幸运」、永久强化「主神的眷顾」可以提高高稀有度几率
- 只有数字的卡按倍率放大；带「次数、道数」这类整数的卡，高稀有度改成「多加一次」或附带额外效果（每张卡在下面写清楚）
- 选神、质变、觉醒不抽稀有度

### 3. 信仰

- 选这位神时信仰为 1，每拿一张他的强化卡按稀有度加信仰，最高 12
- 平均每张卡约 +1.5 信仰：拿 3～4 张到信仰 6（质变），7～8 张到信仰 12（觉醒）
- 一局 29 次升级，扣掉 5 级、10 级两次选神，约 27 张卡，再加宝箱和支线的奖励。分给 3 位神、基础武器和通用属性后，通常是：**3 位神都拿到质变，1～2 位觉醒**；全力养一位神，大约 5～6 分钟觉醒

### 4. 卡牌种类

| 种类 | 来源 | 说明 |
| --- | --- | --- |
| 神术 | 选神时获得 | 这位神的自动技能 |
| 强化 | 升级三选一 | 每位神 4 个方向，每个可以拿多级，加信仰。只放改变玩法的效果（数量、范围、控制、触发），不放纯伤害 |
| 质变 | 信仰到 6 | 每位神 3 个，只能选 1 个，神术换一种形态；前面的强化跟着换作用方式 |
| 觉醒 | 信仰到 12 | 3 个质变各对应一个觉醒，外加这位神共有的神格被动 |
| 基础武器 | 升级三选一 | 角色武器的强化，不变 |
| 通用属性 | 升级三选一 | 力量、暴击、冷却缩短、幸运等，不加信仰 |

第二版里的「附魔」和「誓约」卡不在新模板里，先删掉（其中好的点子并进了质变和觉醒）。

### 5. 融合技

- 原定「两位神都觉醒」：按新节奏一局大约 1～2 位觉醒，全力养两位才能做到，融合技会比较少见
- 建议：**一位觉醒 + 另一位已经选过质变**（信仰 ≥ 6）就出现融合卡，一局大约 1 个（？）

### 6. 卡池规则

- 每次三选一的 3 张不重复，至少 1 张来自已信仰的神
- 已经拿满级的强化不再出现；一位神 4 个方向全部满级后，他的卡不再出现
- **放逐**（新的永久强化）：每局可以把一张不想要的卡移出卡池
- **神明的好恶**：海姆达尔与洛基是宿敌，选神时两位不会同时出现在同一次三选一里（但都信仰时有专属融合技「同归于尽」）

### 7. 通用属性卡

| 卡 | 普通 / 稀有 / 史诗 / 传说 | 说明 |
| --- | --- | --- |
| 力量 | 所有伤害 +10% / 15% / 22% / 30% | 各位神原来的「+伤害」卡（雷霆万钧、炽焰、密写符文……）都并到这里 |
| 暴击 | 暴击率 +5% / 7.5% / 11% / 15%，暴击伤害 ×2 | 新增；原来托尔的「天罚」改到这里，所有伤害都能暴击 |
| 冷却缩短 | 所有神术冷却 -5% / 7.5% / 11% / 15% | 取代各位神自己的「缩短间隔」卡 |
| 急速 | 基础武器冷却 -8% / 12% / 18% / 24% | 原来的急速只管基础武器 |
| 幸运 | 高稀有度几率 +3% / 4.5% / 6.5% / 9% | 新增 |
| 迅捷、体魄、引力、智慧、闪避、再生 | 原数值 × 稀有度倍率 | 不变 |

## 四、八位神明

现有 4 位（托尔、奥丁、洛基、弗蕾亚）保留现有神术。新增 4 位：**提尔、海姆达尔、弗雷、斯卡蒂**（？）。

挑选原则：都是北欧本土神（符合「信仰」的设定）、神话里有鲜明的故事可以做成卡、玩法定位互不重复。

| 洛基 · 诡计之神 | 持续伤害、混乱 | 诡火光环 | 灼烧、迷惑 |
| 弗蕾亚 · 爱与战争女神 | 生存、环绕 | 女武神之羽 | 女武神的拣选 |
| 提尔 · 战神 | 近战、控制精英 | 誓约斩 | 誓约 |
| 海姆达尔 · 神域守门人 | 防守、控场 | 加拉尔号角 | 震慑 |

| 斯卡蒂 · 冬与狩猎女神 | 冰冻减速、狙击 | 霜猎之箭 | 霜冻 |

备选（如果想换掉某一位）：弗丽嘉（命运纺织、护盾）、维达（沉默的复仇者，杀死芬里尔）、伊敦（青春苹果、回复）、乌勒尔（弓箭与雪鞋，和斯卡蒂重叠）。

**神印**是这位神给敌人挂的状态，本身效果很小，主要给质变、觉醒和融合技用（两种神印碰在一起会起反应）。

强化后面的括号是 普通 / 稀有 / 史诗 / 传说 的数值，和这个方向最多能拿几级。

### 托尔 · 雷神

- **神印·感电**：被雷击中的敌人感电 3 秒
- **神术·落雷**：每 2 秒向附近的敌人劈下 1 道雷，范围半径 50

**强化**
1. 风暴：每次多劈 1 道雷；史诗再附带落雷范围 +10%，传说一次多劈 2 道（3 级）
2. 雷域：落雷范围 +12% / 18% / 26% / 36%（4 级）
3. 麻痹：被落雷击中的敌人有 12% / 18% / 26% / 36% 几率麻痹 0.6 秒，停止移动和攻击（3 级）
4. 回响：落雷有 12% / 18% / 26% / 36% 几率在 0.5 秒后原地再劈一次（3 级）

**质变：雷神的道路（信仰 6，三选一）**

| 质变 | 效果 | 流派 | 强化怎么变 |
| --- | --- | --- | --- |
| 妙尔尼尔 | 落雷改为每 3 秒向最近的敌人掷出战锤，飞出去再飞回手里，锤子经过的地方一路落雷 | 直线、走位 | 风暴 = 多掷一把锤（扇形）；雷域 = 沿途的雷更宽；麻痹 = 被锤子砸中也会麻痹；回响 = 锤子回手时有几率立刻再掷一次 |
| 雷暴云 | 头顶跟着一团雷云，持续向周围随机劈小雷（每秒 3 道，单发伤害是原来的 40%） | 持续覆盖、清小怪 | 风暴 = 每秒多劈 1 道；雷域 = 雷云和小雷都变大；麻痹、回响按每道小雷判定 |
| 静电场 | 落雷不再造成直接伤害，而是给范围内的敌人叠感电层数；相距 150 以内的感电敌人连成电网，每秒互相电击 | 状态、连锁 | 风暴 = 每次多劈 1 道（叠层更快）；雷域 = 电网连线距离变长；麻痹 = 电网电击也会麻痹；回响 = 电网每次电击有几率再跳一次 |

| 雷暴云 | **山羊战车**：雷云扩大到覆盖整个屏幕，变成雷暴（托尔驾着山羊拉的战车，车轮声就是雷鸣） |

### 奥丁 · 众神之父

- **神印·符文印记**：符文命中叠 1 层印记，叠到 3 层时引爆，造成一次额外伤害
- **神术·符文飞弹**（现有）：向最近的敌人发射符文

**强化**
1. 符文增殖：每次多发射 1 枚符文；传说多 2 枚（3 级）
2. 破甲符文：符文穿透 +1；史诗、传说穿透 +2（3 级）
3. 符文共鸣：印记引爆时波及半径 50 / 75 / 110 / 150 内的敌人，并给它们叠 1 层印记（3 级）
4. 回旋符文：符文飞到尽头后折返一次，有 25% / 37% / 55% / 75% 几率在折返时分裂成 2 枚（3 级）

### 洛基 · 诡计之神

- **神印·灼烧 / 迷惑**：诡火让敌人灼烧（离开火焰后继续掉血 2 秒）；迷惑的敌人会攻击身边的同伴
- **神术·诡火光环**（现有）：身边燃起火焰，持续灼烧靠近的敌人

**强化**
1. 野火蔓延：火焰范围 +12% / 18% / 26% / 36%（4 级）
2. 余烬：灼烧持续时间 +1 / 1.5 / 2.2 / 3 秒（3 级）
3. 银舌：灼烧的敌人每秒有 4% / 6% / 9% / 12% 几率被迷惑 3 秒（3 级）
4. 火种：灼烧的敌人死亡时爆出火星，点燃身边 1 / 1 / 2 / 3 个敌人（3 级）

## 六、和其他系统的连接

- **局外解锁新神**：初始只能信仰现有 4 位；提尔、海姆达尔、弗雷、斯卡蒂用支线剧情点在主神空间解锁（或通过某个隐藏支线结识他们）。给局外成长更多目标
- **地图上的神像**：地标里偶尔出现某位神的神像，走过去获得一次「只有这位神」的三选一，帮助玩家走自己想要的流派
- **图鉴**：强化分类按 8 位神分组，融合技单独一栏，「发现过的融合技」是收集目标
- **升级卡插画**：新神需要 4 张画像（Codex，和任务 F 同一套画风）；融合卡用两位神的画像左右拼合，不用另画
- **剧情**：洛基借力的伏笔可以和「同归于尽」「芬里尔」两个融合技呼应

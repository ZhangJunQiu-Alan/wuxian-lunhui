# 地图设计

三关地图都已做完并接入。数值以代码为准：尺寸、地标、边界在 `scripts/data/level_db.gd`，地面和物件的摆放在 `scripts/world/<关卡>_map.gd`。坐标原点是地图中心（出生点），x 向右、y 向下；地块 64×64。

## 通用规则

- 每个地标都要让玩家看得出「这里发生过什么」。
- 大物件（房屋、船、立石、石柱、岩石）挡路；小物件（木桶、骨头、脚印）只是装饰，可以穿过。
- 碰撞物不能把路堵死，地标之间至少两条通路。
- 高的物件在玩家走到后面时变半透明，不能挡住玩家和怪物。
- 地面装饰要比角色暗、对比度低，几百只怪同屏也要看得清。留出大片空地给玩家走位。
- 边界是天然屏障，玩家和怪物都过不去，镜头到边缘停住。

4608×4608（72×72 块）。代码：`level_db.gd` 的 `NORSE_1.map`，`midgard_map.gd`。

| 地标 | 中心 | 半径 | 内容 |
| --- | --- | ---: | --- |
| 十字路口（出生点） | (0, 0) | 320 | 冻土小路交叉，符文路标石、翻倒的手推车 |
| 被雪掩埋的村庄 | (-1350, -1250) | 650 | 6~8 座维京长屋，断栅栏、冻住的水井，门口有打过仗的盾和断矛 |
| 峡湾码头 | (1450, -1400) | 550 | 被冰挤碎的码头、半埋的龙头长船，冰面上有巨人脚印通向东方 |
| 奥丁的符文石阵 | (-1500, 950) | 420 | 一圈符文立石围着石祭坛，雪很薄，地面颜色更深 |

| 冰湖 | (1350, 1100) | 650 | 开阔光滑的冰面，没有障碍，适合风筝和打 Boss |

边界：北是峡湾冰崖，东是冰封的海，西是枯松林，南是山脚岩壁。

## 第 2 关：亡者之船（赫尔海姆）

4608×4608。代码：`level_db.gd` 的 `NORSE_2.map`，`helheim_map.gd`。

![第 2 关地图布局草图](images/map_helheim_layout.png)

| 地标 | 中心 | 半径 | 内容 |
| --- | --- | ---: | --- |
| 亡者广场（出生点） | (0, 0) | 350 | 黑石板地面，一列列朝北的脚印，亡者丢下的拐杖、木马 |
| 吉欧尔桥 | (0, -800) | 320 | 金瓦长桥，宽 192，适合在桥口卡怪 |
| 纳吉尔法尔港 | (400, -1600) | 650 | 指甲拼成的巨船只露出一段，4 条锚链拴在岸边 |
| 冥雾沼泽 | (-1400, 150) | 650 | 常驻冥雾，泥沼、枯树、白骨 |
| 海拉的大厅 | (1400, 100) | 600 | 黑石柱、空王座和长桌，门前有八足神驹的蹄印 |
| 世界树之根 | (-1250, 1350) | 550 | 拱出地面的巨根，布满啃痕 |
| 加姆的洞窟 | (1300, 1550) | 500 | 南墙上的洞，断铁链、血迹、犬爪印 |
| 指甲工坊 | (-1400, -1500) | 500 | 指甲小山、工作台、拼到一半的指甲傀儡 |
| 结冰的浅滩 | (-1600, -800) | 250 | 第二个过河点，冰下冻着刀剑 |

- **冥河**横贯北部（y = -900 ~ -700），和边界一样过不去，只能走桥或浅滩；冥雾幽魂能飘过去。
- **冥雾**：雾里每秒掉 2% 最大生命，敌人移速 -40%。沼泽常驻，另有 3 团雾在地图上飘。
- **Boss 物件**跟着 Boss 出现在玩家附近，不固定在地图上：加姆的 4 根锁桩、尼德霍格啃的世界树根、海拉二阶段的纳吉尔法尔虚影。

边界：北是冥海，东是赫尔之墙，西是雾之深渊，南是寒冰岩壁。

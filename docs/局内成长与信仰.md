# 局内成长与信仰

具体数值以代码为准：经验和满级在 `scripts/entities/player.gd`，卡牌在 `scripts/data/upgrade_db.gd`，神明和融合技在 `scripts/data/gods.gd`，每位神的神术在 `scripts/gods/<神>.gd`，Boss 和刷怪时间轴在 `scripts/data/level_db.gd`。

## 一、单局规则

- 每关是一局独立游戏：重新选角色，从 1 级开始构筑，不继承上一关的等级、卡牌和信仰。局外解锁和永久强化照常生效。
- 一局最多 5 个主要战斗技能：角色基础武器 + 4 位神的神术。强化、觉醒不另占槽；通用属性、大招和闪现不算在内。
- 1、5、10、15 级各选一位神，8 位里一局最多信仰 4 位。普通升级和选神都是四选一，质变是三选一。
- 选神时信仰为 1，拿该神的任何强化卡固定 +1，与稀有度无关；信仰 6 质变、12 觉醒。觉醒后该神的强化卡不再进入升级、重抽和宝箱的卡池。

### 关卡时长

- 当前目标约 10 分钟：03:00、06:00、09:00 依次登场三个 Boss，前一个没死后一个等着；三个都击败才通关。10 分钟不强制结束，也不判负。
- 后期刷怪加密：05:20、07:20 各加快一档，09:00 再加一档；Boss 在场时小怪刷新减半。
- 升级选卡和暂停不计入战斗时间。
- 正式发布后改成约 15 分钟，到时 Boss、刷怪和成长节奏一起重排，不只是拉长等待。

### 等级与经验

等级上限 40。第一次升级要 5 经验，之后每级多要 6 点（`XP_STEP = 6`）。

| 到达等级 | 本次所需 | 从 1 级起累计 |
| ---: | ---: | ---: |
| 2 | 5 | 5 |
| 5 | 23 | 56 |
| 10 | 53 | 261 |
| 15 | 83 | 616 |
| 20 | 113 | 1,121 |
| 25 | 143 | 1,776 |
| 30 | 173 | 2,581 |
| 35 | 203 | 3,536 |
| 40 | 233 | 4,641 |

- 到 40 级时照常发最后一次升级选择；一次捡再多经验也不会超过 40 级。
- 满级后不再累计经验，经验条保持填满；Boss 宝箱的选卡奖励照常给。
- 升级速度、构筑成型和觉醒时间还没按这套规则试玩验证。

## 二、信仰

### 1. 一局的流程

| 玩家等级 | 发生什么 |
| --- | --- |
| 1 级（开局） | 选第一位神：从 8 位里随机给 4 位，选 1 位，获得他的神术 |
| 5 级 | 选第二位神（从没信仰的神里随机 4 位） |
| 10 级 | 选第三位神 |
| 15 级 | 选第四位神，之后不再出现选神 |
| 其他等级 | 四选一：已信仰的神的强化卡、基础武器卡、通用属性卡 |
| 某位神信仰到 6 | 立刻弹出这位神的**质变**（不占用升级）：3 个里选 1 个 |
| 某位神信仰到 12 | 立刻弹出这位神的**觉醒**（不占用升级）；觉醒的形态取决于选过的质变 |

### 2. 稀有度

每张卡抽出来时随机一个稀有度，同一张卡稀有度越高数值越大，但神明强化卡增加的信仰始终为 +1。卡面边框用不同颜色区分。

| 稀有度 | 颜色 | 基础几率 | 数值倍率 | 加信仰 |
| --- | --- | --- | --- | --- |
| 普通 | 白 | 60% | ×1 | +1 |
| 稀有 | 蓝 | 28% | ×1.5 | +1 |
| 史诗 | 紫 | 10% | ×2.2 | +1 |
| 传说 | 金 | 2% | ×3 | +1 |

- 时间越往后，高稀有度越常见（每分钟稀有以上 +2%）
- 通用属性卡「幸运」、永久强化「主神的眷顾」可以提高高稀有度几率
- 只有数字的卡按倍率放大；带「次数、道数」这类整数的卡，高稀有度改成「多加一次」或附带额外效果（每张卡在下面写清楚）
- 选神、质变、觉醒不抽稀有度

### 3. 信仰

- 选这位神时信仰为 1，每拿一张他的强化卡固定 +1，最高 12；普通、稀有、史诗、传说都一样。
- 累计选择 5 张强化卡达到信仰 6（质变），11 张达到信仰 12（觉醒）。质变和觉醒选择本身不额外增加信仰。
- 一局从 1 级到 40 级有 39 次经验升级，扣掉 5、10、15 级三次选神，共 36 次普通强化选择，另有宝箱的独立奖励。实际觉醒数量与时间需要按新规则试玩验证。
- 神明觉醒后停止提供该神的强化卡，将后续选卡机会留给其他神明、角色武器与通用属性。

### 4. 卡牌种类

| 种类 | 来源 | 说明 |
| --- | --- | --- |
| 神术 | 选神时获得 | 这位神的自动技能 |
| 强化 | 升级四选一 | 每位神 4 个方向，每个可以拿多级，加信仰。只放改变玩法的效果（数量、范围、控制、触发），不放纯伤害 |
| 质变 | 信仰到 6 | 每位神 3 个，只能选 1 个，神术换一种形态；前面的强化跟着换作用方式 |
| 觉醒 | 信仰到 12 | 3 个质变各对应一个觉醒，外加这位神共有的神格被动 |
| 基础武器 | 升级四选一 | 角色武器的强化，不变 |
| 通用属性 | 升级四选一 | 力量、暴击、冷却缩短、幸运等，不加信仰 |

### 5. 融合技

- 两位神**都觉醒**后，立刻弹出他们的融合技（不占用升级）。觉醒后的强化卡禁用不影响融合技；实际获得频率需要按新规则验证。
- 12 个融合技见第四节；没有融合技的组合不会弹出

### 6. 卡池规则

- 每次四选一的 4 张不重复；仍有未觉醒神明的可选强化时，至少 1 张来自这些神明。
- 已经拿满级的强化不再出现；一位神觉醒后，或 4 个方向全部满级后，其强化卡不再出现。普通升级、重抽、宝箱选卡使用相同过滤规则。
- 所有神都觉醒后，继续提供角色武器和通用属性；卡池全部耗尽时使用现有回复生命的保底卡。
- **放逐**（新的永久强化，还没做）：每局可以把一张不想要的卡移出卡池
- **神明的好恶**：洛基害死了巴德尔，两位不会同时出现在同一次选神里（但都信仰时有专属融合技「槲寄生」）

### 7. 通用属性卡

| 卡 | 普通 / 稀有 / 史诗 / 传说 | 说明 |
| --- | --- | --- |
| 力量 | 所有伤害 +10% / 15% / 22% / 30% | 神明强化不放纯伤害，加伤害只靠这张 |
| 暴击 | 暴击率 +5% / 7.5% / 11% / 15%，暴击伤害 ×2 | 所有伤害都能暴击 |
| 冷却缩短 | 所有神术冷却 -5% / 7.5% / 11% / 15% | 神明强化里没有缩短间隔，只靠这张 |
| 急速 | 基础武器冷却 -8% / 12% / 18% / 24% | 只管基础武器 |
| 幸运 | 高稀有度几率 +3% / 4.5% / 6.5% / 9% | |
| 迅捷、体魄、引力、智慧、闪避、再生 | 原数值 × 稀有度倍率 | |

剑士的基础武器卡另有两张：**太刀·震退**（击退距离 +40%，3 级）、**太刀·断筋**（砍中的敌人移速 -20%，持续 2 秒，2 级）。

## 三、八位神明

挑选原则：都是北欧本土神（符合「信仰」的设定）、神话里有鲜明的故事可以做成卡、玩法定位互不重复。

| --- | --- | --- | --- |
| 托尔 · 雷神 | 范围爆发 | 落雷 | 感电 |
| 奥丁 · 众神之父 | 远程精准、印记引爆 | 符文飞弹 | 符文印记 |
| 洛基 · 诡计之神 | 持续伤害、混乱 | 诡火光环 | 灼烧、迷惑 |
| 弗蕾亚 · 爱与战争女神 | 生存、环绕 | 女武神之羽 | 女武神的拣选 |
| 巴德尔 · 光明之神 | 直线贯穿、护盾 | 圣光 | 光痕 |
| 澜 · 海之女神 | 聚怪、控场、召唤 | 澜之网 | 溺水 |
| 弗雷 · 丰饶之神 | 追击、成长、回复 | 自战之剑 | 丰收 |
| 斯卡蒂 · 冬与狩猎女神 | 冰冻减速、狙击 | 霜猎之箭 | 霜冻 |

备选（如果想换掉某一位）：弗丽嘉（命运纺织、护盾）、维达（沉默的复仇者，杀死芬里尔）、伊敦（青春苹果、回复，和弗雷重叠）、乌勒尔（弓箭与雪鞋，和斯卡蒂重叠）。

**神印**是这位神给敌人挂的状态，本身效果很小，主要给质变、觉醒和融合技用（两种神印碰在一起会起反应）。

强化后面的括号是 普通 / 稀有 / 史诗 / 传说 的数值，和这个方向最多能拿几级。

### 托尔 · 雷神

- **神印·感电**：被雷击中的敌人感电 3 秒
- **神术·落雷**：每 2 秒向附近的敌人劈下 1 道雷，范围半径 50

**强化**
1. 风暴：每次多劈 1 道雷；史诗再附带落雷范围 +10%，传说一次多劈 2 道（3 级）
2. 雷域：落雷范围 +12% / 18% / 26% / 36%（4 级）
3. 麻痹：被落雷击中的敌人有 12% / 18% / 26% / 36% 几率麻痹 0.6 秒，停止移动和攻击（3 级）
4. 回响：落雷有 12% / 18% / 26% / 36% 几率在 0.5 秒后原地再劈一次（3 级）

## 五、和其他系统的连接

- **永久强化**：「命运的偏爱」，高稀有度几率 +2%，5 级。
- **图鉴**：强化按 8 位神分组，融合技单独一栏，「发现过的融合技」是收集目标。
- **升级卡插画**：八神普通／觉醒画像和 60 张道路、觉醒、融合独立卡面都已接入。
- **剧情**：洛基借力的伏笔可以和「槲寄生」「安德瓦利」两个融合技呼应。
- **还没做的玩法**：放逐（每局把一张卡移出卡池）、地图上的神像（走过去得到一次只有这位神的选卡）、三神传说（第四节末尾）。

# 技术细节

《哈迪斯》用于参考斜俯视镜头和战斗打击感。北欧篇章的场景美术遵循[苍蓝神话规范](游戏整体美术风格.md)。玩法规则见[游戏设定](游戏设定.md)；局内构筑沿用项目已有的数据（神明、卡牌、装备），按房间制改写后在试玩中迭代。

场景美术采用《哈迪斯》式 2D 手绘背景（2026-11-18 起，替代「脚本建模 + AI 贴图」）。固定斜俯视镜头下，每个房间由一张高精度手绘地面背景、若干前景遮挡层和动态精灵（门、火、传送门、粒子）组成。3D 白盒只用于构图参考和碰撞，不直接出现在画面里。镜头角度、角色尺寸、技能范围和受击反馈使用实机战斗验证。

第一阶段独立搭建「芬布尔之冬 · 冻石庭院」，通过 Godot 主菜单进入。镜头保持固定斜俯角，随角色在房内平滑移动。远景使用较慢的位移产生视差。地形、拱门、遗迹和远景单独制作，战斗和祝福选择接入新房间。角色现在还是旧的像素序列帧，正在换成实时 3D 角色加风格化着色器，见[剑士 3D 试点](Codex_剑士3D试点/README.md)。关卡顺序、房间口径与关底 Boss 以[游戏设定](游戏设定.md)为准。

雪崖前路和中庭属于同一间房。清理前路的普通敌人后可继续前进。角色完全越过中庭门槛后，入口木闸自动落下并封住回头路。击败中庭最后一个敌人时，东侧拱门复原并点亮传送光幕。玩家选完祝福后可通过传送门离场。

现在的冻石庭院是第五版（手绘）：雪崖前路接扩建后的维京祭庭，三处掩体，清场后东侧光门点亮。各轮修改见[制作记录](../assets/source/midgard_courtyard/v5_painted/制作记录.md)。

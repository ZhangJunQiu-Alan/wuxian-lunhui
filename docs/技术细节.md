《哈迪斯》用于参考斜俯视镜头和战斗打击感。美术遵循[苍蓝神话规范](游戏整体美术风格.md)。局内构筑沿用项目已有玩法与数据，在试玩反馈基础上迭代。

场景美术采用《哈迪斯》式 2D 手绘背景（2026-11-18 起，替代「脚本建模 + AI 贴图」）。固定斜俯视镜头下，每个房间由一张高精度手绘地面背景、若干前景遮挡层和动态精灵（门、火、传送门、粒子）组成。3D 白盒只用于构图参考和碰撞，不直接出现在画面里。镜头角度、角色尺寸、技能范围和受击反馈使用实机战斗验证。

第一阶段独立搭建「芬布尔之冬 · 冻石庭院」，通过 Godot 主菜单进入。镜头保持固定斜俯角，随角色在房内平滑移动。远景使用较慢的位移产生视差。地形、拱门、遗迹和远景单独制作，战斗、既有的 2D 角色动画和祝福选择接入新房间。关卡顺序、房间口径与关底 Boss 以[游戏设定](游戏设定.md)为准。

雪崖前路和中庭属于同一间房。清理前路的普通敌人后可继续前进。角色完全越过中庭门槛后，入口木闸自动落下并封住回头路。击败中庭最后一个敌人时，东侧拱门复原并点亮传送光幕。玩家选完祝福后可通过传送门离场。

第三版将庭院重建为临海岩岬。浅石道路穿过冻草和松林，岩体、遗迹和植被集中在路径外沿，开阔中庭用于战斗。模型、碰撞锚点、地形材质和峡湾远景的[制作记录](../assets/source/midgard_courtyard/v3/制作记录.md)随项目保存。

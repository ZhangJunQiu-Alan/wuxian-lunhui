## 规则

- 只有玩家的**武器**触发顿帧和冲击帧，神术不触发（神术持续自动出伤害，触发的话画面会一直卡）。
- 顿帧用 `Engine.time_scale = 0`，计时用不受时间缩放影响的计时器；新的一次直接接管，不叠加。
- 自动测试和挂机压测打开 `player.auto_attack`，顿帧照样生效。

## 还没做

- 敌人还是 2D 像素图（3D 化见[敌人 3D 试点](Codex_敌人3D试点/README.md)），受击表情、受击动作等 3D 模型有了再加。
- 中频「碎裂」层没有单独做，用的是原来的受击声。
- 击杀没有单独的爆裂演出，沿用原来的死亡粒子。

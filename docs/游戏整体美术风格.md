# 游戏美术风格规范 V1.0

## 一、整体美术定位

### 1.1 核心风格定义

**风格名称：苍蓝神话 · 神圣史诗幻想**

英文内部标识：*Azure Mythic Fantasy*

整体风格以古典神话美学为基础，融合超现实主义场景设计、具有雕塑感的角色造型、电影化光影与插画式材质表现。

世界呈现出一种介于真实与幻想之间的视觉状态：建筑拥有可信的结构，人物具有真实的身体比例，石材和金属保留物理质感，但场景尺度、色彩关系和空间构图可以突破现实规律。

**核心视觉公式：**

真实形体结构 + 古典艺术语言 + 超现实尺度 + 高对比色彩 + 插画化材质

### 1.2 核心视觉关键词

| 维度 | 关键词 |
|---|---|
| 整体气质 | 神圣、宏伟、孤寂、神秘、肃穆 |
| 世界环境 | 深海、悬崖、巨像、神殿、星空、遗迹 |
| 建筑设计 | 石质结构、几何秩序、雕刻装饰、历史感 |
| 人物设计 | 英雄主义、雕塑感、精细盔甲、披风 |
| 色彩表达 | 苍蓝、骨白、深黑、古金 |
| 材质表现 | 岩石颗粒、石雕裂纹、金属刻纹、厚重织物 |
| 氛围表现 | 永恒、史诗、超现实、神性压迫感 |

### 1.3 风格边界

本项目不采用以下视觉风格作为整体基础：

- 常规低多边形 Low Poly 游戏风格
- 具有明显玩具感的卡通 3D
- 高饱和、均匀发光的传统魔幻手游风格
- 灰褐色占据全部画面的常规暗黑奇幻风格
- 缺乏统一设计语言的纯写实素材拼接
- 全场景使用粗黑描边的传统卡通渲染

本项目追求的是**具有真实空间结构的精致神话插画视觉**，而非单纯提高模型面数实现照片级写实。

## 二、色彩系统

### 2.1 主色彩

根据参考图中反复出现的海洋、天空、石雕、建筑、盔甲与植被色彩，建立以下建议色板。

| 色彩名称 | HEX | 主要用途 |
|---|---|---|
| 神域深蓝 | `#081B46` | 深海、夜空、背景暗部 |
| 苍穹钴蓝 | `#124CB0` | 天空、海面、神性空间 |
| 高光蔚蓝 | `#246CC4` | 冷光、远景、神力表现 |
| 大理石白 | `#E8E1D2` | 建筑、雕塑、角色浅色织物 |
| 风化石灰 | `#B8B3A7` | 岩石、地面、古老建筑 |
| 深渊黑 | `#10151C` | 暗部、盔甲、深色植被 |
| 古典鎏金 | `#C49B55` | 金属装饰、神性符号、UI 重点 |
| 暗红朱砂 | `#963D3F` | 危险、血量、警示、局部点缀 |

以上为依据参考图视觉特征制定的设计色值，并非对图片进行逐像素取样的结果。

### 2.2 色彩使用原则

**原则一：蓝色是世界的标志性颜色。**

苍蓝并不意味着所有场景都必须充满蓝色。它主要用于天空、海面、背景空间，以及神力相关的视觉表现。

**原则二：白色代表古典秩序与神圣感。**

骨白色建筑、雕像、石阶和角色织物，与深蓝环境形成项目最核心的视觉识别。

**原则三：深黑用于塑造层次。**

黑色盔甲、幽暗树木、深谷、建筑背光面，可以强化白色主体的体积感。

**原则四：金色是高价值的视觉强调色。**

金色适合神明象征、武器关键装饰、稀有奖励及重要 UI，不应在普通资产上大面积滥用。

### 2.3 色彩分配建议

在典型的苍蓝神域场景中，可采用以下初始比例：

- 35% 蓝色环境
- 30% 石白与灰白
- 25% 黑色、深灰及自然暗色
- 10% 金色、绿色、红色等辅助色

此比例只针对展示型场景。战斗房间应根据角色可见度调整，不得机械套用。

## 三、场景与世界环境

### 3.1 场景设计理念

场景不是现实地理环境的直接复制，而是经过神话艺术处理的幻想空间。

自然景观与人造建筑应形成鲜明对比：

**自然环境：** 宏大、原始、不可控制。

**神话建筑：** 几何规整、精密雕刻、象征秩序。

二者结合，创造具有历史厚度和神明存在感的空间。

### 3.2 核心环境元素

小关内共享统一的美术风格，但根据各自的神话背景、环境特征和战斗机制，配置不同的场景元素,下面的场景元素不要全部用上。

#### 环境资产使用原则

1. **模块化复用：** 同一小关内的普通战斗房、精英挑战房、极限生存房等，可以共享地面、建筑、植被、障碍和装饰资产，通过不同布局及机关组合形成差异。

2. **突出地域特征：** 三个小关应具备鲜明的环境识别度。芬布尔之冬以冰雪与寒冬为核心；亡者之船以冥雾、亡灵及世界树根域为核心；最后之战以火焰、毁灭和神话战争为核心。

3. **环境与玩法结合：** 冰裂平台、冥雾、熔岩、符文封印等不仅是视觉元素，还可以作为特殊战斗房和极限生存房的实际机制。

4. **神话巨构用于空间叙事：** 巨型神像、纳吉尔法尔、世界树、彩虹桥等主要作为远景地标和关键剧情场景。普通战斗房间不必单独制作完整巨构，而应通过远景模型、背景层和局部结构复用。

5. **剧情资源嵌入现有房间：** 回忆水晶球作为可交互叙事物件，根据剧情条件在战斗结束后生成，不额外占用房间数量。主线CG和回忆内容可以在图鉴中重新查看。

6. **保证战斗可读性：** 场景中的植被、石柱、建筑和特效不得长期遮挡玩家、敌人或攻击范围。高复杂度装饰优先放置在战斗区域边缘及背景层。

7. **保持整体美术统一：** 三个小关虽然具有不同环境特征，但应统一采用神话巨构、雕塑化造型、高对比光影和插画式材质表现，避免产生三个完全不同画风的游戏区域。

### 3.3 建筑美术规范

建筑应具备以下特点：

**结构：**
- 强调清晰的大型几何结构。
- 通过石柱、拱门、门廊、台阶形成秩序感。
- 建筑体块应具有厚重感，避免轻薄、塑料化。
- 可以使用重复结构表现宏伟尺度，但需增加破损、风化和细节变化。

**表面：**
- 使用浅灰、骨白、暖白色石材。
- 保留雕刻纹样、石材接缝、自然裂纹。
- 通过局部磨损呈现历史感。
- 石材应具有粗糙度变化，而非均匀白色。

**装饰：**
- 使用神话符号、浮雕、祭祀图腾。
- 建筑装饰需符合所在神话区域的文化设计体系。
- 不同文明可以具有共同的美术基调，但不能使用完全相同的建筑语言。

### 3.4 巨构与超现实场景

这是项目最值得重点发展的美术特色之一。

参考图中的山体神面、巨型瀑布、海浪、雕塑和神殿组合，具有强烈的视觉记忆点。

在游戏中可以发展为：

- 山脉内部露出远古神明的面孔。
- 已经死亡的神明化作巨型石雕。
- 瀑布从巨像口中流出。
- 神殿悬浮于海面或峡谷之上。
- 天空中的星河流入山脉。
- 某些道路由巨型武器、骨骼或神明遗骸形成。

巨构主要承担世界观叙事、视觉识别和关卡地标功能，不应为了奇观而牺牲战斗可读性。

## 四、角色美术规范

### 4.1 角色总体造型

角色以真实人体比例为基础，适度强化英雄气质和视觉轮廓。

基本要求：

- 成人角色总体以约 7–8 头身作为设计起点。
- 重要人物可适当夸张肩宽、肢体比例和装备体积。
- 人物轮廓应在斜俯视视角下保持清晰。
- 角色造型不能完全依赖面部和细碎装饰获得辨识度。

### 4.2 盔甲与服装

参考图中最有价值的设计元素包括：

**金属盔甲：** 深色金属底材、鎏金边缘、精细蚀刻、局部高反射。

**织物：** 厚重的浅色披风、深色内衬、自然垂坠的大型褶皱。

**头盔：** 具有鲜明顶部轮廓与文化装饰，同时保证整体形状具有辨识度。

**武器：** 修长、锋利、几何结构清楚，关键部位使用独立装饰符号。

角色设计应强调三个层次：

1. 远距离：依靠剪影识别职业与阵营。
2. 中距离：识别盔甲、披风、武器与主要色块。
3. 近距离：呈现雕刻、金属、皮革及织物细节。

游戏内绝大部分战斗发生于中远距离，因此第一、第二层的优先级应高于微观细节。

### 4.3 角色阵营差异

不同神话文明可以具有独立服装结构和装饰符号，但应共享以下视觉基础：

- 真实的形体结构。
- 明确的大型色块。
- 具有历史感的材质。
- 强烈的冷暖或明暗关系。
- 高识别度的武器和头部轮廓。

### 4.4 角色渲染（2026-11-19 定）

- 本文的「苍蓝神话」是北欧篇章的**场景**风格。可玩角色不要求和场景同一种画风，也不要求四个角色彼此统一。
- 角色是实时 3D 模型，用风格化着色器渲染。每个角色按出身换笔触，共用同一套光照和色板，保证站在同一个场景里不打架。
- 剑士宫本武藏用「墨意东方」：墨色晕染的暗部、干笔飞白的边缘、宣纸纹理，朱砂集中在腰带、刀穗等大色块上。其余三个角色的笔触还没定。
- 第 1.3 节的边界照样适用：不要玩具感的卡通 3D，不要全身粗黑描边。
- 制作流程见[美术与音频素材规范](美术素材规范.md)「角色：实时 3D」。

## 五、材质与渲染风格

### 5.1 核心材质定位

**真实材质基础，插画化最终表现。**

模型表面应具有可信的物理属性，但最终呈现不追求完全中性的真实摄影，而应保留人为设计的色彩层次、明暗节奏和装饰性。

### 5.2 石材

- 保留自然破损、裂纹、颗粒与风化细节。
- 优先使用大、中、小三级纹理层次。
- 通过法线贴图及粗糙度变化呈现结构。
- 避免所有石材使用同一套重复贴图。
- 大型石像必须有明显雕塑体块，而不仅是贴图丰富。

### 5.3 金属

- 黑铁、青铜、银色金属和鎏金为主要类型。
- 金属反射应服务于角色造型。
- 刻纹、浮雕和金属镶边构成主要装饰。
- 避免整套盔甲均匀镜面反射，造成塑料或镀铬玩具效果。

### 5.4 织物

- 优先表达大型褶皱和重量感。
- 布料表面具有细微纹理。
- 运动时强调披风与角色主体的方向关系。
- 避免过度碎裂的褶皱干扰角色识别。

### 5.5 风格化后期

参考图中可见明显的颗粒化、绘画化与高对比处理。

可探索以下后期效果：

- 色彩分级
- 冷暖分离
- 轻微边缘强调
- 有控制的高光压缩
- 局部锐化
- 轻度胶片颗粒
- 细节层次适度简化

**特别约束：** 颗粒感、锐化和强对比是视觉气质，不应全强度叠加于游戏画面。游戏内必须保证角色、敌人、弹幕和交互物品具有清晰的视觉边界。

## 六、光照与氛围规范

### 6.1 光照风格

以具有清晰方向性的主光源为基础，建立强烈但可控的明暗关系。

重点表现：

- 雕塑面部和身体的大型阴影。
- 建筑石柱的明暗节奏。
- 盔甲金属的局部高光。
- 深蓝天空与白色建筑之间的色温对比。

### 6.2 典型光照方案

| 场景 | 光照方向 |
|---|---|
| 海岸神殿 | 偏暖的侧向阳光、冷蓝环境补光 |
| 遗迹内部 | 高处天光、局部火光、深色环境 |
| 神域星空 | 冷蓝主光、银白边缘光、金色神力 |
| Boss 战 | 强化主体轮廓，危险攻击使用独立视觉通道 |
| 叙事空间 | 电影化构图、明显光影方向与焦点 |

### 6.3 可见性要求

即使是黑暗场景，也不应通过让所有区域接近纯黑来制造神秘感。

玩家、敌人、交互物品和危险区域应始终可以被识别。

## 七、斜俯视战斗画面规范

本项目采用固定或受限制的斜俯视观察式视角，战斗设计必须优先满足可读性。

### 7.1 摄像机

- 使用稳定的斜俯视角。
- 第一版可从约 40°–55° 向下俯视的角度测试。
- 建议优先考虑透视较弱的透视投影或正交投影。
- 避免战斗中频繁改变摄像机角度。
- 保持角色在不同战斗房间中的视觉比例基本一致。
- 大房间内镜头随玩家平滑移动。入口、主要战斗区和出口沿途逐步进入视野。

角度需以实际游戏截图和战斗测试确定，不能仅依据概念图。

### 7.2 场景层次

战斗场景划分为四个视觉层次：

**第一层：战斗地面**

材质细节相对克制，确保移动方向、攻击范围和危险区域清晰。

**第二层：角色与敌人**

具有最清楚的轮廓和动作反馈，是玩家注意力中心。

**第三层：环境装饰**

石柱、雕像、树木、祭坛及墙体，提供空间结构和世界观信息。

**第四层：远景巨构**

远处的海洋、山脉、神像、天空及建筑，形成视觉记忆点。

### 7.3 战斗可读性

任何环境特效都不能长期遮挡角色位置、敌人攻击或伤害提示。

技能特效可以华丽，但必须通过形状、颜色、动画时序和亮度建立明确区分。

## 八、UI 与页面视觉规范

2026-11-19 选定本章的方向，替代 11-13 选的「像素复古」。具体样式先出界面样张给制作人选，现有的像素界面（`scripts/ui/ui_kit.gd`）以后替换。

### 8.1 UI 设计方向

**古典碑刻 + 深蓝星图 + 精细金属装饰**

UI 不采用厚重的传统手游式大面积金属边框，也不采用完全脱离世界观的纯科技风格。

整体追求精致、克制、神秘和仪式感。

### 8.2 UI 基础设计

| 组件 | 建议方向 |
|---|---|
| 主菜单 | 深蓝或黑色背景、古典字体、少量金色线条 |
| 生命值 | 深色底槽、明确的红色或其他高识别度填充 |
| 技能图标 | 雕刻图腾、清晰轮廓、统一边框体系 |
| 祝福选择 | 类似古典石板或神谕卡片 |
| 任务面板 | 深色半透明底板、浅色文字、分层排版 |
| 地图 | 星图、古代航海图、石刻符号等视觉元素 |
| Boss 信息 | 具有神话仪式感的标题、纹样和动态反馈 |

### 8.3 文字排版

建议使用双字体体系：

**标题字体：** 具有碑刻、古典铭文气质的字体。

**正文字体：** 易阅读、现代、笔画清楚的字体。

中文界面不应大量使用复杂书法字体，避免影响战斗中的信息获取。

### 8.4 界面动效

界面过渡可以使用：

- 金色纹样逐渐显现。
- 星光沿线条扩散。
- 石板文字缓慢浮现。
- 神话符号旋转、组合与消散。

动效时间应受到控制，常用操作必须能够快速完成。

## 九、不同神话章节的统一性

本项目计划以多个神话故事组织游戏世界。

虽然各章节拥有不同文化背景，但必须共享统一的视觉识别系统。

### 9.1 全局不变的内容

- 真实与幻想结合的形体表达。
- 宏大且超现实的空间设计。
- 强烈的冷暖与明暗关系。
- 精细而具有历史感的材质。
- 具有雕塑感的人物与巨构。
- 克制而精致的 UI 表现。

### 9.2 每个章节可以变化的内容

- 建筑结构与文化符号。
- 服装、盔甲、武器与神话生物。
- 主要自然环境。
- 辅助色系。
- 环境天气与神性力量表现。
- 音乐与特殊视觉效果。

**统一的是艺术语言，不是所有文明的外观。**

## 十、第一大关：北欧神话篇的视觉方向

### 10.1 章节定位

北欧篇不应直接复用参考图中的古希腊石柱、雅典式神殿和古希腊武士装备。

参考图所提供的是色彩、构图、材质与神话尺度的艺术指导，而非北欧建筑和服饰的历史依据。

北欧篇应保留苍蓝、古老、神圣、超现实的整体风格，同时建立自身文化特征。

### 10.2 场景元素

可探索以下视觉组合：

- 深蓝峡湾与高耸断崖。
- 风化的符文石碑。
- 古老木构建筑与石质祭坛。
- 世界树根系形成的自然巨构。
- 被遗忘的神明雕像。
- 悬于山巅的神圣长厅。
- 深色针叶林、苔藓岩石和冰川。
- 星空、极光、神秘天象。

### 10.3 建筑语言

以北欧木构建筑、长厅、石质纪念物及相关神话图腾为文化设计起点。

重点特征包括：

- 厚重木梁与石质地基。
- 富有节奏感的屋顶结构。
- 兽首、交织纹样与符文雕刻。
- 强烈的竖向轮廓。
- 具有风雨侵蚀痕迹的表面。

允许幻想化夸张，但应避免将古希腊神殿简单更换名字后作为北欧建筑。

### 10.4 场景标志性奇观

第一章建议至少设计一个具有原创识别度的主视觉奇观。

例如：

**世界树下的苍蓝峡湾**

一座巨型远古神像被嵌入悬崖，树根穿过山体和废墟，冰蓝色水流从断裂的神像胸口倾泻而下。

玩家在山腰遗迹中战斗，远景可看见古老神殿、深蓝海湾和贯穿天空的巨大树枝。

此概念属于初步原创提案，不是已经确定的世界设定。

## 十一、美术制作验收标准

所有角色、场景和重要道具需进行风格一致性检查。第一阶段用「芬布尔之冬」的一间普通战斗房做实机验证。审核网站逐项展示游戏实拍、3D 场景、2D 美术与战斗反馈，最终结论由制作人手工填写。

**模型：**
- 基本比例合理。
- 大型轮廓清晰。
- 具有独特设计而非简单基础几何拼接。
- 能够适配游戏镜头及动画需求。

**材质：**
- 颜色符合所属章节的调色体系。
- 石材、金属、织物具有不同质感。
- 纹理密度和细节层级一致。
- 无明显重复纹理和不自然的贴图接缝。

**场景：**
- 具有清晰视觉焦点。
- 地形及建筑形成可信空间。
- 远景奇观能够体现世界观。
- 环境装饰不干扰战斗。

**整体效果：**
- 画面具有统一的艺术语言。
- 玩家角色及敌人具备足够辨识度。
- 光影和后期处理具有节制。
- 在目标设备上满足性能要求。

## 十二、最终美术指导原则

**原则一：艺术统一性高于单个模型的复杂度。**

高精度模型如果无法融入统一的色彩和光照体系，也不应直接使用。

**原则二：轮廓与形体高于细碎装饰。**

优先设计远距离可辨认的人物、建筑和地标。

**原则三：神话感来自尺度、秩序与超现实关系。**

不应单纯依靠增加发光粒子、魔法符号和高饱和颜色体现神性。

**原则四：世界观通过环境表达。**

建筑遗迹、神像、地形与神话奇观应共同承担叙事功能。

**原则五：游戏体验高于静态截图。**

任何美术效果最终都必须在真实战斗中验证，不能只以概念图或宣传图的精美程度判断是否合格。

**项目最终追求：**

让玩家在进入游戏的第一眼，就能够识别出一种独特的神话世界：

苍蓝的天空与海洋、古老的白色石质遗迹、宏伟而不可思议的神明巨构、穿行其间的英雄，以及隐藏在壮丽景观背后的衰亡与命运。

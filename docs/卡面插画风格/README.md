# 卡面插画风格

2026-11-19。用户让检查选神、升级卡上的插画（`assets/sprites/cards/`，81 张，2026-10 由 Codex 用 ImageGen 画）是否符合现在的美术风格，不符合就重画。

## 现有插画的问题

对照 [游戏整体美术风格](../游戏整体美术风格.md)：

1. **色调不对**：整体是灰褐、暗棕加金黄色的暴风云天空，正好是规范「风格边界」里排除的「灰褐色占据全部画面的常规暗黑奇幻风格」。规范要的是苍蓝、骨白、深黑、古金，高对比。
2. **质感脏**：全画面同一种锐化过度的碎笔触，毛皮和下半部分糊成一片噪点；天空有方块状的笔触，像旧的像素时期。规范要「真实材质基础，插画化最终表现」，精致、克制。
3. **构图雷同**：几乎每张都是正面、仰视、半身居中、下半截全黑（为了垫文字）；弗蕾亚、巴德尔、弗雷都是手按胸口。缺规范里的「雕塑感」「超现实尺度」「神性压迫感」。
4. **角色卡画风不统一**：剑士、刺客、枪手、法师四张是日式动漫脸，和神像不是一种画法，也和已经定稿的 3D 剑士（墨意东方）对不上。角色卡跟着各角色自己的 3D 试点重做，不在这次范围。

## 做法

先试画法再批量：三种画法 × 三位神（托尔、奥丁、斯卡蒂）共 9 张，放到验收网站给用户选；选定后用同一套提示词重画 8 位神的基础像和觉醒像，再画质变、融合技、通用属性卡（共 76 张，不含 4 张角色卡和 `general.png` 以外的角色相关图）。

## 三种画法

| 版本 | 名字 | 想法 |
| --- | --- | --- |
| A | 神像雕塑 | 神像如同苏醒的巨型古典雕像：骨白大理石的皮肤和衣褶、古金镶嵌、刻纹盔甲，苍蓝天空和冷光，强烈明暗。最贴「雕塑感」「巨像」「大理石白」。 |
| B | 电影厚涂 | 写实人体加干净、有控制的厚涂笔触，大块冷暖对比；神以超现实尺度出现在环境里（托尔立在雷云之上、斯卡蒂俯视雪山），不再是贴脸半身。 |
| C | 古典神话油画 | 像 19 世纪学院派神话油画（彼得·尼古拉·阿尔博一类的北欧神话画）：罩染、柔和过渡、克制的苍蓝与古金，庄严肃穆。 |

三种都必须：苍蓝、骨白、深黑、古金为主色，每位神的标志色只用在神力上（托尔冷蓝电光、奥丁淡紫符文、斯卡蒂冰白霜气）；不要灰褐满屏，不要满画面碎笔触，不要动漫脸。

## 规格

- 1024 × 1536 竖图（现在的卡是 720 × 1200，按新界面再裁切）。
- 脸在画面中上部的中央区域，方便以后裁成圆形徽章；神的标志物（锤、矛与渡鸦、弓）完整可辨。
- 下三分之一保持较安静、偏暗，但仍是画面的一部分（地面、云海、雪坡），不是一块黑。
- 三位神的长相延续现有卡面（托尔红发红须、奥丁独眼宽檐帽长须、斯卡蒂银白长辫猎人），方便玩家认出来。

## 产出

- `A_神像雕塑/{thor,odin,skadi}.png`、`B_电影厚涂/…`、`C_古典油画/…`
- `对比.png`：3 × 3 拼图，加一列现有卡面对照。
- `说明.md`：工具、每张实际用的完整英文提示词、每种画法的优缺点、批量重画时的一致性风险。

2026-11-19 用户选 **B 电影厚涂**。按 B 的提示词重画 77 张（8 位神的基础像与觉醒像、24 张质变及其觉醒、12 张融合技、`general.png`）；剑士、刺客、枪手、法师 4 张角色卡不在这次范围。

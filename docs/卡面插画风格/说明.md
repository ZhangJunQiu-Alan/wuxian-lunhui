# 卡面插画风格试画说明

## 工具与范围

使用内置 ImageGen，分别以现有对应神明卡面作为人物辨识参考；使用 Python Pillow 统一输出尺寸并排版对比图。九张图均为 1024 × 1536。对比图中的现有卡面按原比例缩入，不裁切。C 版奥丁初稿的矛尾被遮挡，采用下列附加要求重新生成，交付的是重画结果。

## 方向评价

- **A 神像雕塑**：骨白石材、苍蓝环境和巨像尺度最贴近项目核心；代价是人物容易趋于同一种雕像材质，红发和其他身份特征需要单独控制。
- **B 电影厚涂**：人物与辽阔环境的结合和动态光影较强；笔触与细节密度容易失控，部分画面依然接近原卡的正面半身构图。
- **C 古典油画**：罩染、柔和光影与庄严感适合神话叙事；对比和蓝色强度较柔和，容易偏暖、偏暗，C 奥丁重画后背景也较简略。

**推荐 A**：石质形体与苍蓝、骨白、深黑的关系最直接呼应项目的神性巨构。先让制作人选择方向，再以获选样图建立风格基准；这些样张不是最终美术验收结论。

## 批量制作 76 张

先固定获选风格的色板、主光方向、构图边界、材质密度和负面约束，建立经人工确认的基准图；每位神再建立发型、面部、标志物及神力颜色参考。按神明和卡类分批生成，逐批与基准及相邻卡对照；保留提示词、参考图、版本及重画记录。以缩略图、圆形头像裁切及实际卡面裁切分别检查辨识度，逐张放大检查手指、武器、眼部、文字和水印，再由制作人验收。

风险：参考图可能把旧构图和旧细节一并带入；同一提示词不能保证角色长相、光照和笔触稳定；武器连接、手指及符号可能生成错误；裁切会损失标志物；神像材质可能削弱不同人物身份。觉醒、融合和通用属性卡还需要各自的视觉规则，不能只机械替换角色名称。

## 本批检查与局限

目视检查了九张的独眼、锤子、弓及弓弦，未见明显文字或水印；部分手指有自然遮挡，不能仅凭图像确认每根手指，最终使用前应逐张放大复核。C 奥丁的矛现已露出两端，但背景较暗且下部以衣袍为主；部分画面仍接近原作的仰视半身，三种画法的差异和最终裁切效果须由制作人决定是否足够。

# 第 1 关地图设计：芬布尔之冬（米德加尔特）

> 「第三个没有夏天的冬季。村庄被白雪掩埋，坟墓一座座裂开，死者从冰下爬了出来。」

## 一、基本规格

| 项目 | 数值 |
| --- | --- |
| 地图大小 | 4608 × 4608 像素（72 × 72 块 64×64 的地块），约 3.6 × 6.4 个屏幕 |
| 出生点 | 地图正中央的十字路口 |
| 边界 | 四边都是天然屏障，玩家和怪物都过不去；镜头走到边缘会停住 |
| 地标 | 6 处，支线固定出现在对应地标 |
| 坐标 | 地图中心为 (0, 0)，向右为 x 正，向下为 y 正 |

数值写在 `scripts/data/level_db.gd` 的 `NORSE_1.map` 里，地面和物件的摆放写在 `scripts/world/midgard_map.gd`。现在用的是第 4 批的首批素材（7 种地块、13 种物件），屏障带暂时用压暗的冰面、枯松和乱石代替，等边界素材交付后替换。

## 三、各区域细节

目标是**真实、有生活过的痕迹**：每个区域都要让玩家看得出「这里曾经发生过什么」。

### ⓪ 十字路口（出生点）
- 两条冻土小路十字交叉，路面有车辙和被雪半盖住的脚印
- 中央一块刻着符文的路标石，旁边一辆翻倒的手推车，散落的木桶和麻袋
- 路边几根歪斜的木桩路标，指向四个地标

### ① 被雪掩埋的村庄
- 6~8 座维京长屋：有的只剩屋脊露出雪面，有的屋顶塌陷、只剩木框架
- 木栅栏围着村子，好几处被撞断
- 村子中央的水井（冻住了）、晾鱼架、劈柴墩和斧头、空荡荡的羊圈
- 熄灭的篝火堆（支线的篝火在这里点燃）
- 门口散落的盾牌和断矛：这里打过仗

### ② 峡湾码头
- 伸向冰海的木码头，一半被冰挤碎
- 半埋在冰里的维京长船残骸，龙头船首还露在外面
- 系船木桩、渔网、翻倒的小船、堆在岸边的木箱
- 冰面上有巨大的脚印通向东方（霜巨人从冰海那边来）

### ③ 奥丁的符文石阵
- 一圈 8~10 块高大的符文立石，围成圆形，中间是石砌祭坛
- 祭坛上有献祭用的角杯和干枯的槲寄生
- 立石之间散落着渡鸦的黑色羽毛
- 地面颜色更深，雪很薄：这里有某种力量

### ④ 古老的墓丘
- 5~6 座隆起的墓丘（长满枯草的土丘），其中几座**裂开了**，露出黑洞
- 船形石阵墓（立石排成船的轮廓，北欧真实存在的墓葬形式）
- 倒下的墓碑、生锈的陪葬剑、散落的骨头
- 地面有从墓里爬出来的拖痕：尸鬼就是从这里来的

### ⑤ 冰湖
- 大片开阔的冰面，比雪地更亮、更平滑，有放射状的冰裂纹
- 湖心冻着一条小渔船，湖边有冰钓的洞和遗落的鱼竿
- 冰面下隐约可见冻住的鱼和水草的暗影
- 开阔、没有障碍：适合在这里风筝怪物，也是打 Boss 的好地方

### 区域之间的过渡
- 小路连接各地标，路边点缀：枯松、灌木、岩石、雪堆、倒下的树干、狼的脚印、乌鸦停在枯枝上
- 零散的战场痕迹：插在雪里的剑、破盾、冻僵的马
- 不要每一格都塞满：留出大片干净的雪地，玩家要有空间走位，装饰物太密会看不清怪物

### 边界
| 边 | 屏障 | 要点 |
| --- | --- | --- |
| 北 | 峡湾冰崖 | 雪地边缘是陡峭的冰壁，往下看得到深色的峡湾海水 |
| 东 | 冰封的海 | 岸线是破碎的浮冰，冰海一直延伸到画面外；远处隐约有巨人的影子 |
| 西 | 枯松林 | 密集的枯死松树，越往外越密、越暗，最后完全看不进去 |
| 南 | 山脚岩壁 | 灰色的岩壁和落石，岩缝里结着冰 |

## 四、玩法规则

- **碰撞**：大型物件（长屋、长船残骸、立石、墓丘、大岩石）会挡住玩家和怪物；小物件（木桶、骨头、羽毛、脚印）只是装饰，可以穿过
- 碰撞物不能把路堵死；地标之间至少有两条通路，避免玩家被怪物堵在死角
- **遮挡**：高的物件（枯松、长屋）在玩家走到它后面时变成半透明，不能挡住玩家和怪物
- 地面装饰的颜色要比角色暗、对比度低，同屏几百只怪时也要能看清

## 五、制作分工

1. **素材**（Codex，任务书第 4 批）：地块、物件、边界、地面贴花
2. **拼地图**（Claude）：在 Godot 里用 TileMapLayer 铺地面，按本文档摆放物件，加碰撞和遮挡
3. **验收**（用户）：实际玩一局，看地图是否真实、走位是否顺畅，再调整

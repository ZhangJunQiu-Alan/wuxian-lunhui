# 无限轮回 — 开发路线图

> 类吸血鬼幸存者 + 局外成长 + 多角色 + 局内 Boss + 支线任务 + 「无限恐怖」式世界关卡制
> 引擎：Godot 4（GDScript），在 Mac 上开发，导出 Windows 版

## 世界观与关卡结构

完整设定见 [世界观设定.md](世界观设定.md)。

- **主神空间**（局外大厅）：选择角色、花「奖励点」做永久强化、选择篇章
- **篇章**（世界）：一个独立题材，分 **3 个关卡**；每关 **2 个小 Boss + 1 个大 Boss**；第 3 关的大 Boss 是篇章最终 Boss
- **单关节奏**（15 分钟）：05:00 小 Boss 1 → 10:00 小 Boss 2 → 14:00 大 Boss，期间随机触发支线
- 结算：奖励点（局外货币）+ 支线剧情点（解锁新角色、新篇章）

| 篇章一：诸神黄昏 | 小 Boss 1 | 小 Boss 2 | 大 Boss |
| --- | --- | --- | --- |
| 1. 芬布尔之冬（米德加尔特） | 斯库尔 · 追日之狼 | 哈提 · 逐月之狼 | 赫列姆 · 霜巨人之王 |
| 2. 亡者之船（赫尔海姆） | 加姆 · 冥府猎犬 | 尼德霍格 · 噬根之龙 | 海拉 · 冥界女王 |
| 3. 最后之战（维格利德） | 耶梦加得 · 尘世巨蟒 | 芬里尔 · 魔狼 | **苏尔特 · 黑焰之王（最终）** |

后续篇章候选：西行（西游记）、封神、山海经、奥林匹斯、百鬼夜行

## 信仰系统（升级三选一）

- 升级时暂停，三选一。卡牌分三类：
  - **人物基础武器**：强化角色自带的武器（宫本武藏是太刀）
  - **通用属性**：力量、迅捷、体魄、引力、急速、智慧（经验）、闪避、再生
  - **神明卡**：获得或强化神明技能，增加该神的信仰
- 第一次升级必定是「选择你的第一份信仰」：只出神明技能卡
- 多神自由混搭：选哪位神的卡，就给那位神 +1 信仰（上限 5）
- 一局最多信仰 **3 位神**（加上角色的初始武器），信满 3 位后其他神的卡不再出现
- 某位神信仰满 5 后，必定出现该神的**觉醒卡**（终极强化）
- 「信仰」是北欧篇章的叫法，其他篇章会有各自的说法和规则。北欧世界的四位神：

| 神明 | 技能 | 强化 | 觉醒 |
| --- | --- | --- | --- |
| 托尔 · 雷神 | 落雷：劈向附近敌人的范围伤害 | 伤害、数量、间隔 | 雷神之锤：伤害翻倍 + 连锁 3 个敌人 |
| 奥丁 · 众神之父 | 符文飞弹：射向最近的敌人 | 数量、穿透 | 冈格尼尔：无限穿透、数量 +2、伤害 +50% |
| 洛基 · 诡计之神 | 诡火：身边的灼烧光环 | 范围、伤害 | 诸神黄昏之火：范围 +50%、伤害翻倍 |
| 弗蕾亚 · 爱与战争女神 | 女武神之羽：环绕羽刃 | 数量、转速 | 弗尔克范格：羽刃 +3、每秒回血 +3 |

所有卡牌数据都在 `scripts/data/upgrade_db.gd`，加新卡只需要在表里加一行，再在 `apply()` 里写效果。

## 开发阶段

每个阶段结束时游戏都应该能玩，做完一个再进入下一个。

- [x] **阶段 0：环境** — 安装 Godot，创建项目
- [x] **阶段 1：核心循环** — 移动、刷怪、自动攻击、经验宝石、血量、死亡重开
- [x] **阶段 2：升级三选一 + 信仰系统** — 初始武器太刀；升级三选一；北欧四神的技能、强化与觉醒；最多信仰 3 位神
- [x] **阶段 2.5：大招系统** — 击杀充能、空格释放；宫本武藏的次元斩与被动二天一流
- [x] **阶段 3：敌人扩充与刷怪节奏** — 第 1 关四种敌人（含远程冰霜精魂）、敌人互相推挤、精英怪、按时间轴配置的刷怪表与包围事件；所有攻击只在敌人进入范围时出手
- [x] **阶段 4：战斗反馈** — 伤害数字（暴击金色大字）、按重量击退、受击闪白放大、死亡碎片、玩家受伤红屏与震屏；素材自动接入（按文件名替换占位图形）
- [x] **阶段 5：局内 Boss** — Boss 框架（状态机、技能预警、血条、登场与击败、宝箱）；第 1 关斯库尔、哈提、赫列姆；击败赫列姆通关
- [x] **阶段 5.5：大招特写** — 释放大招时右上角滑入角色「最璀璨的时刻」、台词与大招名；内置开源中文字体
- [x] **阶段 6：支线任务** — 支线框架（光柱标记→接受→限时目标→奖励）、右侧任务面板、屏幕边缘指向箭头；第 1 关三个支线；结算显示奖励点与支线剧情点
- [ ] **阶段 7：角色系统** — 角色数据与选人界面；安妮·奥克利、兰陵王、梅林的武器、被动和大招
- [x] **阶段 8：局外成长** — 存档（user://save.json）；主神空间（启动画面）：奖励点、战绩、9 项永久强化（含命运重抽、主神的眷顾复活）；奖励点来源：每分钟 +10、Boss +100/150/300、通关 +300、支线；死亡也保留全部奖励点
- [ ] **阶段 9：世界框架** — 世界数据（敌人表、Boss、支线、主线、地图），世界选择，主线任务通关结算
- [ ] **阶段 10：美术与音效** — 按 [美术素材规范.md](美术素材规范.md)：✅ 定为像素风、第 1 关敌人与 Boss 静态素材接入（程序动画、影子、精英外观、帧条自动切帧）；待做：主角、地面、Boss 蓄力姿势、特效、音效与 BGM
- [ ] **阶段 11：菜单与设置** — 主菜单、暂停、音量、分辨率、全屏
- [ ] **阶段 12：发布** — 导出 Windows exe，测试，（可选）上架 Steam

## 项目结构

```text
project.godot          项目配置
scenes/main.tscn       战斗主场景
scripts/core/          全局模块（save_data.gd 存档，自动加载为 Save）
scripts/game.gd        战斗总控（刷怪、计时、结算）
scripts/data/          数据表（神明、升级卡牌、敌人、关卡刷怪表）
scripts/entities/      玩家、敌人、经验宝石
scripts/weapons/       太刀、子弹
scripts/skills/        神明技能（落雷、符文飞弹、诡火、羽刃）
scripts/ultimates/     角色大招（次元斩）
scripts/bosses/        Boss（boss.gd 是基类，每个 Boss 一个文件）
scripts/quests/        支线剧情（side_quest.gd 是基类，每个支线一个文件）
scripts/effects/       特效
scripts/ui/            界面
assets/                素材（图片、音频、字体、源文件，走 Git LFS），授权台账 LICENSES.md
docs/                  设计文档
```

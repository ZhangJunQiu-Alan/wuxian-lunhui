# 无限轮回 — 开发路线图

> 类吸血鬼幸存者 + 局外成长 + 多角色 + 局内 Boss + 支线任务 + 「无限恐怖」式世界关卡制
> 引擎：Godot 4（GDScript），在 Mac 上开发，导出 Windows 版

## 世界观框架

- **主神空间**（局外大厅）：选择角色、花「奖励点」做永久强化、选择要进入的世界
- **世界**（关卡）：每个世界是一个独立题材，有自己的敌人、Boss、支线和主线任务
- **主线任务**：主神发布，例如「存活 15 分钟」或「击败芬里尔」，完成即通关
- **支线剧情**：局内随机触发的小任务，奖励更多奖励点 / 稀有道具
- 结算：奖励点（局外货币）+ 支线剧情点（解锁新角色、新世界）

## 第一个世界：诸神黄昏 · 米德加尔特

| 类型 | 内容 |
| --- | --- |
| 普通敌人 | 尸鬼 Draugr（慢、肉）、狼（快、脆）、冰霜巨人（大体型、慢、高伤）、黑暗精灵（远程） |
| 精英 | 狂暴狼人 Úlfheðnar、霜巨人督军 |

| 最终 Boss（15 分钟） | 巨狼芬里尔 Fenrir：冲锋、撕咬、狂暴阶段 |

## 信仰系统（升级三选一）

- 升级时暂停，三选一。卡牌分三类：**太刀强化**、**通用属性**、**神明卡**
- 第一次升级必定是「选择你的第一份信仰」：只出神明技能卡
- 多神自由混搭：选哪位神的卡，就给那位神 +1 信仰（上限 5）
- 某位神信仰满 5 后，必定出现该神的**觉醒卡**（终极强化）
- 每个世界有自己的本土神，北欧世界的四位神：

| 神明 | 技能 | 强化 | 被动 | 觉醒 |
| --- | --- | --- | --- | --- |
| 托尔 · 雷神 | 落雷：劈向附近敌人的范围伤害 | 伤害、数量、间隔 | — | 雷神之锤：伤害翻倍 + 连锁 3 个敌人 |
| 奥丁 · 众神之父 | 符文飞弹：射向最近的敌人 | 数量、穿透 | 智慧之泉：经验 +15% | 冈格尼尔：无限穿透、数量 +2、伤害 +50% |
| 洛基 · 诡计之神 | 诡火：身边的灼烧光环 | 范围、伤害 | 幻影：15% 闪避 | 诸神黄昏之火：范围 +50%、伤害翻倍 |
| 弗蕾亚 · 爱与战争女神 | 女武神之羽：环绕羽刃 | 数量、转速 | 生命女神：每秒回血 | 弗尔克范格：羽刃 +3、每秒回血 +3 |

所有卡牌数据都在 `scripts/data/upgrade_db.gd`，加新卡只需要在表里加一行，再在 `apply()` 里写效果。

角色草案：狂战士（近战旋风斧）、女武神（长矛穿透）、符文法师（符文飞弹，初始角色）、游侠（弓箭散射）

## 开发阶段

每个阶段结束时游戏都应该能玩，做完一个再进入下一个。

- [x] **阶段 0：环境** — 安装 Godot，创建项目
- [x] **阶段 1：核心循环** — 移动、刷怪、自动攻击、经验宝石、血量、死亡重开
- [x] **阶段 2：升级三选一 + 信仰系统** — 初始武器太刀；升级三选一；北欧四神的技能、强化与觉醒
- [ ] **阶段 3：武器池** — 4~6 种武器（飞弹、环绕斧、雷锤、冰霜光环……），每种可升到 5 级；用 Resource 文件做数据驱动
- [ ] **阶段 4：波次与难度** — 按时间轴配置刷怪表，敌人互相推挤，精英怪，性能优化（对象池）
- [ ] **阶段 5：局内 Boss** — Boss 状态机、技能、血条、击败奖励宝箱
- [ ] **阶段 6：支线任务** — 任务系统框架（触发→目标→计时→奖励），实现 2~3 个北欧支线
- [ ] **阶段 7：角色系统** — 角色数据（初始武器、属性、被动），选人界面
- [ ] **阶段 8：局外成长** — 存档（user://），奖励点，主神空间永久强化，解锁
- [ ] **阶段 9：世界框架** — 世界数据（敌人表、Boss、支线、主线、地图），世界选择，主线任务通关结算
- [ ] **阶段 10：美术与音效** — 替换几何图形为像素图 / 序列帧，受击特效、伤害数字、BGM 和音效
- [ ] **阶段 11：菜单与设置** — 主菜单、暂停、音量、分辨率、全屏
- [ ] **阶段 12：发布** — 导出 Windows exe，测试，（可选）上架 Steam

## 项目结构

```text
project.godot          项目配置
scenes/main.tscn       战斗主场景
scripts/game.gd        战斗总控（刷怪、计时、结算）
scripts/data/          数据表（神明、升级卡牌）
scripts/entities/      玩家、敌人、经验宝石
scripts/weapons/       太刀、子弹
scripts/skills/        神明技能（落雷、符文飞弹、诡火、羽刃）
scripts/effects/       特效
scripts/ui/            界面
docs/                  设计文档
```

# 选神界面样张说明

这是《诸界余烬》的选神界面概念图。A、C 并排显示三位神的技能。B、D 默认展开托尔的详情，鼠标悬停在奥丁上时展开奥丁的详情。

## 返工合成方法

沿用 `生成底图/` 中的四张无字 ImageGen 原图。Pillow 在 1672 × 941 的底图坐标下抠出界面元素，再缩放到 1920 × 1080 的成品画布。场景整层使用 `输入/游戏背景.png`，统一压暗，对三处 HUD 区域做局部柔化、去色和降亮度，让地名、血条、击杀数、信仰格和原操作提示沉到遮罩下。

| 版本 | 素材合成 | 奥丁悬停 |
| --- | --- | --- |
| A 立石神谕 | 分别抠出整块石碑，保留厚边、绳结、雪和底座。原卡面沿拱形画框裁切，文字放在原图的磨平石面上。 | 中间石碑略上移、放大并盖在最前。提取原刻纹的亮部做淡紫发光。 |
| B 星穹罗盘 | 保留原圆徽及边上的金属饰件，从原图提取金弧和星座线的亮部。下方保留原面板的外形、线纹和山脊纹饰，轻压底色。 | 中间徽章放大并加淡紫光晕，下方显示「符文飞弹」及描述。 |
| C 神殿挂幡 | 抠出雕龙木梁和三面尖底挂幡，用色差细化流苏边缘。原卡面贴入各自幡面，叠加同一块布的纹理，画面下沿渐隐入布。 | 中间布幡以挂杆为支点向右下摆，原有金绣线提亮。 |
| D 神谕法典 | 整本书沿外轮廓抠出，保留皮封、装订、圆框、渡鸦和书页底部预留的进度饰件。原卡面按左右页的圆框分别裁切。 | 第二行以淡紫高亮标记，右页更换原卡面及技能详情。 |

标签统一使用普通空格与间隔点「神明 · 托尔 · 雷神」，收去字体在间隔点两侧自带的空白。数字 1、2、3 按实际字形边界在圆圈内水平和垂直居中。标题和技能使用 macOS 宋体，描述用简体华文黑体。成品中的描述至少 22 px，技能名至少 36 px。

运行需要 Python、Pillow、脚本中指定的 macOS 字体，以及源背景、三张卡面和四张生成底图。修改 `排字.py` 中的文案后执行下列命令，会覆盖八张样张。

```bash
python3 docs/选神界面样张/排字.py
```

## 各方向评估

| 版本 | 优点 | 缺点 | Godot 实现估计 |
| --- | --- | --- | --- |
| A 立石神谕 | 三项信息同时可见，石碑符合祝福选择与北欧主题。 | 长描述和稀有度会挤占石板；需要制作石材和绳结切片。 | 中等：Control 容器与 StyleBoxTexture / NinePatchRect 构造石碑；符文发光可用 CanvasItem shader。 |
| B 星穹罗盘 | 星图识别度强，详情面板可容纳更长文字与进度。 | 同时只能阅读当前选项的详细技能，需要移动焦点比较。 | 中高：Control 排节点，圆形头像使用遮罩 shader，星线和弧线用绘制或纹理；焦点驱动详情更新。 |
| C 神殿挂幡 | 木雕和织物传达北欧长厅气氛，三项能直接对比。 | 暖色容易与冷色战斗场景冲突，长文与窄幡存在空间压力。 | 中高：Control 排列幡面，StyleBoxTexture / NinePatchRect 表现织物；悬停绣线可用 shader，木梁需独立素材。 |
| D 神谕法典 | 信息层级清楚，详情可扩展稀有度、信仰进度及觉醒。 | 三项详细技能需要逐项查看；占屏面积较大。 | 中等：左侧列表与右侧详情使用 Control 和 StyleBox；纸面微光可选 shader，切换焦点需适配键鼠。 |

推荐 **D 神谕法典**：同一面板需要承载选神、强化、信仰与觉醒，列表加详情的结构对不同长度和额外字段更有余量；同时应在键盘切换时同步高亮和更新详情。最终美术方向仍由制作人选择。

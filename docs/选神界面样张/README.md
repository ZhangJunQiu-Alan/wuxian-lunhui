# 选神界面样张

2026-11-19。剑士 3D 试点验收时用户提出：选神界面要重新设计，先出几版不同样式，由用户选定后再做进游戏。

- 界面代码：`scripts/ui/level_up_panel.gd`（选神、升级强化、道路、觉醒、融合技共用这一个面板）。
- 现在的样子：`输入/现在的界面.png`（暗色遮罩上两张圆角卡，上半是插画，下半是文字）。
- 美术方向：[游戏整体美术风格](../游戏整体美术风格.md)第八章「古典碑刻 + 深蓝星图 + 精细金属装饰」，精致、克制、有仪式感，不要手游式的大面积金属边框，也不要纯科技风。祝福选择「类似古典石板或神谕卡片」。

## 界面要放的内容

样张统一用开局选第一位神的情况，三位神：

| 按键 | 标签 | 技能名 | 描述 |
| --- | --- | --- | --- |
| 1 | 神明 · 托尔 · 雷神 | 落雷 | 每 2 秒向附近的敌人劈下一道雷，被劈中的敌人感电 |
| 2 | 神明 · 奥丁 · 众神之父 | 符文飞弹 | 向最近的敌人发射符文。符文印记叠到 3 层时引爆 |
| 3 | 神明 · 斯卡蒂 · 冬与狩猎女神 | 霜猎之箭 | 每 1.8 秒向最远的敌人射出穿透的冰箭。霜冻叠到 5 层时冻结 |

另外：标题「选择你的第一位神」，每张卡底部小字「新的神明（一局最多 4 位）」，按钮「重抽选项（剩余 1 次）  [R]」，底部提示「点击卡牌或按数字键选择」。每位神有自己的颜色：托尔冷蓝、奥丁淡紫、斯卡蒂冰白。插画用现有卡面 `assets/sprites/cards/thor.png`、`odin.png`、`skadi.png`。

同一个面板以后还要放升级强化（带稀有度：普通、稀有、史诗、传说）、信仰进度「信仰 2 → 3 / 10」和觉醒卡，所以样式要能装下这些变体。

## 四个方向

| 版本 | 名字 | 想法 |
| --- | --- | --- |
| A | 立石神谕 | 三块竖立的符文石碑。深灰蓝石面，边缘刻北欧绳结纹，插画像嵌进石里的彩绘画板，技能名用细金线描刻，描述写在打磨平整的石面上。鼠标移上去时石上的符文亮起该神的颜色。 |
| B | 星穹罗盘 | 屏幕上方一道细金线的星盘弧，三位神是挂在星盘节点上的圆形徽章（插画裁成圆），节点之间连着星座线。下方一块深蓝半透明面板，显示鼠标所指那位神的完整信息。 |
| C | 神殿挂幡 | 一根雕龙木梁（和庭院大门同一种北欧木雕）横在上方，三面窄长的布幡挂下来，插画像织在布上，金线滚边；文字写在幡的下半段。颜色比其他版本暖，有木和布的质感。 |
| D | 神谕法典 | 左边一列三行紧凑条目（圆形头像、神名、称号、按键），右边一大块详情页：大插画、技能名、描述、以后放信仰进度的位置。信息最清楚，像翻开的一本神谕书。 |

## 产出

- `A_立石神谕/样张.png` ……`D_神谕法典/样张.png`：1920 × 1080，盖在 `输入/游戏背景.png` 上（背景压暗）。
- 每版一张 `悬停.png`：鼠标停在第 2 张（奥丁）时的样子。
- `说明.md`：用了什么工具、完整提示词、每版的优缺点和做进 Godot 的难度。

样张是概念图，不是 Godot 截图。用户选定后再由 Claude 做进 `level_up_panel.gd`。

## 决定

2026-11-19 用户选 **A 立石神谕**，并要求：

- 选项按品质分颜色（游戏里已有的四档：普通白、稀有蓝、史诗紫、传说金），品质越高特效越华丽。
- 鼠标悬停不改颜色，改成一个动效。

实现：石碑框素材由 Codex 出（石面底图 + 刻纹蒙版），品质颜色和特效、悬停动效由 Claude 在 Godot 里用着色器和粒子做。

选定后删除了 B、C、D 的样张和底图，只留 A（`A_立石神谕/`、`生成底图/A.png`）；四版的描述和取舍见上表和 `说明.md`。游戏里的实现：`scripts/ui/level_up_panel.gd`、`scripts/ui/stele/`，素材 `assets/sprites/ui/stele/`（源文件 `assets/source/ui_stele_2026-11-19/`）。2026-11-19 实机版验收通过。

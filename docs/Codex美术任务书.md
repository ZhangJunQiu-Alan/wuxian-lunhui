## 二、工作权限、参考与交付

1. 素材 Agent 只写自己任务的 `assets/` 文件，不改 `scripts/`、`scenes/`、`docs/`、`project.godot`、导入设置，不执行 Git 提交或推送。代码接入交给集成 Agent。
2. 每个任务使用独立目录 `assets/source/taskH0_critical_YYYY-MM-DD/`、`taskH1_skoll_fx_YYYY-MM-DD/` 等；不得清理、覆盖其他任务的目录。覆盖既有成品前保存旧文件及哈希。
3. 先读 [美术素材规范](美术素材规范.md)、[世界观设定](世界观设定.md)和本任务对应 Boss／支线脚本；参考正式素材及该角色已归档的制作记录，保持同角色、同配色、同画风。H0 的女巨人参考 `enemies/frost_giant.png`、`frost_veteran.png` 的尺度和材质，但必须是可辨识的老年女巨人。
4. 沿用已批准的内置图像工具；新动作以项目已有图为输入参考。提示词写外形、服装、材质和动作，不写真实或传说人物名，不参考影视、游戏、漫画角色或画师。Pillow 仅用于裁帧排帧、检查和预览，不用来重画角色。

6. 每项交付：正式 PNG；原图与失败候选；实际提示词、参考图、工具与来源记录；`manifest.json`；`README.md`；`gallery.html`；逐帧与播放预览；`integration.md`。不提交 ZIP。

## 三、统一规格与验收

- 所有路径以项目根目录为起点；H/I 的尺寸和名字是本次新增的交付约定。表中尺寸均为**单帧**；横向帧条，无间距，例如 4 帧 64×32 输出为 256×32。
- PNG RGBA、透明背景。角色、实体道具、锁链节：alpha 仅 0/255；光、烟、地面区域可用半透明，但不得有底色、白边、文字或水印。
- 像素风，深色背景 `#121721` 上可读；沿用参考素材调色板，默认不超过 48 色。半透明特效分别记录 RGB 颜色数和 alpha，不能用 alpha 变化冒充新颜色；需要例外时写明原因。
- 角色／实体光从左上方来；会旋转的抽象光效不要画固定方向的投影。人物、生物、弹体默认朝右；人物所有帧脚底和躯干中心固定，四周至少留 2 像素。
- 角色移动 8 fps 循环、攻击 16 fps 单次。特效按表指定；8 fps 循环无跳变；单次效果有清楚的发生、峰值、衰减，不通过重复同帧凑帧数。
- 默认锚点中心；人物锚点脚底中心，最终坐标记录在 manifest。定向喷吐／拖尾／锁链的特殊锚点见表。
- 每条动画提供原速和 8 fps 慢放预览，至少检查 1 倍、4 倍、深色背景；角色另做静态图并排和脚底基线检查。区域、弹体另做实际范围叠加、旋转／拉伸预览。
- 技能预警与实际伤害边界必须一致；安全缺口、背后可攻击区和安全圈不能被美术遮住。预警几何、判伤、冷却、AI、控制效果继续由原代码负责。
- H0～I6 的“制作完成”只指文件与制作记录交付；“自检通过”需实际逐帧检查。“代码接入”“游戏验收”由集成 Agent 后续记录，不能借用历史文档的验收声明。

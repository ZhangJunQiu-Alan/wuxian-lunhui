1. 先读[素材规范](美术素材规范.md)、[世界观](世界观设定.md)、实际Loader和对应批次最终manifest/integration；先核实是否已有合格资源。
2. 像素实体透明RGBA、二值alpha、限定色板、近邻和稳定脚锚；非方帧/区域/安全区以最终契约为准。保留原速/慢放、逐帧和实际几何检查，不以图库代替游戏画面。
3. 商用许可核验后再使用新来源，记录assets/LICENSES.md；需要新登录、注册、付费或授权不清时询问用户。人物只按史实/神话和本项目设定，不复制其他作品角色。
4. 记录真实Prompt、参考、原图、退稿原因、批准文件、哈希和接入说明；未运行/未试听的项目不标通过。

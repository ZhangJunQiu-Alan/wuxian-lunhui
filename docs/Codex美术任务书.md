# Codex 美术任务书：动画、素材修复与地图

你是这个游戏项目的美术制作代理。请使用 Chrome 浏览器自行寻找合适的网站和工具，完成下面所有素材。**游戏品质第一**：宁可多花时间反复修改，也不要交出「差不多」的东西；每一项都要走完「制作 → 自检 → 不合格就重做」的流程，不要省略任何步骤。

- 开始前**必须先读**：

  - `docs/世界观设定.md`：每个关卡、Boss、支线的背景描述
  - `docs/角色设定.md`：宫本武藏等角色设定
  - `assets/LICENSES.md`：授权台账
- **风格基准**：`assets/source/norse_pixel_2026-10-16/` 里的 23 张像素精灵（64×64 小怪、128×128 Boss），总览见 `assets/source/norse_pixel_2026-10-16_overview.png`。新素材的画风、调色、描边、光照方向都必须和它们一致，放在一起不能看出是两批东西
- 游戏画面：1280×720，深色背景（#121721），像素画**按 1 倍整数显示**。画布尺寸就是游戏里的显示尺寸
- 美术风格已确定为像素风；AI 生成内容已允许使用，上架时会披露

## 一、硬性规则

1. **只在 `assets/` 目录里工作**。不要修改 `scripts/`、`scenes/`、`docs/`、`project.godot`，不要执行 `git commit` / `git push`。另一个代理（Claude）正在同时修改代码，素材由它审核、接入游戏、实测后再提交
2. 中间文件、候选图、原图放在 `assets/source/<批次名>_<日期>/`；**通过自检的最终文件**按第四节的命名放进 `assets/sprites/` 对应文件夹。覆盖 `assets/sprites/` 里已有的文件前，确认旧文件在 `assets/source/` 里有备份
3. **不要提交 zip**，也不要把 zip 放进 `assets/`
4. **授权**：使用任何网站或工具前，先确认其条款允许**商用**并且产出归用户所有。每个工具和每批素材都在 `assets/LICENSES.md` 里记录：来源、工具、授权、链接、日期。条款不明确时**停下来问用户**
5. **账号与付费**：需要登录、注册、付费或升级套餐时，**停下来问用户**，不要自己注册，不要输入任何付款信息
6. **避免侵权**：宫本武藏只参考史实（江户初期剑客，二天一流，1612 年巌流岛决斗时约 29 岁）。**不要参考**《浪客行》《Fate》《王者荣耀》《仁王》等作品里的武藏形象，也不要在提示词中出现这些作品名或任何其他游戏、动漫角色的名字。所有北欧神话角色同理，不参考《战神》等游戏的形象
7. **不要虚报**：README 里只写你实际做过、实际检查过的内容。「游戏内验收」由 Claude 负责，你不要声称已在游戏中测试

## 二、工具建议（请自行搜索和比较，选最适合的）

- 生成造型：ChatGPT 图像生成（上一批素材就是用它做的）。生成新动作时，**上传现有素材作为参考图**，要求保持同一角色、同一配色
- 像素化：Pixel Asset Studio（https://pixel-asset-studio.com/ ，已确认可商用）。上一批的设定：调色板 Source，颜色预算 32，无抖动，清理透明边缘，1 倍导出
- 逐帧动画：请搜索带「动画 / 行走循环 / 动作帧」功能的 AI 像素工具（例如 PixelLab 等），比较效果和授权后再选
- 修帧和拼帧：浏览器里的像素编辑器（例如 Piskel：https://www.piskelapp.com/ ），用于逐帧修正、对齐基线、统一调色板、导出横向帧条
- **AI 很难一次生成前后一致的帧**。必须逐帧检查轮廓、配色、体型是否一致，不一致就在像素编辑器里手动修正，或重新生成

## 三、质量门槛（每张、每条动画都要逐项自检）

**通用**
- [ ] 尺寸精确；PNG、RGBA；背景真正透明；透明度只有 0 和 255（没有半透明的边缘杂色）
- [ ] 画风、调色、描边和 `norse_pixel_2026-10-16` 一致；同一角色的所有动作配色完全一致
- [ ] 主体**朝右**；主体在画布中水平居中，**脚底基线在所有帧里位置相同**，四周至少留 2 像素
- [ ] 把成品放到 #121721 深色背景上按 1 倍查看：轮廓清楚，和背景对比足够
- [ ] 没有文字、水印、签名、背景场景

**动画**
- [ ] 横向帧条：每帧是正方形，从左到右排列，帧之间没有间隔
- [ ] 首尾帧衔接流畅，循环播放时没有跳帧、抖动、闪烁
- [ ] 每一帧的体型、比例、细节一致，不会忽胖忽瘦
- [ ] 为每条动画导出预览 GIF（8 帧/秒，放大 4 倍）

**地块**
- [ ] 平铺 4×4 后**看不出接缝**，没有明显重复的图案
- [ ] 地块颜色比角色暗、对比度低，不能抢角色的视觉（角色必须在地面上清楚可见）

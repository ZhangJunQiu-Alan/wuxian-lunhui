你是这个游戏项目的美术与音频制作代理。请使用 Chrome 浏览器自行寻找合适的网站和工具，完成下面的素材。**游戏品质第一**：宁可多花时间反复修改，也不要交出「差不多」的东西；每一项都要走完「制作 → 自检 → 不合格就重做」的流程，不要省略任何步骤。

## 一、硬性规则

1. **只在 `assets/` 目录里工作**。不要修改 `scripts/`、`scenes/`、`docs/`、`project.godot`，不要执行 `git commit` / `git push`。另一个代理（Claude）正在同时修改代码，素材由它审核、接入游戏、实测后再提交
2. 中间文件、候选图、原图放在 `assets/source/<批次名>_<日期>/`；**通过自检的最终文件**按第四节的命名放进 `assets/sprites/` 或 `assets/audio/` 对应文件夹。覆盖 `assets/sprites/` 里已有的文件前，确认旧文件在 `assets/source/` 里有备份
3. **不要提交 zip**，也不要把 zip 放进 `assets/`
4. **授权**：使用任何网站或工具前，先确认其条款允许**商用**并且产出归用户所有。每个工具和每批素材都在 `assets/LICENSES.md` 里记录：来源、工具、授权、链接、日期。条款不明确时**停下来问用户**
5. **账号与付费**：需要登录、注册、付费或升级套餐时，**停下来问用户**，不要自己注册，不要输入任何付款信息
6. **避免侵权**：角色只用职业称呼（剑士、枪手、刺客、法师），**提示词里也不要写任何真实或传说人物的名字**，只描述时代、服装和气质。**不要参考**《浪客行》《Fate》《王者荣耀》《仁王》《战神》等作品里的同类角色，也不要在提示词中出现这些作品名或任何其他游戏、动漫角色的名字
7. **不要虚报**：README 里只写你实际做过、实际检查过的内容。「游戏内验收」由 Claude 负责，你不要声称已在游戏中测试
8. **多个任务同时进行**：可能有几个 Codex 同时做不同的任务。每个任务只动自己的文件和自己的 `assets/source/` 文件夹；`assets/LICENSES.md` 只在末尾追加自己任务的一节，每次写之前重新读一遍，不要覆盖别人刚写的内容

## 二、工具（前几批实际用过、已确认可商用）

- 生成造型：ChatGPT 图像生成、内置图像工具（用户已批准）。生成新动作时，**上传现有素材作为参考图**，要求保持同一角色、同一配色
- 逐帧修正和拼帧：Piskel（https://www.piskelapp.com/ ）。逐帧修正轮廓、对齐基线、统一调色板、导出横向帧条
- 像素化：Pixel Asset Studio（https://pixel-asset-studio.com/ ）。调色板 Source，颜色预算 32，无抖动，清理透明边缘，1 倍导出
- Pillow 只用于尺寸、透明度、调色板检查、裁帧排帧和预览，不要用它重画角色
- **AI 很难一次生成前后一致的帧**。必须逐帧检查轮廓、配色、体型是否一致，不一致就手动修正或重新生成

## 三、质量门槛（每张、每条动画都要逐项自检）

**通用**
- [ ] 尺寸精确；PNG、RGBA；背景真正透明；透明度只有 0 和 255（没有半透明的边缘杂色）
- [ ] 画风、调色、描边和风格基准一致；同一角色的所有动作配色完全一致，颜色从它的静态图调色板里取
- [ ] 主体**朝右**；主体在画布中水平居中，**脚底基线在所有帧里位置相同、和静态图相同**，四周至少留 2 像素
- [ ] 把成品放到 #121721 深色背景上按 1 倍查看：轮廓清楚，和背景对比足够
- [ ] 没有文字、水印、签名、背景场景

**动画**
- [ ] 横向帧条：每帧是正方形（特效按给定尺寸），从左到右排列，帧之间没有间隔
- [ ] 循环动作（idle、move）首尾衔接流畅，没有跳帧、抖动、闪烁
- [ ] 每一帧的体型、比例、细节一致，不会忽胖忽瘦
- [ ] 游戏按**每秒 8 帧**播放（攻击动作每秒 16 帧）。为每条动画导出预览 GIF（8 帧/秒，放大 4 倍）
- [ ] 刀光、爪痕、冲击波、魔法光等**特效由程序绘制**，不要画进角色帧里

**地块**
- [ ] 平铺 4×4 后**看不出接缝**，没有明显重复的图案
- [ ] 地块颜色比角色暗、对比度低，不能抢角色的视觉（角色必须在地面上清楚可见）

**音频**
- [ ] 音效：WAV，16 位，44.1 kHz，单声道；开头没有静音（声音在 10 毫秒内响起），结尾自然衰减到 0，没有爆音、削波
- [ ] 音效响度统一：峰值 -1 dBFS；同类音效放在一起连续播放时，听不出哪个特别响或特别轻
- [ ] 每秒会响很多次的音效（命中、刀光、开枪、拾取经验）要短（0.3 秒以内）、不刺耳，连续听 1 分钟也不烦；每种做 3 个略有差别的版本 `_01`~`_03`，游戏会随机挑
- [ ] 音乐：OGG Vorbis，44.1 kHz，立体声，整体响度约 -16 LUFS；循环曲**首尾无缝**（把结尾接回开头连播 3 遍，听不出接缝）
- [ ] 同一篇章的音乐听起来是一套：乐器、混响、音色一致
- [ ] 为每个音频文件记录：时长、峰值、响度、来源

#### G4、G5：神术特效（像素）

放在 `assets/sprites/effects/gods/`（新文件夹）。像素风，规则和第三节一样，风格参考 `assets/sprites/effects/` 里已有的 `lightning.png`、`rune_missile.png`、`feather_blade.png`、`will_o_wisp_aura.png`。

- 「帧」写了数字的是横向帧条（例如 2 帧 24×24 就是 48×24 的 PNG），按每秒 8 帧播放（野猪每秒 12 帧）；没写的是单张
- 「朝向」：会旋转的东西（战锤、长枪、光矛、飞剑、冰箭）一律**朝右**画；会左右翻转的生物（渡鸦、幼狼、战猫、野猪）**朝右**画
- 「锚点」是游戏把这张图对准位置的那个像素（从左上角数），例如长枪的锚点在枪尖附近，画的时候枪尖要落在这个点上
- 「会缩放」的图（地面区域、光束、浪）会按技能范围放大缩小，不是整数倍。这类图用简单、边缘干净的形状，不要细碎的像素细节；**允许半透明**（地面区域整体要淡，不能盖住敌人）

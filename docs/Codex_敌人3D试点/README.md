# 敌人 3D 试点

剑士已经是实时 3D 模型（见[剑士 3D 试点](../Codex_剑士3D试点/README.md)），敌人还是旧的 64 像素像素画，放在一起不统一。先做冻石庭院里出现的两种敌人：**尸鬼**（draugr）和**冰霜精魂**（ice_spirit），流程跑通后再铺开到其他敌人和 Boss。

## 总体流程

| 阶段 | 内容 | 谁做 | 验收点 |
| --- | --- | --- | --- |
| 1 | 每种敌人 3 个设计方案：全身立绘 + 画进实机截图的游戏视角样张 | Codex（ImageGen） | 用户各选一个 |
| 2 | 选定方案的三视图（正、侧、背，A-pose，不带武器的另出一张） | Codex（ImageGen） | 用户确认 |
| 3 | Tripo 图片转 3D，Blender 修整 | Codex 出模型，Claude 修 | 模型转台 |
| 4 | 绑骨和动作：待机、移动、攻击（尸鬼近战挥砍 / 精魂施法射冰锥）、受击、死亡 | Codex 下载动作，Claude 转换 | 动作预览 |
| 5 | 接入 Godot，替换庭院里的像素敌人，墨意着色器、受击反馈 | Claude | 实机录像，测试全过 |

## 设定依据

- **尸鬼 Draugr**：死后不得安息、从墓丘爬出的古代战士。慢、血厚，近战（`docs/世界观设定.md`）。旧像素图是穿破皮甲、拿斧子的壮硕尸体。
- **冰霜精魂**：风雪中凝结的怨灵。远程，发射冰锥；飘浮移动（`gait: float`）。旧像素图是冰蓝色、半透明、飘带状的人形。
- 美术规范：`docs/游戏整体美术风格.md`（苍蓝、骨白、深黑、古金；真实形体 + 插画化材质；不要灰褐满屏、不要卡通、不要粗黑描边）。
- 游戏里所有 3D 角色都用同一个墨意着色器（低饱和、两级明暗、轮廓略加深、细纸纹），所以设计要靠**剪影和明暗块**区分，不要靠细碎花纹。参考 `01_设计方案/参考图/实机近景.png`（3D 剑士在庭院里的样子）。

## 尺寸

- 剑士身高 1.5 个世界单位（模型 1.8 m）。尸鬼要比剑士高大：约 1.15 倍（模型 2.1 m），肩宽、体块重。冰霜精魂飘在离地约 0.3 m 处，身高约 1.1 倍，下半身是拖尾的风雪，没有脚。
- 庭院正常镜头下剑士约 120 像素高，敌人一眼要能和剑士、背景分开：尸鬼偏深色厚重，精魂偏亮、冷蓝、半透明。

## 规则

- 每个阶段做完停下来等验收。
- Codex 只用 ImageGen 和本地 Python（阶段 1、2）；阶段 3、4 才用默认浏览器上 Tripo、Mixamo，账号、邮件、聊天、系统设置都不动；遇到验证码、付款、绑卡就停。
- 原创设计，不模仿现有游戏或影视作品里的具体角色。
- Tripo、Mixamo 的原始下载只留本机，不进仓库（Mixamo 不允许单独再分发原始动作）。

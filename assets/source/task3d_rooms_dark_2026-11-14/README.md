# 芬布尔之冬深暗废墟样式

按用户 2026-11-14 的黑暗画风反馈制作本批。八件模块采用冷灰石材、焦木、低饱和积雪与橙色符文。模型倒角收窄，地面增加裂纹，积雪改为不规则薄片，门板与立柱增加伤痕。场景灯光采用冷色主光与低强度暖色边光。

可编辑源文件和预览在本目录，游戏 GLB 位于 assets/models/midgard/rooms_dark/。清单网页 docs/芬布尔之冬模型清单/index.html 默认展示深暗样式，可切换原版对照，两组审核记录独立保存。

生成八件模块使用 build_dark_assets.py，生成同布局对照场景使用 assemble_dark_room.py。两份脚本复用上一批的建模模块和材质生成函数。GLB 保留四组活动部件动画，陷阱、坠落和机关联动等待玩法接入。

本批为画风评审变体。室内环境光、实时火光和角色照明需要在实际战斗镜头中共同调整。

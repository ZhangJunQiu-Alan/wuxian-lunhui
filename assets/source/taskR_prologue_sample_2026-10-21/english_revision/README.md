# 英语旁白与动态混音修订

目标：三关配音全部为英语；原画、关卡剧情、默认中文字幕保留。叙述者为文字设计的深沉、略沙哑、英国英语男声，逐段表演从压抑预兆推向宣告。只借鉴史诗序幕的叙事力度，不复制其他游戏台词、音乐或演员声音。

## 制作与来源

- Qwen3-TTS-12Hz-1.7B-VoiceDesign，Apache-2.0；MLX Community 4bit转换同为Apache-2.0；MLX-Audio推理代码MIT。
- 纯文字设计音色，无真人录音或第三方声音参考。使用免费公开权重本机生成，无账号、付款或收费API。
- `records/narration_plan.json`保存12条英语台词、原中文字幕、英语字幕和实际表演指令；`records/generation.json`保存原始语音参数、seed、时长、哈希。
- `originals/`保留原始英语WAV；`candidates/`保留语气比较；`before/`保留被替换的中文成品、时序、视频和交付记录。
- `records/build_english.py`按真实语音长度调整镜头，音乐在说话期间自动让位，句尾恢复；不通过降低整段播放速度伪造深沉音色。
- 音乐和音效复用原R已核验CC0来源；没有引入其他游戏音频。

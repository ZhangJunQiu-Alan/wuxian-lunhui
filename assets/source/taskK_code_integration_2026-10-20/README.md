## 5. 压力 / 长时

`tools/stress_vigrid.gd`，本机真实窗口。玩家无敌、不移动，只有角色武器（开局随机的神术已移除，保证可比）。350 个混合普通敌人（亡者 110 / 狂狼 100 / 火巨人 80 / 精锐 60，每秒补满）分别配一个 Boss，每段 25 秒：

| 场景 | 修复前 p50 / p95 | **最终 p50 / p95 / p99（ms）** |
| --- | --- | --- |
| 只有 350 敌人，没有 Boss | — | 29.9 / 50.7 / 64.8 |
| + 耶梦加得 | 33.0 / 53.1 | 30.1 / 37.0 / 59.3 |
| + 芬里尔 | 31.7 / 52.1 | 27.8 / 45.9 / 56.8 |
| + 苏尔特（直接压到 25%，火墙和 64 格同时在跑） | **131.8 / 172.4** | 31.6 / 51.9 / 66.5 |

修复前苏尔特那一行很慢，原因是火墙圆外红色区域、火墙条带和终焉之火都是逐段、逐格绘制。合成一次提交（`BossFx.draw_quads`）、不安全格按行合并之后，和没有 Boss 时基本一样。耶梦加得的身体和地图边界火带也改成了一次提交。

反复进出关卡 4 次：节点 267、静态内存 76.4MB，没有增长，孤儿节点 0；退出后敌人和火焰都是 0。

350 敌人时本机约 30ms/帧，这是普通敌人本身的负载，前两关用的是同一套机制。这里没有和前两关做同条件的对照，目标设备上的性能也没有测。

注意：完整流程和压力测试跑完之后，代码又改了两处，都只是删掉 K6 事件表以外的音效（插剑的 boss_slam、弗雷登场的 awaken），然后重跑了专项测试、截图和全部回归。完整流程和压力测试没有重跑。

## 8. 第三版（同日）：用户指定 Boss 血量，耶梦加得加招，美术对比图

用户要求：三个 Boss 的血量按出场时间算是 3000 / 5000 / 12000；耶梦加得「只会绕圈喷毒，太傻」，要优化攻击方式；美术任务书配上图片对比。

**耶梦加得新的攻击方式**（数值见 design_decisions §3，都是暂定值；冻结规则没动：只有蛇头能受伤、蛇身撞飞、环绕收紧每次 ≤128、托尔 90 秒）
- **按距离选招**：游完一段后，玩家近就喷毒息，远就猛噬；同一招最多连出 2 次。以前站远一点就完全安全。
- **猛噬**：
  - 蛇头离开路径冲向玩家，身体拉成一条横穿场地的颈（颈也能撞人）。
  - 蓄力时淡黄预警条跟着玩家转，最后 0.3 秒变红锁定，横向走开就能躲。
  - 扑空后咬进地里 1.6 秒，期间受到的伤害 ×1.5，近战也打得到。之后缩回路径。

- **狂怒**：低于 50% 血量一次：游得更快、毒液弹更多、猛噬落点留毒雾。

## 复现

```sh
S=<scratchpad>; R=$S/k_runtime   # 从项目 rsync，排除 .git、assets/source、build、.godot、validation；Boss 测试另外拷 H 规格 JSON，卡面测试另外拷 card_ids.json
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path $R --log-file /dev/null --import
$G --headless --path $R --log-file /dev/null --script tools/test_vigrid.gd -- --save-file=user://k_vigrid.json --settings-file=user://k_settings_zh.cfg --output=$S/out
$G --path $R --log-file /dev/null --script tools/review_vigrid.gd -- --save-file=user://k_review.json --settings-file=user://k_settings_zh.cfg --output=$S/shots
$G --path $R --log-file /dev/null --script tools/playthrough_vigrid.gd -- --save-file=user://k_play.json --settings-file=user://k_settings_zh.cfg --output=$S/play
$G --headless --path $R --fixed-fps 60 --log-file /dev/null --script tools/playthrough_vigrid.gd -- --save-file=user://k_play2.json --settings-file=user://k_settings_zh.cfg --output=$S/play2
$G --path $R --log-file /dev/null --script tools/stress_vigrid.gd -- --save-file=user://k_stress.json --settings-file=user://k_settings_zh.cfg --output=$S/stress --seconds=25
```

`k_settings_zh.cfg` 是一份 `language="zh"` 的独立设置文件。不指定设置文件时会跟随系统语言，在英文系统上卡面测试会因为 UI-01 失败。

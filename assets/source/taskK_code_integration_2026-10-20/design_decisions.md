# 第三关代码集成：设计暂定项

日期：2026-10-20（同日第二版：用户要求加强 Boss 和后期小怪，改过的项标了第一版的值。第三版：用户指定三个 Boss 按出场时间算的血量 3000 / 5000 / 12000，并要求耶梦加得的攻击方式不要只是绕圈喷毒）。下面的数值都是**暂定值**，没有经过用户批准，原文和 K 契约都没有给出。它们集中在 `scripts/data/vigrid_tuning.gd`（`VigridTuning`），改数值只改这一个文件；刷怪表在 `scripts/data/level_db.gd` 的 `NORSE_3`。

冻结的规则直接照契约实现，不属于暂定：
- 托尔 90 秒：只算巨蛇本场遭遇的未暂停时长，含 90.0，不含 90.001。
- 芬里尔吸引阶段通道至少 64。
- 终焉之火格子 64，原点 (0,0)，格坐标 floor。
- 苏尔特在 60% 和 25% 各触发一次。
- 维达：奥丁信仰并且奥丁觉醒。
- 弗雷：弗蕾亚信仰并且弗蕾亚觉醒。
- 三命运和洛基标记只会从 false 变成 true；命运数只算三个命运。

## 8. 画面上的取舍

- **K 素材的脚锚**：K 素材按契约把脚锚对齐到 root + (0, 20)，影子也画在那里。前两关的素材保持原来的居中摆放，没有改。
- **路面辨识度**：维格利德 6 张地块的平均颜色完全相同（都是 38,31,32），焦土小路和焦草斑块在实际画面里几乎看不出来。没有用程序提亮，已交给 Codex（`docs/Codex_第三关美术优化任务.md` M-ART-01）。
- **苏尔特剑弧**：按扇形半径放大约 4.8 倍，像素颗粒偏粗。已交给 Codex（M-ART-02）。
- **洛基的火**：复用的绿火只在这一份材质实例里把色相改成 0.04，饱和度、明度、透明度不变，洛基原来的神术不受影响。
- **合批绘制**：火墙、蛇身、边界火带都合成一次三角形提交（`BossFx.draw_quads`）。逐段绘制时，350 只敌人加上苏尔特终焉之火阶段，实测 p50 从 125ms 降到 32ms。
- **蓄力音效**：Boss 基类原来就会给每个 `*windup` 状态放 `boss_windup`。芬里尔的扑咬、苏尔特的横扫也因此有蓄力声，这两处不在 K6 的 25 事件表里。狂奔的准备状态改名为 `run_prep`，避开这条规则，所以狂奔开始时只放事件表规定的 `boss_howl`。

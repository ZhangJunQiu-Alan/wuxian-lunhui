## 退回与修复记录

1. 高清站姿并非原生 64×64，带半透明边缘。保留原图；比较最近邻、BOX、LANCZOS 三种采样，采用最近邻；裁掉透明噪点，统一 32 色、人物 48 像素高、水平居中、基线 y=59。
2. 第一轮待机改变脸部、鞋和衣纹，不能仅做呼吸。第二轮虽减少了动作幅度，局部像素仍漂移；两轮均保留，AI 原始待机不通过。随后在 Chrome 免费 Piskel 以已通过站姿为底稿，手工修正为 A-B-C-B 四帧呼吸循环；导出 v05 后逐像素核对修帧计划，四帧零偏差，头脸与脚不变，32 色、二值透明、基线 y=59。v04 导出曾有 13 个误选色像素，v05 已在 Piskel 补齐；中间视口变化造成的错位笔触已通过保存工程恢复，没有进入 v05。
3. 第一轮跑步左右手脚没有清楚交替。第二轮后两帧改变躯干朝向，接回首帧时跳动；两轮均保留，AI 原始跑步不通过。随后在 Piskel 锁定侧脸并逐像素修正：v04 的动作主要依靠前后肢明暗交换，未通过；v05 重画前摆手臂但缺少中间过渡，未通过；v06 在第 3、6 帧加入腰侧摆臂过渡。六帧均朝右，头脸固定、脚底 y=59、二值透明、既有 32 色子集，导出像素与修帧计划零偏差。已在 Chrome 查看 GIF。
4. 倒地原图上下两排未按图像中线等分，最初等分切帧会截断上排脚部、把残片带入下排。改用实际排间空白 y=640 切分后，以同一比例处理全部六帧并对齐地面；没有逐帧单独缩放来掩盖比例差异。
5. 受击采用同一比例处理两帧，使恢复站姿回到 48 像素体量，受击屈身帧自然略矮；基线相同。
6. 特写裁为眼部到面部的近景，并保留同一人物的发色、服装与视线。基础 32 色不足以保留眼部高光，增加来自该特写原图的阴影/肤色及眼白高光，形成最多 48 色的批次调色板；精灵用色为该调色板的子集。

# K5：燃烧平原地图素材

交付 2 张新 PNG、共5帧。沿用K0布局；12种过渡复用旧遮罩运行时派生，6地块、5场景物件、环境火焰、边界与神明援助复用已有素材。不是一套已接入的可玩地图。

- `giant_tread`：64×64静态，中心(32,32)，烧灰足迹贴花，24RGB/8级alpha。内置图像工具实际生成的原图、Prompt和结果记录均保存。
- `distant_battle`：512×128×4横排，8fps循环，24RGB/8级alpha。由K2维达、K3弗雷、K4巨人和已有特效在独立Godot窗口合成，近邻0.5倍缩放、暖灰低饱和；未生成新人物。只放在不可走的北侧远景带，不能算敌人或剧情死亡。

已查看焦土合成、16角点过渡板、四帧远景板、脚印8倍图与修正后的完整边界渲染；边界首轮因窗口裁切被拒绝，记录保留。程序逐项检查见records/final_audit.json。6地块有4×4平铺预览，接缝统计只辅助检查，不证明任意混铺都无缝。

预览不代表第三关运行验收。尚需地图加载器、世界坐标布局、遮罩加载、可走边界、相机远景裁切和援助控制器接入；碰撞、密集场景和完整流程未测。来源、哈希、复用路径及余项见manifest和integration。没有修改正式代码或提交Git。

# 补给系统接入契约

用户已授权正式接入、验收、commit/push。本轮两种道具自动安装到所有已实现关卡，不需要新场景或项目设置。规则集中在`scripts/data/supply_db.gd`，这些数值是首版调参值。

| 项目 | 蜜酒 | 聚魂符石 |
|---|---|---|
| 作用 | 回复8生命，不超过上限；满血保留 | 吸取触发瞬间已存在、归属于当前玩家且尚未被吸引的经验 |
| 首次允许时间 | 20秒 | 60秒 |
| 两次掉落最短间隔 | 35秒 | 90秒 |
| 随机概率 | 每次合格击杀2.5% | 每次合格击杀0.8% |
| 无掉落保底 | 距上次掉落75秒或累计40次合格击杀 | 150秒或120次合格击杀 |
| 场上数量上限 | 2，含延迟入树预留名额 | 1，含延迟入树预留名额 |
| 留存时间 | 120秒，最后10秒闪烁 | 同左 |

- 首次时间、掉落冷却、场上上限优先于保底。保底只在下一次合格击杀产生；不会凭空出现在玩家脚边。场上已有补给占满上限时保底等待空位。
- 普通怪、精英通过现有`Game.enemy_killed`信号触发；Boss、`still`支线结构和零经验单位排除；不改敌人死亡、神术治疗及宝箱逻辑。使用独立RNG，不抽取现有战斗随机流。
- 掉落位置位于死亡点，经活动范围夹取、脚部障碍推出后再核实，不可达位置拒绝生成且不重置保底。
- 两种道具均由玩家进入26像素距离主动取得，不随拾取范围被远程吸走。重复回调同帧只生效一次；死亡、结局阶段不能取得。
- 聚魂只遍历`xp_gems`组。经验自行飞向玩家并按原规则结算，不能吸走苹果、金羽、金泪、蜜酒、宝箱、支线物件；不增加后续掉落的吸取范围。空场不消耗符石，满40级停止新掉落且不消耗已有符石。
- 不新增任何Boss伤害、控制、护盾或清怪能力；后续清怪符石必须对精英/Boss单独限制，不能跳过阶段机制。护盾及清怪符石尚未制作。

接入文件：`scripts/world/supply_drops.gd`负责掉落节奏与上限；`scripts/entities/run_supply.gd`负责展示/拾取；`scripts/entities/xp_gem.gd`新增入组及一次性吸取入口；`scripts/game.gd`仅新增安装一行；`locale/text.csv`新增回血/聚魂提示英译。

测试入口：`tools/test_run_supplies.gd`（独立存档、三关/可用关卡功能与供给模拟），`tools/review_run_supplies.gd`（独立存档、实际Game受控截图）。提交候选与工作区分别测试；具体结果、失败尝试与验收限制见README和RESULTS。

# 剑士武器特效与逐把反馈复核

总览逐把评价中读到 10 条有文字的反馈，太刀栏无文字。修订后的 PNG 继续用横向帧条。除了新增莫邪普攻和太刀的可选新版刀光，现有帧数、帧速、锚点、半径和扇角沿用本批清单。初始游戏里的太刀刀光仍在原文件路径。

| 武器 | 本轮处理 |
| --- | --- |
| 太刀 | 新版银白双层回锋，原刀光和旧帧还原继续保留。 |
| 村正 | 暗红刃线配浅粉回锋、断续残丝和飞屑。 |
| 物干竿 | 栗棕鞘靠肩收拢并补可见肩扣。燕翼式双层刀光，刀尖单独高亮。 |
| 断水 | 青色水壁加白沫、波纹和落水碎片。 |
| 髭切 | 普攻偏银白，鬼化为绯红交叉刃线。 |
| 干将莫邪 | 新增副手反切六帧。预览按干将暖金、莫邪霜蓝交替出招。 |
| 诛仙四剑 | 发剑期间角色身体保持待机。剑尖最远约 102 px，示范命中点放进 110 px 近战范围，随后收剑。四剑的金、绯、紫、墨轨迹分别可看。 |
| 青龙偃月刀 | 待机用右手立持。横扫、旋风、重劈各有青色鳞纹和碎光。 |
| 湖中剑 | 入鞘和空鞘都做尖头。刀光改银蓝配金线，闪光仍跟同一鞘口。 |
| 日月双刀 | 日刀刃身收窄。日刀为暖金横扫，月刀为冰蓝窄刺，预览交替可看。 |
| 纯阳剑 | 背鞘靠肩重挂并补肩扣。普攻是清白剑气，饮酒和醉步用较小的金色碎光。 |

[总览](index.html)顶部「新版刀光」可以切雪地、冥界、焦土。武器档案里的特效播放器保留分技能和判伤范围。[Godot 实际帧](previews/vfx_polish/godot_samples.png)展示双剑交替、诛仙发剑及新挂位。旧版 S-SW 特效留在 `candidates/vfx-before-polish/`，新版发布路径、帧数和像素尺寸见 [素材清单](manifest.json)。新版接入字段与状态时序见 [接入说明](integration.md)。

用内置 imagegen 制作了 [特效视觉参考](originals/vfx_polish_style.png)，[生成提示词](records/vfx-polish-prompt.txt)随批保存。正式像素帧条按现有尺寸与边界重新绘制。

交替攻击与诛仙发剑通过本地网页和独立 Godot 时间轴展示。正式工程接入时，还需在实际输入、碰撞判伤、打断和换手状态下验证这些行为。

## 制作与来源

实际使用已授权的 OpenAI 内置图像工具，所有新动作上传对应本项目静态图。亡者、普通弓手造型复用项目既有源图，来源在逐项 generation 记录。提示词只描述外观与职业，不写人物名或其他作品名。

Pillow 用于最近邻尺寸、二值透明、静态 RGB 色板映射、整帧位置、裁排和预览。未用 Python 重画角色。小傀儡静态/最终行走从同族素材等比缩小；原创肢体运动线稿仅作生成姿势参考。C 没有使用 Piskel 手绘角色。

## 实际自检

逐项检查见 records/reviews.json。检查了 #121721 背景下实际 1× 和最近邻 4×、所有动作相位、轮廓与角色特征、统一尺度/脚底或雾尾基线、首尾相接。逐项 PNG 技术检查核对精确尺寸、RGBA、alpha 仅 0/255、每帧至少 2px 留白和不超过 48 色；每个角色动作的 RGB 全部取自其静态图。

每条动画有四倍 8fps GIF，游戏攻击建议 16fps。GIF 120/130ms 交替以达到平均 8fps。三相位的双循环处理仅用于 D，本任务动画均为偶数帧。final_audit.json 逐像素核对 GIF 与对应 PNG 帧，并核对正式文件、approved 快照和候选哈希。循环变化量统计仅作辅助，不能替代逐帧目视。

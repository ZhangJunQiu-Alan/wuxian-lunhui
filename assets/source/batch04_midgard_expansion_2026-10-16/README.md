## 实际制作与检查

以已接入的 Midgard 地面、枯松、岩石、残屋、长船、符文石及剑士为项目自有风格参照，使用用户已批准的内置 image_gen。使用Pillow12.1.1做最近邻尺寸、固定色板、二值透明、完整物件裁切、裁排和预览。边界/地面接缝采用原图像素重叠裁切；连接口复制相应直线段原像素。过渡块只给现有冰面与踩实雪地裁出二值alpha，不改变其RGB，没有重新绘制角色。

普通地形/物件使用既有48色调色板；三张血迹统一使用一种低饱和暗红，单张最多47种不透明RGB；本批及已接入首批环境素材合计48种（47种既有颜色+1种暗红），已对四个正式目录一起统计核实。血迹没有被映射成灰棕色。冰下鱼和水草由原图透明度阈值提取后，全部改为0/255透明。

实际在Chrome Piskel导入160×128长屋，关闭平滑缩放并检查尺寸、轮廓、透明棋盘。截图：`previews/chrome_piskel_longhouse_review.png`。**没有在Piskel手工改图或导出成品**。Chrome打开本地画廊，259个图像元素完整加载，边界筛选显示8/112。未注册、登录新账号、付费或调用另行收费API。

已实际查看：全部物件1×总览与分组4×；全部24种过渡4×和内外角拼装；四边与四角4×、重复段及整圈1×；两种新增填充地面的4×4与滚动；雪地/冰面贴花和冰下暗影；村庄尺度合成。技术核对包括PNG/RGBA、精确尺寸、alpha仅0/255、非空、独立物件至少2px透明留白，以及候选、快照、正式文件哈希一致。逐项见manifest与`records/final_audit.json`。

## 接入注意

1. 边界：北/南256×192，沿x每256px重复；东/西192×256，沿y每256px重复。四角192×192。以整圈预览的画布左上角坐标排布。深度192px不可拉伸；内侧透明区需要已有地面垫底。
2. 过渡块64×64：`ice_edge_*`配套`ice.png`；`path_edge_*`配套**`snow_trampled.png`**；底层用`snow_01`~`04`。`n/e/s/w`表示暴露边；`outer_*`是凸外角，`inner_*`是凹切角。冰面第二变体目前是填充变化，不把第一种纹理的边缘强行拉伸。
3. 独立物件底部有2px透明留白，落地锚点应扣除这2px。物件朝向、脚底/动画检查对这批环境素材不适用。
4. 码头两种直线段64×64沿y连接；上下端口没有透明留白，左右保持透明。破碎段是终端，必要时与直段重叠2~4px。此次没有横向码头段。
5. 陪葬剑画布32×48；初计划16×48会把斜放刀身压得难辨，因此扩大画布。任务书没有指定陪葬剑尺寸。
6. 已有`snow_trampled`在宽路面上有可见的周期纹样，RGB按“已有地块不用重做”保留。本批边缘解决方格轮廓；请代码代理在实际镜头复核宽路面材质，不把这份合成当成游戏验收。
7. 障碍轮廓/碰撞、Y排序、遮挡、出生通路、边界阻挡范围、玩法可读性仍需Claude在Godot中接入实测并由用户验收。此批不包含代码或其他批次素材。

# 剑士 3D 试点：阶段 5 接入游戏

2026-11-19。冻石庭院（`scenes/fimbulwinter_courtyard.tscn`）里的像素剑士换成 3D 模型。

## 文件

| 文件 | 内容 |
| --- | --- |
| `assets/models/characters/swordsman/swordsman.glb` | `04_绑骨/swordsman_rigged.glb` 的副本，运行时用这个 |
| `scripts/roguelite/courtyard_hero_3d.gd` | 3D 剑士：跟随 2D 玩家的状态播放动作、转向、受击闪色、死亡；挂占位刀和刀鞘 |
| `scripts/roguelite/courtyard_ink_actor.gdshader` | 墨意着色：不吃场景灯光，按太阳方向自己算两级明暗，降饱和、偏冷，轮廓略加深，细纸纹 |
| `scripts/roguelite/courtyard_actor_xray.gdshader` | 被墙、门、柱子挡住时透出冷蓝剪影；只把前面隔着 0.45 以上的东西算遮挡 |

## 怎么接的

- 逻辑不变：玩家还是 2D 的 `CharacterBody2D`，`fimbulwinter_courtyard_stage.gd` 每帧用 `world_at` 把位置换到 3D，调用 `hero.sync(player, at, delta)`。
- 身高 1.5 个世界单位（模型 1.8 m，缩放 1.5/1.8）。Godot 里蒙皮网格的 AABB 不可靠，测试用骨骼 `mixamorig_HeadTop_End` 量头顶（1.46）。
- 跑步：播放速度 = 实际移速 ÷ 3.5（原速下脚着地的地面速度，Blender 里量 4.2 m/s 再按身高换算），夹在 0.6–1.6，避免滑步。
- 出招：`attack` / `attack2` 交替，按游戏里的出招时长加速；转向鼠标方向。冲刺按冲刺加无敌时间播放；受击播 `hit` 并闪红。
- 死亡：Tripo 向前扑倒，跳过开头站着摇晃的 1.2 秒，1.2–3.7 秒这段压进 1.6 秒。游戏一死就暂停，所以 3D 剑士在死亡时改成 `PROCESS_MODE_ALWAYS`。`fimbulwinter_courtyard_player.gd` 把 `death_duration()` 至少设为 1.6 秒，结算界面等倒地后再出。
- 武器：还没有 3D 模型，`_add_weapons()` 在 `weapon_r` / `sheath_l` 上放程序生成的长条。挂点在 Blender 里 +Y 是刀身方向，glTF 导出后在 Godot 里是 -Z，尺寸和位置按 (x, z, -y) 换。

## 验证

- `tools/test_fimbulwinter_courtyard.gd`：7 个动作、两个挂点、身高、移动时跑步、出招时斩击、空格冲刺。加 `--record-walkthrough` 并配 `--write-movie` 可录整段流程。
- 验收时用的录像、近景、遮挡剪影和死亡逐帧没进仓库（体积大）。

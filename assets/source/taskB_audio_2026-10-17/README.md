# 任务 B：音效与音乐候选（2026-10-17）

状态：制作候选已齐，主观听感尚未验收，未发布到游戏自动接入目录。任务书要求的听感门槛不能用波形指标替代。

- `originals/`：实际下载的 CC0 原音频、音效库许可文本和枪械说明 CSV。没有保存下载压缩包。
- `candidates/sfx/`：任务书指定名称的 54 条 WAV，包括 7 组 `_01`～`_03`。
- `candidates/music/`：6 首 OGG Vorbis 候选。
- `gallery.html`：可直接播放的列表，列出时长、峰值、响度及验收状态。默认音量 25%，同时只播放一条。
- `manifest.json`：逐文件来源、作者、商用授权页、处理配方、哈希、测量值和未完成的自检项。
- `previews/`：7 组一分钟连续音效预览、4 首循环曲三遍连播 FLAC。它们是供试听的测试文件，不代表已经实际听过。
- `records/`：来源、下载凭证、配方和技术测量记录。音频任务按任务书第五节使用试听列表，GIF 和地块平铺不适用。

## 已实际完成的检查

音效逐条用 WAV 解码检查 PCM 16 位、44100 Hz、单声道；声音在 10ms 内起音，末样本为 0，没有达到数字满幅的样本，样本峰值为 -1dBFS（容差 0.01dB）。7 组高频音效各有 3 个非同字节变体，全部短于 0.3 秒。同组 RMS 差控制在 1.5dB 内；RMS 接近不能推定感知响度一致。完整结果见 `records/sfx_audit.json`。

音乐从编码后的 OGG 重新解码并用 FFmpeg 测量；检查 Vorbis、44100 Hz、双声道、任务书时长范围、整体响度 -16±1LUFS、真峰值低于 -1dBTP。循环边界的单样本跳变与正常相邻样本差做对比；这个指标只暴露明显信号异常，不能证明音乐段落无缝。4 份三遍预览直接重复解码后的候选，不在重复处额外修补交叉淡化。

短于 0.4 秒的单条音效无法得到可靠的事件内 EBU R128 综合响度，因此另测「补静音至 1 秒」的 LUFS 测量窗，manifest 和试听页明确注明。音效另有 RMS，不能把补零窗口的 LUFS 当成音乐的综合响度比较。

## 来源和处理边界

全部下载的外部音源来自明确标注 CC0、允许商用及改编且无需署名的作者页面。工具许可及链接已追加到 `assets/LICENSES.md`，每条成品的来源在 manifest 内逐项关联。自编波形与包络、混音和裁切由 Python 标准库、NumPy 2.4.3 和 FFmpeg 8.1.1 离线完成。没有使用 AI 音乐服务，也没有外部模型提示词。

用户手动激活并登录 Freesound 后，通过 Chrome 的 Download sound 按钮取得狼嚎、击锤和装弹原件。狼嚎为作者自制音效，不宣称是真实野生狼录音。最终换弹候选使用 tkane0512 的开膛、快速装弹、闭合录音；Nox_Sound 的击锤原件保留作来源比较，没有冒充换弹。

枪声来自 CC0 枪械库，说明 CSV 明确列为 .38 Special 左轮实录；三个变体使用同一发录音轻微变调，裁短尾音。合成的提示音、皮鼓、气流、拨弦收尾是本项目自编 DSP，与外部录音按配方分开记录。音乐是已有 CC0 曲目的剪辑，不宣称是本项目独占原创配乐。

## 仍未通过验收的项目

本会话的工具可解码、测量并播放音频，但无法可靠听辨声音内容。因此没有把「没有爆音、自然衰减、不刺耳、一分钟不烦、三遍听不出接缝、北欧配器及同篇章音色一致」标为通过。所有主观条目都明确为 pending，也没有声称做过 Godot 游戏内实测。

特别需要试听：

1. `midgard` 与 `helheim` 各重复两个裁切后的音乐单元；相邻段落与最终回环都需要听。两首来自不同作者/曲目，配器一致性尚未证明。
2. `victory`、`defeat` 目前是固定时间窗截取并淡出，完整音乐收尾及情绪尚未证明。音量与时长达标不能代替乐句检查。
3. 升级和大招就绪的节奏不同，是否容易分辨尚未听；刀光、命中、枪声和经验音的疲劳感、轻重与实际身份也需要听。
4. 号角段按能量选取，不是按已听过的乐句选取，短号与警告能否形成合适旋律尚未证明。

未验收文件保留在 candidates，没有复制到 `assets/audio/sfx/` 或 `assets/audio/music/`。听感不合格的文件需修改或换源后重测，再由代码代理接入游戏实测。任务 A 已独立完成，见同级 `taskA_cleanup_2026-10-17/`。

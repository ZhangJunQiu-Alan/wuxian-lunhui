# 冻石庭院 v5 中庭手绘小样

## 构图与源稿

用原项目的 Godot Compatibility 渲染器从 v4 的白盒导出。镜头方向直接读取舞台的 `CAMERA_OFFSET`。引导画幅为 4032×2688，正交高度 16，比例为每世界单位 168 像素。当前游戏 720 像素高、最小正交高度 9，最多每世界单位 80 像素。引导分辨率是这一上限的 2.1 倍。

- [引导目录](引导/) 含两态白盒、地面与冰海单独渲染、分组 ID、逐组二值遮罩、两态及独立地面的深度、落闸引导。[projection.json](引导/projection.json) 同时记录镜头基向量、火盆基点和 257 个原碰撞锚点。深度按 R、G 字节编码为 16 位线性相机距离。
- [court-paint.png](court-paint.png) 用破败态白盒作为构图输入，A1、C1 作为配色、光向和材质输入。底稿使用整幅 1536×1024，保留长厅、两处场内石堆、墙线、崖缘与门洞的位置。
- [court-underpaint.png](court-underpaint.png) 用底稿和地面白盒补画，填回木架、石墙、门及石堆后面的铺地和雪面。
- [court-broken.png](court-broken.png) 以底稿和 C1 返画破败门，修改横梁断口与错台、门板纵向裂口、门脚积雪。[court-restored.png](court-restored.png) 用同一底稿和 C1 重画接合横梁与空门洞。
- [brazier-paint.png](brazier-paint.png) 用底稿与 C1 生成透明底座火盆。以上五次均使用内置 ImageGen。完整指令见[提示词](提示词.md)。

## 切层与动态精灵

[prepare_layers.py](prepare_layers.py) 以独立遮罩切出长厅和墙石层。被挡住的内部用补画底稿回填，轮廓留同源像素重叠。出口两个状态独立切轮廓并回填对应门槛与阴影。入口闸板由破败门板按四角投影转绘压图，保留原落闸动作。进／离中庭的交叠区同步羽化地面和墙石层。

- 运行时位图位于 [v5_painted](../../../models/midgard/courtyard/v5_painted/)。长厅、墙石层、两态门框、入口闸板通过相机空间深度和场景深度测试绘制，角色被挡时沿用原剪影。
- 门框两列手绘线条按古弗萨克 `ᚠᚢᚦᚨᚱᚲ` 同序绘制。字形参考 [Unicode Runic 字符表](https://www.unicode.org/charts/PDF/U16A0.pdf)。两态门上的其余装饰为交织纹和兽首浮雕。
- 火盆精灵固定基座，shader 在火舌区做小幅位移和亮度动画。火光、传送门蓝光分别使用叠加光晕位图。透过门洞四角投影定位光幕，保留原有发光时序和粒子。
- v4 白盒蓝图及碰撞锚点仍来自同一个 GLB。中庭重绘区域隐藏 v4 可绘制部件，外围前路继续使用 v4。角色、敌人和流程沿用原关卡。

## 轮次 06 · 前路铺满

- 斜立石碑沿用此前在 Blender 5.3 图形界面保存的源文件。编辑模式缩放碑坯、倒角，添加并应用细分曲面，再用雕刻 Draw 笔刷做 ᛉ 浮雕和表面起伏。最终调整立碑朝向和倾角，使用平滑着色。过程保留碑坯、雕刻、定型三个阶段的游戏镜头与近景。 [BLEND](blender/approach-leaning-stele.blend) · [过程截图](blender/过程截图/)
- 原模型的正交视口与游戏相同，Blender 的渲染脚本只设置工作台渲染和输出。透明底稿按石碑脚点叠进 Godot 输出的前路引导图，保留轮廓、浮雕方向和倒角。续作按指示沿用这一版，单独制作的 stele_v2 留到后续换图。 [透明底稿](blender/stele-game-guide.png) · [叠入后的引导图](引导/approach-paint-guide.png)
- `export_guides.gd` 导出西向 8064×5376 正交白盒、分组遮罩和两幅深度图。按同一比例将已验收的中庭贴到引导图右侧，再以 B1 和已验收的色温作手绘覆盖。第一张作废，入口前多画了一条路。重画后沿白盒的单一路线定位墙脚和入口。 [白盒](引导/approach-whitebox.png) · [分组](引导/mask-groups-approach.png) · [前路手绘](approach-paint.png)
- 将近景冷杉、斜立符文碑和断石柱描边切层。树石后方补雪、低墙、岩石，底层保留原画的抗锯齿边缘。遮挡纹理由物件脚点取深度。场景继续使用原角色深度剪影。 [背后补画](approach-underpaint.png) · [遮挡轮廓](引导/approach-contours.json)
- `prepare_room.py` 将左右底画合成 4096×2192 的整房底板，沿林缘、路面和崖岸软接；东侧补画承接出口外镜头。V4 场景只提供既有锚点和门的父节点，所有网格隐藏，旧冷杉、水和材质构建停用。前路火盆同中庭使用动态精灵。 [东侧补画](court-east-edge.png)
- `prepare_layers.py` 在点亮态门左柱外重新补画石墙和雪地，破败态保留落木。门、符文、光幕、剪影和光晕按各自图层绘制。 [左柱外侧补画](gate-restored-without-left-brace.png)
- 重跑时先执行 `python3 prepare_layers.py` 和 `python3 prepare_room.py`，再按任务包 README 导入 Godot。三个新增运行时纹理必须先落盘，否则脚本的 `preload` 会级联失败，关卡的 `pulse()` 收到空节点。

## 轮次 08 · 扩建中庭

- 西侧门槛保留在 `(-672, -165)`。战斗左右限位为 `-642 / 1388`，东侧门组、光幕和门后离场点一起东移 580。北、南两条弧形墙从中段向外展开，在西闸和东侧通道收回原宽。绘制和碰撞共用 [庭院布局](../../../../scripts/roguelite/fimbulwinter_courtyard_layout.gd) 的坐标变换。对扩开后的墙线补足碰撞锚点，退役场内旧碎石的六个锚点。

- 以上一轮整房地面按新坐标投影得到[绘画引导](round08/paint-guide.png)，与 A1 一起输入 ImageGen，生成[手绘源稿](round08/court-paint.png)。要求沿原透视画冷灰石板、踩雪路和蓝冰，中央嵌交织纹圆盘，预留空白铭文带，墙边放断矛、盾牌、头盔。地面中央不画直立物。正式面积测量后小幅收窄两侧肩部，[最终投影](round08/registered-guide.png)用于二次配准。
- 圆环沿用石刻纹理。用 Apple Symbols 按 24 个古弗萨克字符逐个排入凹槽，雪线减弱笔画，保留原稿的裂缝和缺口。按内沿羽化手绘地面，外围保留连续的林缘、门槛和崖海。两态出口门、入口木闸、长厅、火盆和光效沿用既有精灵。

# 剑士武器 3D：太刀

2026-11-20。剑士 11 把武器的第一把，参考 `assets/source/characters/swordsman_3d/02_三视图/武器.png` 上排的长刀。

## 做法

没有用 Tripo：刀这种细长的硬物件，图片转 3D 容易把刀身糊成一团，几何也简单，直接在 Blender 里用脚本建模（`建模.py`）。

| 文件 | 内容 |
| --- | --- |
| `建模.py` | 生成刀和空刀鞘：`blender -b --python 建模.py -- katana.blend` |
| `katana.blend` | 两个物体：`katana`（刀身、刀铐、刀镡、柄、柄头）和 `katana_saya`（空刀鞘） |
| `侧视.png` | 侧视预览，排版照参考图 |
| `assets/models/weapons/swordsman/katana/katana.glb`、`saya.glb` | 游戏用的两个模型 |

- 坐标就是挂点的本地坐标：+Y 是刀身方向，+Z 是刃口一侧，握把中心在原点。刀挂右手 `weapon_r`，鞘挂左腰 `sheath_l`（挂点见 `04_绑骨/说明.md`）。
- 尺寸（米，模型身高 1.8）：刀身 0.70、反り 2.2 cm、身幅 3.0→2.3 cm；柄 0.25；刀镡直径约 8 cm；鞘 0.78。
- 截面是棱形（刀背、两侧镐线、刃口），刃口两侧那两条面用亮一点的材质，远看像刃文。柄是黑色卷绳和红色鲛皮交错成斜菱。
- 材质只有底色（没有贴图），游戏里的墨意着色器读材质底色。刀出鞘拿在手里，所以腰上挂的是空鞘。
- 面数：刀 706、鞘 422。

## 以后的武器

另外 10 把照同样的坐标和挂点做；形状差别大的（例如长柄、双刀）在 `建模.py` 里加参数或另写一份。

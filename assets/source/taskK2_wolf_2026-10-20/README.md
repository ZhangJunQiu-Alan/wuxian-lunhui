# K2：狼王、巨口、格莱普尼尔与维达

本批新增12张正式PNG、44帧。5条狼王身体动作、独立上下颚、细编带材料、碎片拾取物，以及维达静态／待机／撕口。交付状态以completion.json和records/final_audit.json为准；没有接入第三关，不代表游戏验收。

来源为已批准内置image_gen。实际提示词、输入参考、工具结果、生成原图和退回原因全部保留。身体动作沿用原狼王48色色表；维达是本项目新制作的世界内人物，不使用卡面作战斗精灵。Pillow只提取／裁排原生成像素、最近邻统一尺度、色表／alpha规范化和预览，没有程序重画人物。每条动作采用共同尺度，不逐帧拉宽压扁。

8份生成稿退回：移动v01改变视角和比例；蓄力v01伸肢超出统一画布；整张巨口和束缚各v01～v03仍侵占中心保护区。原稿和失败检测保留，不发布旧fenrir_maw.png或fenrir_bind.png。新方案见契约K2-maw-bind-v1.1，上下颚分开，束缚用细编带沿权威路径绘制。下颚原图跨格的毛尖通过32px裁格溢出保护完整提取，邻格游离像素排除，没有抹除牙齿来伪造净空。

原速／8fps GIF、1倍逐帧、4倍逐帧和深色对照均在previews。GIF只能以10ms量化，单次动作末帧额外600ms为检查停顿，不是玩法时长；原速8fps与8fps检查相同。编带4×4是材料重复检查，不是地面新图。

独立Godot场景实际输出52张截图：身体和援助动作、巨口／束缚合成、三帧手靴接触，以及8张透明背景净空检查。巨口保护矩形112×64和束缚中心80×84在四相位均为零遮挡；编带实际alpha加权覆盖约4.11%，低于12%门槛。最初预览脚本类型推导错误已修复，失败日志保留；平台输入法mach-port诊断也保留。

维达接触演示仅展示撕口第2～4帧的手／厚靴坐标注册。玩家逃脱、伤害关闭后的援助镜头按接触点移动上下颚；不能把这个镜头的开口位置用于仍可吞噬玩家的阶段。玩家活动吞噬阶段使用至少64px几何分隔。完整进场、撑口、撕裂与离场的时序仍需集成Agent实现并在实际游戏验收。

## 实际检查

逐图检查生成图的人体、手部、武器或动物结构；查看 260×433 缩略图、下45%深色文字遮罩及安全线预览。具体结果和退稿原因在各 generation/approved 记录。重要面容、手势、武器端部和动物脸避开侧边；非关键背景羽翼、光轨、衣摆可出血。下40%亮度仅作辅助记录，不以亮度数字替代目检。并排画风、道路与觉醒对照见 gallery。

离线 mipmap 逐图10级，另提供260×433预览。它们不会自动开启 Godot 导入的 mipmap；接入者必须验证导入和实际 UI。静态卡面不制作动画、GIF、像素4倍或无缝平铺测试，这些不适用。
